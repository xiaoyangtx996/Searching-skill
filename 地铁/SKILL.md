## 站台与屏蔽门

*屏蔽门样式判断城市与线路*

- 铁皮围挡 → 多为地铁施工工地，可用于确认在建地铁
- 站台两侧均设有屏蔽门 → 可判断为岛式站台，轨道位于站台两侧
- 站台屏蔽门在左右两侧 → 岛式站台
- 照片所在城市规模大且存在地铁 → 优先检索该国首都或最大城市
- 店铺招牌上保留某地铁系统的标志 → 该店铺位于该系统所在城市
- 画面中出现本地地铁官方App或乘车码 → 可据App名称与界面识别所在城市
- 机场方向地铁与公路交汇处的形式 → 可用于比对候选城市郊区交通节点
- 城市雕塑分布与有地铁城市重叠 → 可辅助缩小区域/城市范围
- 未开通线路通常已安装屏蔽门而现场没有 → 更倾向判定为废弃线路
- 地铁导视标志形状独特 → 可据此筛选运营城市
- 城市公共雕塑较多且已开通地铁 → 可作为候选区域特征
- 地面小型构筑物尺寸明显小于地铁通风井 → 更可能是其他市政设施，不应据此判定附近有地铁
- 路牌/路口方位与地铁口相对关系 → 可定位站点和拍摄方向
- 屏蔽门形式（全高/半高）具有城市/线路/站点差异 → 可用于排除或确认城市/线路
- 不同城市地铁站台门配置不同 → 可判断地域
- 在站厅和通道中少见到的标识/设施出现在照片 → 对定位权重高，因稀缺特征更易锁定
- 某城市地铁出站导向牌有统一制式 → 可据牌面样式识别城市
- 通用设施缺乏地域区分度 → 定位权重低
- 站台门形式与站点类型相关：高架站常用半高屏蔽门，地下站常用全高屏蔽门 → 可据门型反推地上/地下或高架/地下站
- 站台门形式随建设年代变化 → 可用于判断线路/车站年代
- 半高屏蔽门多见于高架站，地下站若用半高会进尘 → 可辅助判断站台是否高架
- 建筑密度与规格 → 可判断是否市中心/郊区
- 4 路口、地铁口、周边建筑三者同框 → 可构建相对方位关系定位拍摄点
- 5 拍摄者位于路口一侧且地铁口在旁 → 可推断其站在人行道或路缘附近
- 10 站台门为全高或半高 → 可辅助判断城市、线路及车站类型
- 11 高架站与地下站的站台门形式不同 → 可据门型反推站台是地上、高架或地下
- 14 早期站台无屏蔽门、后期加装屏蔽门 → 可据门的有无与样式判断拍摄时期
- 15 站厅和通道中很少见的标识或设施出现 → 定位权重高，因稀缺特征更易锁定
- 16 常见通用设施缺乏地域区分度 → 不宜单独作为城市或站点判据
- 17 既往同类题已确定拍摄城市 → 可将同城市作为新题的首选假设再验证

## 线路图与标志色

*线路标志色锁定具体线路*

- 无文字的线路图难以直接读出城市 → 需靠线网形状比对
- 出站换乘在部分城市更常见 → 可作为城市或线网风格的辅助判据
- 网络流传的线路图存在错误 → 线路实际走向须以官方或实地资料核实
- 多个候选站均为换乘站 → 换乘属性不足以唯一确定，需借助其他特征区分
- 线路图整体倒置 → 该图方向与常规线路图相反，可能拍摄于反向端或镜像视角
- 线路图色块深浅不同 → 可用于区分不同线路，辅助判断拍摄站点所属线路
- 非换乘站仍人流极大 → 更可能位于大城市或核心区
- 换乘站人流多 → 区分度低，不能单独用于判断城市规模
- 非标准/自制线路图出现 → 不能按官方线路图比例与车站顺序定位，需依赖图例和文字说明
- 多条线路共享同一线路代码 → 可能标识直通运转或同一运行系统，可据此理解线路图关系
- 自制线路图仅表示大致走向，不表示真实比例 → 不能按图估距离和方位
- 线路图中用单字/缩写代表站名 → 需先还原站名再定位
- 图中标注站点若全无换乘 → 可排除换乘站密集区域或说明制图简化
- 列车涂装/色带颜色 → 可与城市线路标志色比对，锁定线路
- 换乘标志样式 → 可识别城市或运营体系
- 线路标志色 → 可锁定具体线路
- 线路图中换乘站数量与位置 → 可判断列车运行方向
- 线路图中被遮挡/码掉的站名 → 可结合已过站和未到站推断当前位置
- 站点序列与换乘关系 → 可排除方向或支线

## 车站内景

*装修风格判断城市*

- 沿在建地铁站逐一比对地图 → 结合地图上特殊几何结构可确认位置
- 地铁站入口造型 → 可作为城市轨道交通识别特征
- 路牌的颜色、字体、立柱数量等形制有城市统一标准 → 可据制式匹配城市
- 地铁站台相反方向使用不同标识颜色 → 可据颜色判断站台与行车方向
- 地铁站附近通常设有公交接驳站 → 可作辅助判据
- 识别出护栏、立柱等标准件样式 → 可缩小到特定地区或路网
- 地铁导向标识使用简体"出"字 → 大概率位于中国大陆的地铁系统
- 地铁站名的外文部分为纯拼音 → 大概率位于中国大陆
- 照片中同时出现多个地铁站名 → 站名组合可作为城市指纹用于反查
- 高密度商业区内出现的地铁站 → 多为地下站，地面或高架站多见于外围低密度区
- 建筑前无明显地铁标识 → 不宜直接判定为地铁站
- 画面中同时出现地铁站出入口与道路交叉口 → 拍摄点位于交叉口附近，可据出入口位置判断人行位置
- 若从拍摄点向右转可看到地铁站 → 地铁站位于拍摄方向右侧
- 地铁站出入口垃圾桶样式若为统一制式 → 只能确认附近有地铁站，不宜作为城市或站点唯一判据
- 画面下方出现地铁站，左前方停车场，右前方加油站 → 以三个地物相对方位构建三角形定位拍摄点
- 地物相对位置（地铁站、停车场、加油站） → 可反推拍摄点与朝向
- 利用公交站、海滩入口、市政府、地铁站之间的相对距离 → 可建立距离方程定位
- 著名地标与地铁站的距离差 → 可辅助区分同名或相似海滩
- 出现地铁站牌 → 拍摄点位于该站附近

## 出口与导向

*出口编号与导向标识样式*

- 远处指示牌、标识的文字与图形可指示场所类型 → 可用于判断所处环境
- 直接搜某类地物名称即被导向特定地区 → 属搜索结果的地域偏置，不能直接采信
- 地铁出入口标志上的城市轨道标识 → 可据此确定所在城市
- 小型箭头指示牌样式在公园、景区、园区、单位间通用 → 不能单独作为定位依据
- 城市道路指示牌的底色、字体与配色由地方规范统一规定 → 可据此判定所在城市
- 室外高台设有扶手 → 多为地铁出入口或车站等公共设施
- 出入口编号与出口指示牌标注的道路名 → 可定位车站及出口朝向
- 地铁新线的装修风格与出入口结构 → 可判断所属线路与车站
- 地铁出入口与导向标识样式 → 判断所在城市；线路标志色 → 判断具体线路
- 车辆/列车等工业产品有明确产地与出口流向 → 型号可反推地理范围
- 具体品牌/型号 → 结合出口分布缩小国家/地区
- 工业产品有明确产地或出口分布 → 型号可缩小到特定国家或区域
- 站名与运营标志设于出入口正上方 → 是部分地铁系统的出入口样式，可作筛选或排除依据
- 地铁出入口的形态与材质 → 可用于排除候选城市与线路
- 同一车站不同出入口造型可能不同 → 不可用单一出入口外观代表整站
- 大厦旁钢结构顶部透光的小型建筑 → 大概率为地铁出入口
- 地铁出入口顶棚是否透光 → 可区分不同城市/线路的地铁口形制
- 地铁出入口或电梯口采用统一且高覆盖率的配色 → 该配色可辅助识别所属城市，但需排除多地通用配色
- 地铁出入口顶棚是否透光具有城市或线路差异 → 可辅助区分所属城市或线路
- 地铁出入口顶部是否透光可区分同类出入口形制 → 可用于排除不符合城市
- 地铁埋深/出入口下行深度具有地域或地质差异 → 可辅助判断南北方或城市
- 依赖特定出口编号/临时物料的推测 → 验证资料可能缺失，定位可靠性低
- 2 地铁出入口位于拍摄方向右侧且转头可见 → 拍摄者所在位置与地铁口存在固定相对方位
- 道路指示牌上的城市名 → 通常是该道路的起点、终点或主要途经大城市
- 指示牌上的里程数 → 可沿道路走向反推拍摄点与牌上城市的距离
- 商场、小区等本地化场所的出入口 → 出现本地车牌的概率较高
- 画面中出现地铁与火车站标志的指示牌 → 该地同时有火车站与地铁，属规模较大的城市，可在有地铁的城市中检索地标
- 交通灯旁指示牌的文字与样式 → 可推断所在城市
- 对特定功能指示牌（管理牌、公共设施指引牌）有记忆印象时 → 可作为该地曾见过的快速确认线索
