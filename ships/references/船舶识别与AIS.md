## 一、船舶信息三要素

与航班同理：**船名/IMO/MMSI** 是唯一标识，可反查轨迹。

| 标识 | 说明 |
|---|---|
| **IMO 号** | 国际海事组织编号，**终身唯一**（最可靠） |
| **MMSI 号** | 水上移动通信业务标识（9 位，前 3 位是**国家码 MID**） |
| **船名** | 可能重复，需配合 IMO/MMSI |
| **船籍港（Port of Registry）** | 船尾通常**漆有船籍港名**（常为母港城市拼音/外文） |

### MMSI 前 3 位 = 国家（MID 码）

| MID | 国家/地区 |
|---|---|
| 412 / 413 | 中国 |
| 431 / 432 | 日本 |
| 440 / 441 | 韩国 |
| 477 | 中国香港 |
| 453 | 中国澳门 |
| 416 | 中国台湾 |
| 563 / 564 / 565 | 新加坡 |
| 209 / 210 / 212 | 塞浦路斯 |
| 636 | 利比里亚（方便旗） |
| 538 | 马绍尔群岛（方便旗） |
| 311 | 巴哈马（方便旗） |

> ⚠️ **方便旗**（利比里亚/巴拿马/马绍尔）**不代表船东国籍**——大量中国船挂方便旗。
> 因此 MMSI 只说明**注册国**，不能直接判断船的实际运营地。

## 二、AIS 查询工具（对应航班里的 Flightradar24）

| 工具 | 链接 | 说明 |
|---|---|---|
| **MarineTraffic** | https://www.marinetraffic.com/ | 最常用，实时 + 历史轨迹 |
| **VesselFinder** | https://www.vesselfinder.com/ | 同类替代 |
| **船讯网** | https://www.shipxy.com/ | 中文，国内港口覆盖好 |
| **Equasis** | https://www.equasis.org/ | 欧盟官方，船舶登记信息 |

**用法**：
1. 从画面读出**船名**（船艏/船艉通常刷有大字）或 **IMO 号**
2. 上 AIS 平台搜 → 得到**船型、尺寸、船旗、船东、历史靠港记录**
3. 历史**靠港记录**最有价值——能直接给出这条船到过哪些港口
4. 结合画面里的港口设施（吊机、堆场、堤岸）交叉验证

---

## 三、从画面识别船的要素

| 画面特征 | 能推出 |
|---|---|
| **船型**（集装箱/散货/油轮/客滚/渔船） | 对应的港口类型与航线 |
| **船籍港文字**（船艉） | 注册港所在国/地区 |
| **船旗** | 船旗国 |
| **吃水线高低** | 满载/空载（判断是否刚装卸） |
| **船体文字/公司标志** | 船公司 → 公司常驻港 |
| **吊机/甲板设备** | 船种细化 |
| **驾驶台位置**（前/中/后） | 船型与年代 |

---

## 四、与港口设施交叉

| 设施 | 线索 |
|---|---|
| 岸吊类型（门机/桥吊/卸船机） | 货种与港口等级 |
| 堆场货物（集装箱/煤/矿石） | 港口性质 |
| 系船柱、护舷 | 泊位规模 |
| 航道浮标/导标 | 进港方向 |
| 引航船/拖轮 | 大型港口特征 |

> 港口结构可交 `infrastructure` 域对照；坐标反查用 `geo-sleuth/scripts/osm.py`（`find harbour`）。

---

## 五、执行要求

1. **出口交接**（`docs/技能互联·产出手册.md`）：船型/船籍港/航线 → 交 `region`（船籍港文字）+ `infrastructure`（码头结构）
2. 证据分级：船名/IMO 读出 = **A 级**（可机读反查）；船型目测 = C 级
3. **方便旗不可当国籍**，必须说明局限
4. AIS 历史数据**部分需付费**，免费版常只看近期

---

## 六、局限

- **船名可能重复**（尤其小船），务必用 IMO 号确认
- AIS **有覆盖盲区**（远洋、部分海域关闭 AIS）
- 画面里的船**可能已改名/改籍**——船名历史会变
- 免费 AIS 平台的**历史轨迹保留期短**，老照片可能查不到
