## 机型识别

*客机机型特征识别*

- 民用住宅阳台通常朝向同一采光方向 → 可由阳台朝向反推拍摄方位与飞机航向
- 军用机型的部署地与拍摄地地理条件不符 → 可据此排除该机型判断
- 机型可由外观特征（发动机、翼尖、舷窗等）区分 → 机型确定后可反查航司与常见航线
- 民航客机涂装配色 → 可缩小到特定机型与航空公司
- 通过航班追踪网站按机型与区域筛选航班 → 可定位具体航班进而定位机场
- 平时罕见的机型在某地频繁出现 → 该地为其运营方基地或主要运行点
- 先按大类逐层排除缩小机型范围 → 再结合该机型的部署基地定位
- 驾驶舱窗户形状、发动机数量、起落架轮数等外形特征可用于识别机型 → 机型识别可进一步缩小航司与航线范围
- 候选航班可用机型匹配来排除 → 机型不符的航班可剔除
- 由舷窗形状与座舱内饰细节 → 可判定机型系列，排除常见窄体机型
- 画面中出现凝结尾 → 拍摄高度高于约八千米，属高空航拍
- 仅凭机型系列一致 → 不足以定位机场，需叠加其他线索
- 车载刷卡机型号少见 → 属强地域特征，可作城市判据
- 仅凭登机口或廊桥位置 → 不足以唯一确定拍摄者所乘机型与航司
- 机翼轮廓相近、难以区分机型时 → 用机型特有细节（如翼上灯光位置）判别
- 路口无监控设备 → 提示区域交通管理特征，可作辅证
- 某地有著名特有物种 → 提示气候区与地域范围
- 两侧机翼在画面中视觉长度不等 → 飞机正在转向，较短一侧为转弯方向
- 识别出窄体机型 → 不能据此排除中小型机场

## 航司涂装

*由涂装判断航空公司/国家*

- 学校院内停有飞机或建有跑道 → 该地点多为航空类院校或训练基地，可据此定位城市
- 发动机涂装颜色可用于识别航空公司 → 若其他航司在机身其他部位另有花纹图案，可用整体涂装排除误判
- 大型停机棚或机库体量巨大 → 该机场等级较高，可排除小型通用航空机场
- 飞机侧面图数据库 → 可核对机型与航空公司涂装
- 航司在某机场的运行模式为过站 → 不会停放远机位；出现则提示航班取消等异常
- 机翼小翼或机身涂装的颜色 → 可判别所属航司及是否为彩绘机
- 地勤保障车辆的涂装与标识 → 指向所属航司的基地机场
- 航空公司基地与注册地高度相关，机队多集中于基地 → 识别出航司后可优先排查其基地所在城市
- 翼尖小翼的颜色与形状属于航司涂装特征 → 可用于识别航空公司
- 特殊主题彩绘涂装带有地域或基地信息 → 可用于推断航司所属地区
- 赛事举办期间机场会出现非常驻航空公司的飞机 → 不能按航司常规基地分布推断地点
- 加油站品牌 Logo 可识别 → 搜索该品牌分布可定位国家或区域
- 背景有塔吊 → 工地，塔吊文字/LOGO可含施工单位或项目编号
- 画面中出现稀有涂装或小机队机型 → 可唯一对应某架航空器，进而反查航班记录定位时间地点
- 航空器涂装与注册号 → 唯一对应所属航司及基地
- 照片中出现航空公司标识或飞机涂装 → 结合航司主基地可推断机场
- 设施上的标志或logo具有专属性 → 可据此锁定特定项目、线路或机构，再在其相关场所中排查
- 高楼顶部设置独立logo的一般是大型企业 → 可用logo轮廓反查企业大楼图片锁定位置
- 检索不到的陌生logo → 难以通过图搜匹配到同款，此路径通常不通
- logo中出现蛇与权杖图案 → 大概率为医院或医学院
- 招牌文字残缺或名称不全时 → 用模糊搜索的推荐结果补全品牌名，再以logo比对确认
- 图形类logo的长宽比例 → 可作为辅助识别的特征之一
- 企业完成工程后常在成果物上留下自己的logo和名称 → 此类施工标识可作为反查施工单位进而定位的线索
- 画面视角高度不高于同画面地物 → 拍摄平台不是航空器

## 注册号规则

*B-xxxx 等注册号编码规则*

- 飞机注册号的字母前缀与字符位数有固定编码规则 → 可由注册号格式判断飞机的注册国家或地区
- 由飞机注册号可查得所属航空公司 → 再用该机近期航线分布缩小排查范围
- 跑道编号 → 对应磁方位，可反推跑道走向；编号相差18的两条跑道互为反向
- 飞机注册号 → 可在航班追踪网站反查历史航迹与起降机场
- 注册号尾数易误读 → 需多张照片或多数据源交叉验证
- 机位编号的位数与字母分区规则 → 可反推航班类型及所在航站区
- 机身注册号的近期飞行记录只往返少数机场 → 拍摄地可限定在这些机场之内
- 飞机注册号带有国别前缀 → 可由注册号判断飞机所属国家或地区
- 找不到注册号或飞行记录 → 不能据此断定该飞机未飞行或该航班不存在
- 车辆编号可用于反查其登记归属地 → 可缩小搜索区域
- 标牌上的频率、编号等参数与运营无关 → 属干扰项，不作线索
- 画面中出现可辨识的飞机注册号 → 查询该机长期执飞航线可反推所在机场
- 航空器注册号 → 可查历史航班记录，结合阴影方位可锁定具体班次
- 工地塔吊上的文字或编号 → 可提示施工单位、项目名或地区
- 列车等交通工具的字母与数字编号规则 → 可用于识别车辆类型或配属系统
- 电力/通信箱体上的编号 → 可用于精细定位
- 编号前缀、位数、连续排列规律 → 可排除或确认街区范围
- 模糊编号只能辨认部分数字 → 结合同街区连续编号与建筑特征反推完整编号
- 画面中出现公路编号路牌 → 可用于反查立交、路段或周边路网位置
- 列车编号字母 → 判断车种：K快速、T特快、D动车、G高铁、纯数字为普速
- 画面中出现明确注册号、机号或车辆编号 → 可查其配属与运行记录，反推地域与时间
- 门牌或编号统一使用某种颜色与字体 → 特定机构的标识习惯，可用于排除候选地点
- 号牌两侧出现相同的地名或编号时，说明该处为车辆途经点或归属点 → 可据此锁定拍摄位置
- 照片中出现的店面全部是连锁品牌 → 单凭品牌难以定位，需依赖门店编号或周边环境等附加线索
- 路牌同标两条跑道编号 → 该路口左右分岔分别通往两条跑道端
- 门牌仅部分可见或模糊 → 结合编号规律、相邻门牌序列与街道走向推断完整地址及所在区域

## 机场与跑道

*跑道数目、航站楼判断机场*

- 广告牌内容为某一机场独有 → 可直接锁定该机场
- 雕刻传统纹样的装饰多见于大型国际机场 → 可在大城市主力机场中比对航站楼天花板纹样
- 非英语国家的机场标识通常同时使用本国文字与英文 → 标识文字种类可判断机场所属国及机场等级
- 机场规模体量、周边海拔与水域形态可组合成特征 → 可由水域半岛等地貌形状吻合度锁定城市
- 照片拍摄时段与航班在该机场的停留时段不符时 → 应查更早或更长时间的航班记录再判断
- 机场地面设备（轮档材质、行李拖车样式与颜色）存在地区差异 → 可由特种设备的形制与配色区分机场
- 居民区上空飞机航向稳定 → 可由日常观察到的航向判断机场跑道方向与起降方向
- 夜间被大面积照明、满足航空目视需求的区域多为机场 → 可见跑道照明时判定场景为机场
- 机场通常不会紧邻居民区 → 若拍摄点距居民区极近，更可能是供小型飞机起降的通用机场
- 机场内体量巨大、无窗的厂房式建筑 → 多为机库或飞机维修中心
- 飞机逆风起降 → 由当地盛行风向可反推跑道走向与机头朝向
- 航站楼外观与布局清晰可见 → 可反查具体机场；若多图中含航站楼，通常对应起飞机场
- 按跑道编号推算的范围筛不出匹配地形 → 说明跑道走向或机场范围假设有误，需更换思路
- 货运航线基本固定 → 可通过机场官网或其物流页面查得全部货运航点
- 机位编号与滑行道编号的组合具有机场唯一性 → 可据此直接定位机场
- 机场等级含4F → 该机场具备国际航线
- 城市与机场隔海相望且无桥相连 → 机场位于对岸独立岛屿
- 单跑道机场的起降方向由地形与主导风向固定 → 可由机头朝向反推拍摄方位
- 多架飞机目的地相同而出发地不同 → 目的地为共同交汇机场
- 塔台外形在各机场互不相同 → 用塔台图库比对可唯一定位
- 画面中的企业标识或设备品牌所在地与机场同城 → 可交叉验证城市
- 飞机高度明显低于巡航高度 → 拍摄地距起降机场不远
- 航站楼建筑形态与登机口布局具有唯一性 → 与航司基地比对可确定具体机场及航站楼
- 地铁线路可直接进入航站楼内部 → 该城市拥有轨道交通机场专线，属枢纽级机场
- 在未经确认的机场假设上做反向推理 → 结论只能作为待验证候选，不能直接采信
- 出租车驶上高速 → 大概率行驶于绕城高速或机场高速，起点或终点临近机场
- 体育场馆多呈左右对称兼中心对称布局，外圈带跑道 → 可据此识别场馆类型并定位
- 工程机械或地勤设备的品牌型号具有机场专属性 → 可反查所在机场
- 航站楼上存在独特造型建筑且远处停有特殊涂装飞机 → 结合航司航点网络可交叉锁定机场
- 飞往某一方向的航班先反向绕行主城区 → 可由航迹绕行方向反推城区与机场的相对方位
- 机场跑道、滑行道与轨道的交叉关系 → 可反查所属城市
- 飞机处于起飞后不久的姿态 → 城市具备机场且拍摄点距机场较近
- 画面中出现机场广告/航站楼特征 → 判断为机场；若某城市仅有一个机场，可锁定城市
- 画面出现机场广告/航站楼特征 → 判断场所为机场
- 小城市只有一个机场时 → 机场特征可反推城市
- 飞机进近五边通常为左转程序 → 可据跑道朝向判断航迹是否与机场匹配
- 飞机航迹与跑道朝向矛盾 → 排除该机场为拍摄地
- 机场跑道的数字编号 → 对应其方位角 → 可确定跑道朝向与拍摄方位
- 空中出现飞机尾迹 → 提示附近可能有机场
- 廊桥停机密度高 → 拍摄时段偏早或机场繁忙
- 机场采用远机位摆渡车而非廊桥 → 可辅助推断机场规模或航站楼布局
- 航司标识建筑紧邻跑道 → 该航司在该机场有基地或驻场
- 已知当地盛行风向 → 可推断跑道起降方向与拍摄朝向
- 跑道旁水面有船舶且与跑道高差小 → 机场位于沿海
- 机场已通航但仍在大规模施工、背景为较新设施 → 定位到该机场的新建区域或新投用设施

## 航线与时刻

*航班号与时刻反推航线*

- 货运经停航线一般由同一架飞机执飞，航班号尾号连号 → 可由航班号连号关系判定多张照片是否属于同一架飞机的连续航段
- 飞机飞行高度很低 → 飞机处于起飞或降落阶段
- 将航线分布与地形条件交叉比对，排除不符合的航段 → 可快速缩小候选地点
- 单个机场每天起降的航班基本固定 → 可由航班时刻表反推拍摄地点与时间
- 拍摄侧别结合海面、岛屿、海岸线的相对位置 → 可判断飞机航向，进而区分起飞与降落
- 判定为降落但飞机下方是海面，且目标国少有海岛民航机场 → 该判定大概率错误，应改判为起飞
- 社交平台水印与发布时间 → 可确定拍摄时刻及多张照片的先后顺序
- 同一飞机多张照片的时间差结合姿态 → 可判断处于起飞、巡航还是进近阶段
- 飞机呈上升姿态、高度较低 → 判定为起飞后不久
- 飞机襟翼开度明显且高度下降 → 判定为进近降落阶段
- 航班数据平台数据全但准确度低 → 需用另一数据源二次核实
- 机队规模有限时按机型逐架排查航班号 → 可行，但耗时
- 直升机涂装与用途偏向公务或消防 → 通常无航班号，不能按民航航班线索处理
- 航线走向与进近航路相对固定 → 结合航路图可推断飞机大致位置
- 多个候选航班的时间窗均与拍摄时刻吻合 → 需再用机型航程与飞行时长差异进一步排除
- 一批已知航班在同一跑道降落 → 拍摄点位于该跑道的进近或滑行路径附近
- 航班号不确定但静态地理特征一致 → 以后者定论
- 拍摄设备朝向机头 → 画面方向即机头朝向，可排除与起飞方向矛盾的航班
- 某区域航班起降频次低 → 候选航班数量少，便于逐一反查拍摄地点与时间
- 同一起飞机场或出发地的航班常集中于特定航站楼 → 可由航站楼反推航线或出发地
- 已知日期后，当日实际执飞的航班数量有限 → 可枚举并逐一比对以锁定具体航班
- 航司航班时刻表可用于排除日期 → 无符合时刻的航班即可排除该候选日期
- 航班延误等实际运行状态会使计划时刻失真 → 需用实际运行数据核对而非仅凭时刻表
- 航班追踪数据因接收覆盖不足而缺失，可能仅有部分方向航班的记录 → 记录缺失不能作为排除依据
- 飞机朝向停机位或航站楼方向滑行 → 判断为刚降落；背离则判断为刚起飞
- 候选航班可按停靠机位与画面中机身朝向的关系核对 → 可进一步确认航班号与航线
- 多段经停的航班序列 → 可据此还原航线走向与沿途起降机场
- 洲际航线两端的时刻分布固定 → 按到达时段与飞行时长可判断飞行方向
- 航拍中飞机朝特定方向飞行且已知天亮时段 → 可界定拍摄时段，进而排查该时段的航班
- 航班号固定则按周期性时刻表执飞 → 可用每日或每周固定班期验证假设
- 某时段内某航司在目标区间仅有一班 → 可用航班号唯一性锁定
- 已知拍摄时刻与机场且飞机处于下降进近阶段 → 可用航班时刻表反查唯一着陆航班
- 小站不太可能作为始发站或停车 → 应选运行方向上游的较大城市作为经停站搜索
- 航线纬度范围与拍摄地纬度比对 → 可排除与画面纬度不符的航班
- 航司在特定枢纽投放的宽体机执飞固定航线 → 结合日落时段航班可缩小候选
- 航班过境时刻与当日日落、天黑时间比对 → 可排除时刻不符的航班
- 航班在某一区域内航向保持一致 → 可由航向推断其航段位置
- 画面出现航机姿态与机身标识 → 结合航班动态与当日天气可锁定具体拍摄日期
- 能识别出航班号或起降时刻 → 可结合航班时刻表反推拍摄时间上下限
- 飞机航向偏向一侧且呈转弯姿态 → 可能为起飞后转向或进近绕飞
- 飞机无明显尾迹 → 排除大推力起飞状态
- 缺乏可靠定向依据时，方位未知 → 无法在对称的两个时刻之间二选一
