## 地形地貌

*山地丘陵平原判断*

- 地形与既有交通线的走向特征 → 可辅助判读，但需其他线索印证，不能单独作为依据
- 河流走向、桥梁位置、两侧山体等宏观地貌关系 → 缩小到区域级
- 三维或地形视图中的山体轮廓与照片中山形一致 → 可确认拍摄位置；轮廓不完全一致时不应直接排除
- 地形图上呈独立、孤立的山体 → 可据此排除与周边山系相连的邻近区域
- 连锁机构品牌加街景覆盖分布加地形环境（高山、雪山） → 可把范围收窄到特定区域内的小城市或县城
- 教堂建于小山包等地形凸起处 → 地形起伏可作定位线索
- 教堂建在山包上 → 建筑与地形的高差关系可作为判读地势的线索
- 山地城市地貌与宽阔水面 → 可辅助判断城市与河流
- 内陆多山地、缺乏人类活动痕迹 → 可排除人口稠密的平原区域
- 大棚、风车等设施出现 → 提示光照充足、地形开阔
- 山坡与平原交界处的阴影走向 → 判断地形走向
- 画面出现雪山与经幡等宗教标识 → 高原文化区
- 目标地非沿海且无群山环抱 → 优先考虑平原城市
- 地面大量风力发电机且地形平坦 → 多位于西部平原或高原地带
- 画面为平原、无山体 → 排除多山城市
- 识图返回的是同类地点的多个候选 → 用航拍沿地形（岸线、山脊）找出能形成对景的机位，再上街景找拐弯路牌核实
- 画面中河水浑浊泛黄、含沙量高，山体多沟壑沟谷 → 指向黄土覆盖的高原丘陵地貌
- 目标区域存在显著的地貌或水体分布特征 → 可据此排除或锁定候选区域
- 画面出现成片梯田 → 拍摄地位于多雨坡地的山地丘陵农业区
- 殿内供奉与露天亭内供奉的造像类型有分工 → 可据造像类型及其朝向推断周边地形与水系
- 画面开阔平坦无明显起伏 → 平原或冲积平原地貌
- 周围山体低缓且植被茂密 → 多见于南方丘陵地区
- 地形地貌、气候、植被、建筑、文字 → 需综合交叉判断地理位置
- 荚状云等特殊云种 → 指示山地背风侧地形与特定气象条件
- 某地貌或物种在目标区域仅零散分布而他处集中分布 → 优先考虑集中分布区
- 楼顶普遍设置储水罐 → 供水不足的高原、山区或岩溶缺水区
- 人物肤色明显偏深、日照强烈 → 高原或西南山地地区
- 大面积湖泊紧邻山地且常见云雾 → 可辅助判断湖山结合地形
- 地形起伏大且植被茂密 → 倾向南方山区
- 房屋附近同时有鱼塘、水田、旱地 → 南方丘陵或盆地乡村景观
- 河面窄、水势不急 → 位于支流中上游，且不在大片平原
- 河面宽阔且地处平原 → 多为干流河段
- 照片中的地貌特征（如黄土塬）→ 可指向特定的地形区，缩小地理范围
- 建筑群后方地势明显升高并出现低矮山体 → 该聚落位于丘陵或山地边缘
- 地名存在多个所指时，须用地貌与地表特征交叉排除 → 剔除与可见山势、土壤矛盾的候选地
- 照片中有明显山体，而候选地位于平原或该方位无山 → 排除该候选，改向有山方位寻找
- 账号内其他视频的整体地貌与风景风格 → 可限定内容所在国家或地区
- 画面无山、视野开阔 → 平原地区
- 河道被山体分段阻塞 → 形成串珠状湖面，指示峡谷地形
- 同组多图可能混用不同视角、不同来源甚至不同地点 → 单张图的地形结论不可推广到整组
- 山体轮廓呈平坦顶部等独特形态 → 属标志性地貌，可据此反推地名或所在区域
- 画面地形与拍摄朝向结合 → 判断拍摄方位及所处地形位置

## 山脉与水体

*山脉走向、河流湖汊*

- 附近存在河流 → 与道路、铁路交叉点结合可快速锁定位置
- 河流宽大且未结冰 → 可排除高纬度寒冷地区
- 河流水量大且不浑浊 → 可排除含沙量高的河流
- 湖泊后方有高层建筑 → 大概率为市区湖泊公园
- 道路与河流走向一致且呈南北向 → 可作为确定照片方位的依据
- 植被类型与河流形态 → 可辅助判断大致气候区与山脉位置
- 河流走向与当地主导风向结合 → 可缩小候选城市范围
- 沿河流寻找与流向平行的桥梁 → 可辅助定位
- 山脉走向与房屋朝向一致 → 可交叉验证南北方向
- 河流宽度量级为数十米 → 中等规模水系，可据此排除大江大河城市
- 最大湖泊所属国与其邻国边界长度可作国家关系线索 → 用于确定国家组合
- 铁路以远超常规的高度跨越河流 → 该线可能为重载铁路且前方有越岭需求
- 河流与铁路、道路均近似垂直交叉 → 多位于平原城市且路网规整
- 铁路、公路与河流三者并行的区段 → 可沿交通干线逐段排查定位
- 识图得到测区航拍后 → 反查水体名称，再用河流名称检索沿线实景
- 狭长城市沿江带状分布 → 拍摄地位于山区河谷
- 近景与远景同时存在大面积水域 → 河流、河口三角洲或大型湖泊
- 天际线上出现特征明显的雪山组合 → 可反推所在城市或山脉
- 连绵山体夹河谷或水库 → 可推断小型山脉中的河谷/水库地貌
- 桥梁大致垂直于河流 → 平行于水流的道路不是过江桥，而是沿江道路或高架
- 画面中有大河与山体 → 可辅助判断南方或沿江沿海城市
- 高压线塔用于跨江 → 附近有大江/江河
- 画面中有高耸高压线塔且邻近工业区 → 可能位于跨江输电地段，常出现在大型江河沿岸工业带
- "和牛轭湖形成原理差不多，都是河流截弯取直" → 水体呈弯月/牛轭状且位于旧河道 → 可能为河流截弯取直形成的牛轭湖. General geomorphology
- 水体呈弯月状且位于旧河道轨迹上 → 考虑河流截弯取直形成的牛轭湖
- 树木种类、河流走向、山体走向、建筑样式等自然与人文景观 → 可推断所在区域
- 列车运行方向结合当地靠左或靠右行车制度 → 可反推画面中山体、河流等的地理方位
- 河流出现急弯 → 可据河道弯曲形态定位
- 河岸有密集住宅区 → 河流流经主城区
- 桥面影与对岸桥梁方位 → 判断河流走向
- 河面宽阔、船只密度高、沙洲少 → 多为大型通航河流或干流河段
- 画面出现家鸭等淡水水禽与岸边草丛 → 多为内陆湖泊或公园水体，而非江、海
- 地物与最近河流的距离 → 可用于缩小地理位置范围
- 河流的宽度规模与周边地形特征 → 可用于判别河流身份及其所在河段
- 画面要素组合为河流加海岸加山脉加高楼 → 用同时具备这些特征的城市作候选筛选

## 海岸与岛屿

*海岸线类型与岛屿*

- 岛屿轮廓与周边海水颜色 → 可区分近大陆岛屿与远离大陆的岛国
- 海水清澈呈浅蓝且岛屿无明显侵蚀 → 多位于远离大陆或水质清澈的海域
- 岛屿度假照片的拍摄地可能只是中转城市 → 不能代表主要目的地

## 土壤与地质

*土壤颜色与岩石类型*

- 典型喀斯特峰丛、溶洞等石灰岩地貌 → 亚热带石灰岩分布区
- 有板房和沙土 → 拍摄时可能处于在建状态
- 画面中出现板房与裸露沙土 → 拍摄地当时可能处于在建状态
- 土壤颜色吻合但山势不吻合 → 该候选地不成立
- 晴朗天气下水体呈蔚蓝 → 高海拔或喀斯特峡谷水体
