# 工业设施判读：火电厂与烟囱

> **旁挂**：`SKILL.md` 是通用「线索 → 结论」规则表；本文补足**电厂/工业厂区**的系统判读。
> 素材来源：豆瓣教程《通过火力发电厂确定拍摄位置》（2025-03）+ 现有 `SKILL.md` 中烟囱/冷却塔规则。

## 一、电厂构成的识别

| 部件 | 形态 | 判读 |
|---|---|---|
| **冷却塔** | 双曲线形（收腰）巨大塔 | 湿冷机组；**数量**是机组数 |
| **烟囱** | 高细柱 | 火电厂；红白相间条纹最常见（航空警示） |
| **半圆形建筑/储煤棚** | 半球或拱顶 | 煤场/封闭煤棚 |

> 「**两座冷却塔 + 一个烟囱 + 半圆形建筑**」是极具体的组合指纹——可在卫星图/抖音直接比对唯一定位。

## 二、判读流程（案例法）

1. **取区域先验**：土色偏黄→黄土高原；结合发布者 IP 省份初筛
2. **看交通**：公路高架上跨铁路呈十字交叉；路牌绿色→高速公路；有路灯+宽车道→大城市周边
3. **锁定电厂**：远处冷却塔数 + 烟囱数 + 附属建筑形态 → 检索「城市名+火力发电厂」
4. **落到机位**：找地面**连续凸起结构**（电缆沟盖板/检修道）→ 说明机位在公路或**铁路上**，非野地；据此在卫星图上沿线路定段，再用 POV 视频核对

## 三、可迁移的一般规则

- 工业烟囱**红白条纹**为主流；**异色涂装**是高辨识度特征
- 烟囱涂装存在**地域差异**；与资料照不符 → 换候选地
- 冷却塔**个数**对应机组数，可区分电厂等级
- 厂区**占地形态**（长条/方形）+ 铁路专用线走向 → 缩小到具体单位
- 大型厂房 + 圆形储料设施 → 厂矿工业区，周边常有**铁路专用线**
- 高压线塔跨江 → 常伴大型江河沿岸工业带

## 提醒

电厂**搬迁/关停/改燃气**常见，老照片的电厂可能已不在——按**拍摄年代**核验，不要用现势数据否定旧照。
