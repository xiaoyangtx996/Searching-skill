# 时空文化溯源

由**聚集场景、穿戴器物、祭仪行为**反推**节日时点 → 再反推地域**，以及由**时段 + 区域**反查当时当地正在发生什么。

> 12 个月双轨日历：`references/全球时空日历.md`。只收可复用方法，不收单题答案。

## 何时加载

画面里出现下列任一情况时加载（否则不必）：
- **人群聚集**：赶摆、巡游、长街宴、朝圣、排队人流、万人空巷
- **节庆行为**：祭祀、泼水、火把、放灯、龙舟、赛马、狂欢变装
- **独占性穿戴/器物**：银饰、头饰、面具、纹身、特定民族服饰、乐器、农具、祭器、应援物
- **要反推时间**：需要判断"这是几月/什么节日/什么节气"
- 已锁定「时段 + 区域」后，要查当时当地是否正有爆火事件（网络热点雷达）


**产出去哪**：推定的日期 / 节日 / 季相 → **必交** `lighting-astronomy/`（`python geo-sleuth/scripts/sun.py pos` 验证光影）+ `region/`（节日习俗定地域）。详见 `docs/技能互联·产出手册.md`。

## 使用方式

输出固定四行（缺一行=未执行本技能）：

```
优先级最高级：1–7
规则摘要：<可见线索> → <时点/文化圈倾向>
追加: 时点 → <季节/月份/节气/节日 + 依据>
档位：倾向 | 跳过 | 本领域无可用规则
```

| 步 | 输入 | 立刻做 | 输出 |
|---|---|---|---|
| 1 | 画面可见项 | 套「7 级优先级」；第 3 级穿戴须先排除租借/演出 | 最高级序号 |
| 2 | 行为/器物 | 查 `references/全球时空日历.md` 对月条目 | 命中条或「无命中」 |
| 3 | 命中条 | 抄倾向；泼水/放灯/面具等多文化行为不独占 | 规则摘要 + 时点 |
| 4 | 时点+区域已齐 | 热点雷达**只解释聚集**；不定点 | 行为动机（可选） |
| 5 | 步骤 2–3 | 交回总技能；交 `lighting-astronomy/` / `region/` | 本领域不报 L3+ |

无命中 → 换领域。条件冲突 → 跳过。只命中 1 条 → 止于倾向，不升格点位。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索命中 | 换领域或加载解题方法论 | 写明本领域无可用规则 |
| 画面是游客租穿戴拍照 | 见下方「反例」，降权处理 | 只输出倾向，不当排他证据 |
| 仅命中1条 | 结论止于倾向区域/时段 | 请用户补图或交叉其它领域 |
| 农历/伊斯兰历节日 | 按当年历法换算，不套固定公历 | 只报"时点区间" |

### 🔴 CHECKPOINT · 🛑 STOP

报城市前须另有独立线索；勿把「多为」写成必然；本领域不单独报 L3+。
**穿戴/器物只是"时点 + 文化圈"证据，必须再有一条地域线索才能定地点。**

## 反例黑名单

| 不要做 | 为什么 | 改做 |
|---|---|---|
| 单规则定城定点 / 脑补未见特征 | 本领域只给时点+文化圈 | 止于倾向；另找地域线索 |
| 租借和服/汉服/演出服当居民身份 | 景区租赁极常见 | 穿戴降权；不当排他证据 |
| 租借面具/道具当民俗真证 | 影视城、主题乐园、万圣节商品 | 只报「道具可能」，不定节 |
| 泼水/放灯/面具/彩粉当唯一节日 | 多文化圈共有 | 只报时点区间；要第二条地域线索 |
| 农历节日名直接当公历日 | 年年公历漂移 | 按当年历法换算，只报区间 |
| 「人多」=「在过节」 | 通勤、旺季、演唱会也人多 | 要独占性穿戴/器物或文字 |
| 用热点新闻印证地点 | 热点只能解释聚集 | 热点写进「行为动机」，不进候选坐标 |

## 7 级优先级（不可违背）

按"能排除多少地方"从上往下。上面一条顶下面二十条。

| 序 | 类别 | 说明 |
|---|---|---|
| 1 | **直接文字线索** | 招牌、路牌、车牌、车身字样、应援条幅——哪怕像素级模糊 |
| 2 | **标志性视觉特征** | 独特建筑、桥梁、雕塑、网红打卡构图、logo |
| 3 | **微观穿戴与手持工具** | 首饰/头饰/面具/纹身/乐器/农具——**具有地域民族国别排他性时是最强证据** |
| 4 | **气象·光影·天象·生态** | 影子朝向、天气状态、能见度、植被花期（详见 `lighting-astronomy/`） |
| 5 | **实时网络热点与文旅趋势** | 热搜事件、短视频爆火打卡点（用于解释聚集，不用于定位） |
| 6 | **人文地理与全球文化民俗** | 通用穿搭厚度、节日通用行为、公共设施风格 |
| 7 | **自然地理特征** | 山脉轮廓、土壤颜色、水体特征 |

**注意第 3 条的位置**：它排在气象和热点之前。一个苗族银饰纹样、一顶特定编织的草帽、
一副傩戏面具，常常比一堆气候推理更直接——但前提是**确认它不是租来的**。

## 微观穿戴闸门（第 3 级必过）

按序打勾；**任一失败 → 穿戴降权，只报倾向，不升点位**。

| # | 检查 | 通过 | 失败 |
|---|---|---|---|
| W1 | 看见什么 | 记下：形制/纹样/首饰/面具/乐器/农具（工艺优先于颜色） | 只见颜色/人多 → 不进第 3 级 |
| W2 | 租借/演出？ | 无景区租赁摊、无写真馆布景、无崭新统一道具感 | 有上述任一项 → 降权，套黄金出货 C 类 |
| W3 | 磨损真证？ | 形制+材质+可见磨损（日常用） | 崭新商品感 → 弱证 |
| W4 | 日历命中？ | 打开 `references/全球时空日历.md`，行为/器物对上当月 ≥1 条 | 无命中 → 换领域或只报「未对上日历」 |
| W5 | 多地共有？ | 非泼水/放灯/面具/彩粉等全球共有行为，或另有地域线索 | 共有行为 → 只报时点区间，不定点 |

搜索词示例（命中后仍要过 W2–W5）：苗族银饰、惠安女服饰、傩戏面具、藏族酥油灯、傣族筒裙、那达慕装束、振袖、纱丽、芦笙。

## 网络热点雷达

**只在第 4 步之后启用**（时段 + 区域都已推出），目的是**解释人为什么聚集**，不是定位。

| 步 | 输入 | 立刻做 | 输出 |
|---|---|---|---|
| H1 | 已推定的时段 + 区域 | 检索词：`<区域> <时段年份> 热搜｜文旅｜打卡` | 候选事件列表（现查，不背旧梗） |
| H2 | 候选事件 | 核：是否解释画面人流/构图；能否**不依赖**热点仍成立位置 | 行为动机一行，或「热点无解释力」 |
| H3 | 任何想用热点升档的冲动 | **🛑 STOP** | 热点不进坐标/L 级；只写解释 |

检索源（任选，取当时快照而非「现在」）：微博热搜、抖音/小红书文旅、Google Trends、当地新闻。  
**红线**：热点只能解释聚集，不能证明位置（见反例黑名单）。

## 输出格式

出货口径以总技能 `SKILL.md` 的 L0–L4 为准。本技能只追加上文四行里的「时点」；需要解释聚集时再加一行：

```
追加: 行为动机 → <聚集/穿戴解释；热点仅解释，不证位置>
```

光影/气候走 `lighting-astronomy/` + `weather-climate/`；落国省走 `region/`；风险见「反例黑名单」。

## 历史时空查询（全历史 allhistory.com）

**用途**：老照片、历史事件、旧地名、往期专题——查"那个年代这个地方叫什么、发生过什么"。

| 入口 | 地址 | 能查什么 |
|---|---|---|
| **时空地图** | https://www.allhistory.com/map | 不同年份的历史地图 + 历史事件/人物在时空上的分布。例：马可·波罗从威尼斯到元大都的海上路线、13 世纪世界地图长什么样 |
| **往期专题** | https://www.allhistory.com/history | 按主题整理的历史专题（比百科更聚焦） |
| 首页 | https://www.allhistory.com/ | 时间线入口 |

### ⚠️ 只作人工查询工具，不脚本化

全历史的 `robots.txt` 明确写着：

```
User-Agent: *
Disallow: /user/usercenter
Disallow: /api
Disallow: /online
```

**`/api` 被禁止抓取**，而时空地图的数据（Mapbox GL + supercluster）**全部通过 `/api` 加载**——
所以**不要写脚本去调它的接口**，也不要试图批量抓历史地图数据。

**合规用法**：把链接给人看，或在浏览器里当工具打开查。跟 `chahaoba` 一样的原则——
站点禁止的接口不碰。

### 什么时候值得查它

| 画面线索 | 查什么 |
|---|---|
| **老照片**（街景年代旧、建筑已拆） | 时空地图该年份 → 看当时地名、边界、周边地物 |
| 历史事件纪念物/雕像/标语 | 往期专题 → 该事件的时空节点 |
| 画面提到**旧地名**（今已改名） | 时空地图 → 旧名对应今地 |
| 文物/器物有明确年代 | 时空地图 → 该年代的疆域与交通路线 |
| 服饰/建筑形制偏近代 | 专题 → 对应时期的文化背景 |

### 与其它技能的分工

| 问题 | 用什么 |
|---|---|
| **影像**哪一年拍的 | `maps-streetview/` 的 Google Earth 历史影像 |
| **那个年代**这里是什么样 | **本节的时空地图** |
| 该地历史沿革、行政区划变迁 | `region/references/<国家>.md` |
| 历史遗存（宗教/建筑）判读 | `culture/` |

**红线**：它是**背景知识**，不是定位证据。用它解释画面，不能用它"证明"位置。
