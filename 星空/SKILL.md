## 南北半球判断

*南十字星只在南半球可见*

- 太阳直射南半球期间东南升西南落 → 结合影子方向可判断秋冬季节的上午拍摄
- 屋顶太阳能集热器朝向 → 北半球朝南、南半球朝北，可用于确定画面方位
- 北半球建筑南侧开大窗、北侧开门或小窗 → 南向为采光面，据此确定朝向
- 北半球民居卫星天线普遍朝南偏东或偏西 → 天线朝向可反推画面南北方向
- 住宅阳台集中朝正南或东南 → 拍摄地位于北半球中低纬度
- 最高气温与出现季节 → 判断南北半球与纬度带
- 照片中公路两侧标线为黄色且中央为白色实线 → 与南半球南部的公路标线规范一致
- 北半球某季节太阳偏西南落下 → 拍摄者位于参照物东北侧
- 某纬度带在南半球为海洋 → 该纬度陆地只能位于北半球；经度时区特征 → 定位到大陆西海岸
- 第一眼快速判读 → 先区分本国与外国、南半球与北半球，再逐步缩小范围
