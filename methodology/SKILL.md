## 使用方式

1. 可见特征匹配规则左侧 2. 抄命中并标倾向 3. 交回总技能互证（本领域不报 L3+）
无命中→换领域；条件冲突→跳过；单规则→不升格点位。
回传行：规则摘要：<线索> → <结论>

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索命中 | 换领域或加载解题方法论 | 写明本领域无可用规则 |
| 规则与季节/半球冲突 | 跳过该条 | 只输出倾向 |
| 仅命中1条 | 结论止于倾向区域 | 请用户补图或交叉其它领域 |

### 🔴 CHECKPOINT · 🛑 STOP

报城市前须另有独立线索；勿把「多为」写成必然；本领域不单独报 L3+。

## 识图流程

*从整体到局部的观察顺序*

- 方法正确而暂未找到目标 → 应在同一思路内继续排查，而非推翻方法
- 一侧密集高楼、另一侧空旷但有路网规划 → 城市新城或新区
- 区域内写字楼占比大且有明显较高建筑 → 更可能是地级市的新区而非县城新区
- 近处围墙样式 → 可能为学校或工厂围墙
- 出现水闸建筑 → 附近可能有小河/水道
- 体育场周边有住宅楼、建筑物、亭子、宾馆等 → 可辅助定位具体场所
- 图中出现某店铺（摩托店）且店址已知 → 可定位到具体区域；购买行为通常就近
- 发布者近期动态显示其所在地 → 可推测照片拍摄城市
- 画面中出现可识别的本地店铺 → 结合店铺地址可定位到具体街区
- 人物在店铺购买物品通常就近 → 可缩小至店铺周边区域
- 画面一侧高楼密集、另一侧空旷但已有路网规划 → 该处通常为城市新城或新区
- 区域内写字楼占比高且存在明显更高建筑 → 更倾向地级市新区而非县城新区
- 近处围墙样式规整且带实体基座 → 可能为学校或工厂围墙
- 出现水闸类建筑 → 附近可能存在小河或人工水道
- 画面中出现成片厂房 → 可判断为工业区或工业园区
- 截图中出现特定交互按钮（如踩） → 可辅助判断该内容所属应用类型或平台
- 体育场周边存在住宅楼、亭子、宾馆等建筑 → 可结合周边地标组合定位具体场所
- 画面中已包含解题所需提示 → 应仅依据画面信息判断，不依赖额外猜测或补充提示
- 已知地标或设施名称 → 可用短视频或图片平台搜索实拍内容比对确认位置
- 任何判读方法都非绝对可靠 → 结论需在多次尝试中反复验证
- 照片画质一般、无后期修饰 → 拍摄者可能并非摄影爱好者，据此可缩小其所属人群
- 非本人拍摄或来源不明的照片 → 可通过拍摄者发布记录或其后续说明获取准确位置
- 屋檐形式、出檐方式等建筑在地性特征 → 可用于判断南北方
- 画面中无法确认的敏感区域被刻意模糊 → 判读时不应依赖该区域的信息
- 成片高层建筑且非住宅用途 → 多为商务中心区，通常只出现在首都或核心经济城市
- 高层建筑的数量与层数 → 可反映城市经济等级，发达国家仅少数核心城市具备
- 铁路车辆的型号与制式 → 可锁定所属铁路系统，进而锁定国家或区域
- 画面中人物姿态僵硬、缺乏动态 → 可能是雕像而非真人
- 特殊造型的桥梁或构筑物 → 常为某城市独有，可据此锁定城市
- 区域名称泛指多个城市 → 优先从该区域的省会或核心城市入手，资料与地标最丰富
- 与同类历史题目一致的特征 → 优先套用常规定位手段，而非特殊方法
- 检索关键词优先选择辨识度高、数量少的对象 → 能更快锁定位置
- 参照他人解题思路时注明来源 → 属于解题记录规范，不构成定位线索
- 仅凭驾驶室位置判断车辆行驶方向 → 结论存在误差，因多国允许不同舵位车辆并存
- 判断车辆靠哪侧行驶 → 应依据该国法定行驶方向，而非驾驶室位置
- 依赖单一数据库查询车辆或设备配属 → 数据可能未更新，只能得到粗略范围
- 数据源未覆盖目标信息 → 该思路应暂时放弃，改用其他途径
- 照片出自同一部已知作品 → 可复用该作品已确认的取景区域
- 画面中已确认的标志性建筑 → 可反查拍摄点所在的周边位置

## 推理链构建

*多线索串联逼近答案*

- 由机型推断的航司机队基地与机场规模线索冲突 → 说明推理链存在错误
- 铁路沿线与公路沿线的可达性与景观不同 → 可由沿途景观推断所采用的交通方式
- 画面中关键目标过小或模糊无法辨识 → 应放弃该线索，转而寻找其他可用线索
- 画面中同时出现的其他飞机或车辆可能只是同场景的无关目标 → 不能直接当作主体线索使用
- 飞机以不合常理的低高度贴近居民楼 → 疑似后期合成，该线索应剔除
- 相邻登机口共用远机位摆渡车且从同侧舷窗拍摄 → 可推断邻机所在停机位的相对方位
- 剩余里程数与沿途县级市方位 → 可推断下一个可能的目的地
- 在原图出处平台找到发布者或评论者的自述 → 可能直接暴露地点线索
- 图像过糊且缺乏高区分度线索 → 逐省排查成本过高，应先找独特性地物
- 航拍视角的飞行方向结合建筑朝向 → 推断方位
- 判读目标为准确位置且追求速度 → 优先锁定区分度最高的线索
- 区域内建筑样式高度一致 → 建筑本身不能作区分线索
- 多个相互独立的线索均指向同一城市 → 提高该城市为答案的置信度
- 远处高层建筑上的银行标志 → 大型银行高层网点多为市级分行，可作为城市级线索
- 企业名称 → 可推断业务范围与服务地域，进而缩小搜索区域
- 同一省内不同区域车道数存在差异 → 车道数可作为区域筛选线索
- 多张关联照片中单张信息量少 → 先搁置，结合其余照片线索综合判断
- 车辆带涉水喉、车顶造型与后视镜样式 → 可作为判别车辆所属国别的线索
- 画面存在明显后期处理痕迹 → 不代表其余内容不可信，篡改本身是有人刻意隐藏定位线索的信号
- 票价牌或投币箱显示票价水平 → 票价有地域差异，可作为辅助线索，不能单独定位
- 蝶式或围合式楼盘的阳台分布 → 可推断户型的主朝向，进而推得方位
- 日照强烈程度在同一国家内部存在南北差异 → 可作为区分区域的弱线索，准确率有限
- 多线索排除后剩余少量候选城市 → 用正向太阳位置计算收敛
- 多条同类照片集中于同一地区 → 可据发布历史推断拍摄活动范围
- 铁路与公路走向大致一致 → 可据走向推断拍摄方位
- 工业铁路专用线连接矿区与水运节点 → 可推断区域工业运输走廊及早期铁路区位
- 图中出现某国法规或文化导致的特有设施 → 可作为判定国别的硬线索
- 得出初步推断 → 用另一平台交叉验证后再定论
- 已识到的原图无法定位或原址已消失 → 保留该结果作为风格、来源线索，回溯拍摄者其他作品
- 画面特征鲜明 → 直接局部识图；特征不鲜明 → 转为寻找细节线索并推理
- 对全国范围逐城市盲扫 → 效率低，应先依据线索判断大致区域再逐点核查
- 相似视频内容标签与地点无关 → 需区分内容主题与地理线索
- 搜索结果长期偏离目标 → 说明检索词或特征选取不当, 需更换线索
- 相似图片堆中可能无有效线索 → 需准备替代定位方案
- 画面中的设施虽有特色但同质化严重 → 不能仅凭该设施定位，需结合其他线索
- 关键词搜索结果持续偏离目标 → 应更换线索或回到图像特征重新检索
- 相似图片堆中没有任何有效线索 → 需准备替代定位方案，避免空耗
- 逐项罗列画面可辨元素并标注确定程度 → 形成线索清单后逐条排查
- 相邻日期照片显示云量变化 → 可推断前一日天气趋势并修正单图天气误判
- 建筑风格、时间、天气等场景要素 → 均可用作综合定位线索
- 综合一般信息与特化信息 → 提高定位置信度
- 多类独立线索同时吻合 → 比单一线索更可靠
- 照片中出现多个可识别地物 → 每个地物都应作为独立线索交叉验证
- 屋面瓦片种类、颜色与装饰构件 → 随地方风俗变化，可作地域线索
- 图片经社交平台保存后元数据不可见 → 不能依赖EXIF定位，只能靠画面线索
- 发帖人近期活动轨迹 → 可推断照片拍摄城市
- 画面包含可读新闻标题或事件信息 → 可直接检索新闻确定地点，无需依赖地理线索推理
- 识别出常见公共设施标志但同类设施数量多 → 仅能缩小到城市或区域，需结合其他线索定位
- 建筑装饰颜色与某机构标识主色一致 → 可关联该机构类型；若颜色常见，则需其他线索佐证
- 单一判据不足以确证地点 → 需用多线索交叉比对（对比法）后才能定论
- 从画面线索推断出地区产业类型 → 在对应的产业强县或行业集聚区名单中筛选可联想到的名称，逐一验证
- 账号内容偏好（游戏、动漫、交友、自拍等）→ 可推断拍摄者所属的网络圈层与常驻活动范围
- 线索不足、候选过多时 → 仅在推理末期对已缩小的小范围做穷举排查，避免全程暴力遍历
- 旅行与实地经验积累的城市印象 → 可作为快速判据，但需其他线索佐证
- 同一来源的历史照片 → 可推断拍摄者常驻区域，缩小搜索范围
- 画面中被刻意涂抹的部分 → 未被处理而保留的信息才是有意留下的线索
- 老城区建筑、夜间路边停车 → 车辆多为本地居民所有，缺乏其他线索时可优先按车牌归属地推断
- 同一画面内不同主体色调、比例不统一 → 合成痕迹，相关元素均不可作为定位线索
- "我的入手点: 1、斑马线与停止线之间有块区域，不同常规" → 斑马线与停止线之间的间距/区域异常 → 可能反映当地交通标线规范或特殊路口设计，作为定位线索. General
- 徽记图案与常规配色具有唯一性 → 可作为跨照片识别同一机构的稳定线索
- 人行横道颜色、长宽比例、标线组合存在地区差异 → 可作为区分城市或区域的线索
- 历史人物、城市旧名、流行文化角色与成语等多源线索交叉 → 可用于推断目标城市
- 个人公开行程或聊天中暴露的旅行轨迹 → 可作为照片地点推断的辅助先验
- 单一强线索可能是误导 → 需与其他线索交叉验证
- 某地区或某类景观在题源中高频出现 → 只反映题源采样偏好，不能推断其在现实中的分布频率，仅可在无其他线索时作统计先验
- 罕见设施样式易被误认为熟悉区域 → 单一样式线索需与其他线索交叉验证
- 红绿灯的位置、与路口的夹角及遮光罩安装方向 → 可推断其控制的具体车流方向与所在路口
- 视频画面中若可见列车经过 → 可作为定位比对的稳定线索
- 列车铭牌站名字数 → 可推断列车运行区段
- 已成功定位一个点位 → 其周边同类地物可作为迁移线索，缩小邻近目标搜索范围
- 周边建筑的高度与形态 → 可推断城市内部的具体片区
- 多条相互独立的线索指向同一地点 → 提升定位结论的置信度
- 灯色承担非通行含义（如指示停车位） → 属地方性交规细节，可作定位线索
- 推断出的路口与路面标线相符 → 作为定位的验证条件
- 画面中存在多种交通设施线索 → 逐一排除制式不符的地区
- 多张照片出自同一设备 → 推断为同一用户在同一城市或同一行程拍摄，据此缩小检索范围
- 存在同一作者的其他照片 → 用其中已确定或已推断的拍摄城市作为同源线索
- 宏观区域、半球等易判别线索 → 优先用于第一轮筛选，不急于定位到具体点位

## 排除法

*由反面特征排除区域*

- 多条线索中仅有一条为假 → 用逐一假设与排除法验证其余线索
- 出发地惯用的路线走向 → 可排除不符合该走向的目的地方向
- 跨线桥名牌存在固定命名格式 → 格式不符即排除
- 画面中高楼密集而居民楼密度低 → 可判断为省会级城市，并结合建筑风格排除大区
- 前景建筑偏古典、背景建筑偏现代且混搭不协调 → 排除建筑风格通常统一的区域，指向风格混杂的区域
- 共享单车车筐颜色与该城市普遍配置不符 → 削弱或排除该城市
- 小城市院校建筑通常不超过五六层且具校园形制 → 层数过高或风格不符时排除学校
- 相邻国家的车辆特征需对比排除 → 避免误判国别
- 沿岸地带基本都有密集人类活动 → 可将无人居住的沿海区域排除
- 二至日太阳直射点极值 → 对应日出日落时刻的极端值，可用于排除法
- 无山体背景的平坦聚落 → 可排除山地城市
- 目标国为内陆国家 → 排除所有沿海国家
- 目标地位于该国最南端 → 排除该国中北部
- 字符编码转换结果无意义 → 应排除该编码或分组假设，而非强行解释
- 列尾等非常规视角出现概率低 → 可作为辅助排除条件
- 逐一否定候选答案后重新核查 → 用排除法收敛到唯一解
- 已知大致区域与拍摄日期 → 可用当日天气实况排除天气与画面不符的地点
- 当日天气实况（晴、阴、雨）→ 可排除或锁定候选城市
- 城市平均海拔不足300米且历史极端高温超过36℃ → 不能据此排除沿海低海拔城市
- 已知候选日期/地点时，查历史天气与照片天气比对 → 排除不符合项
- 将照片中天气与历史天气记录比对 → 可验证或排除拍摄日期与地点
- 当某特征在城内分布不均且自身信息不足时 → 优先从不熟悉的辖区开始排查，把已知区域排除
- 将照片中的多处细节与候选地逐项比对 → 若普遍不符即可整体排除该候选地
- 区域内从未出现照片中的某特征 → 可作为排除该区域的依据
- 城市环卫设施有统一配色 → 其配色与图中不符时可排除该城市
- 出现候选地罕见的海中延伸山体或林地 → 可排除该地
- 高杆灯灯头数量明显多于常见规格 → 灯头数量属地域性制式，可作为排除或定位依据
- 某型车辆不跨境运营 → 可据此排除相邻国家或地区
- 排除与相邻行政区交界的区域后剩余片区才符合特征 → 用排除法逐步缩小范围
- 设施图片可能来自厂商宣传图或网图 → 需先排除网图，避免误判
- 题图常为人工压缩处理 → 画质下降是常态，不能因细节缺失排除合理地点
- 凌晨时段仍灯火通明 → 排除居民区与旅游区
- 依据目标船型或渔具在各地的保有量分布 → 可排除保有量低的区域，缩小搜索范围
- 同类标志性设施存在多处 → 用独特结构细节逐一排除，避免误选相似替代物
- 候选城市之间按周边建筑风格逐一比对 → 依次排除风格不符者
- 多个候选城市存在同类设施 → 用细节差异（形状细节、边缘有无条纹）逐个排除
- 厂区一侧为湿地公园等不可建设用地 → 排除该侧存在厂房，将方向限定在可建设一侧

## 建模与枚举

*建立候选集合逐一验证*

- 飞机飞行高度很低且周边有特征植被或建筑 → 附近必有机场，可用植被或屋顶颜色在候选中筛选
- 机场紧邻山体且规模较大 → 可在该地形与气候组合下筛选候选城市
- 纬度范围与机场等级（如E类）→ 可作为硬性筛选条件快速排除候选
- 新机型或单一运营商机型的运行机场范围有限 → 可作为候选机场的筛选条件
- 航班执行有固定班期 → 可用拍摄日期与班期匹配来筛选候选航班
- 路侧环境特征（路面宽度、路边设施、沿途小路）可区分道路等级 → 可用于判断路线类型并缩小范围
- 图片检索出现多个同样匹配的候选 → 该特征不具唯一性，不能单独作为判据
- 厂房棚屋的建筑风格对应特定工业区类型 → 可结合个人对某区域建筑的熟悉度辅助缩小范围
- 多条线路共用同一始发站 → 用共同站点缩小范围
- 山脉走向以某一方向为主 → 出现罕见走向的山脊段属于稀缺特征，可用于缩小范围
- 确定候选城市后，在银行分行周边寻找画面中的地标 → 可锁定拍摄点
- 用 OSM 查询工具批量提取某类设施 → 按设施数量、连续性与排列方式筛选候选点
- 已知品牌英文名 → 可在卫星/地图中搜索品牌网点，缩小范围
- 连锁商业品牌门店 → 搜索品牌在城市中的分店，结合方位筛选候选位置
- 成片出现的水塔等市政设施 → 在多个候选区域内普遍存在，无法用于缩小范围
- 加油站门前铺设地砖等少见铺装 → 铺装类型与当地常见做法不符时，应质疑候选地点
- 题字或碑文可辨认但模糊 → 记录后与候选地资料逐一比对确认
- 用房产平台按城市+关键词检索小区名 → 列出候选小区逐一比对
- 按候选区域逐城扫街 → 记录已排查区域可缩小剩余范围
- 公交站名的命名规律（行政级别前缀式、专有名词式） → 反映城市命名习惯，可推断城市或缩小范围
- 已知大致区域时，可用连锁门店逐点排除缩小范围 → 收敛速度取决于门店密度
- 斑马线采用少见配色和框线样式 → 可作为特定城市或区域的道路标线特征，搜索同类样式可缩小范围
- 照片中有校服配色、花坛样式、护栏等非公交元素 → 这些城市家具或人群特征有地域性，可与公交线索组合缩小范围
- 目标国国庆月已知 → 可作为国家筛选条件
- 目标地所在国与邻国有战争史 → 可作为国家层筛选特征
- 目标地是著名文化人物故乡 → 可用人物籍贯收敛候选地
- 道路通名与走向存在地域性命名习惯 → 可据路牌通名或方位词判断道路走向并缩小范围
- 公交车辆所属运营公司一般不在异地运营 → 可由车辆标识推断运营城市，再由线路首末站缩小范围
- 地面或高架地铁的分布城市有限 → 可枚举候选城市
- 城市建筑规模与密度 → 可判断城市等级，进而收窄候选城市
- 区域特征与城市等级交叉约束 → 可把范围压到少数候选城
- 目标为常见形制的构筑物（石墙、护栏、桥栏） → 识图会返回大量同款，需结合IP属地、材质与植被缩小范围
- 画面中出现有轨电车 → 运营该制式的城市数量有限，可大幅缩小候选范围
- 网络图注给出多个互相矛盾的候选地区 → 应以原始拍摄者或原始元数据为准
- 多个独立细节（标识牌、栅栏、石碑、摄像头等）与候选地点全部吻合 → 可确认定位
- 桥墩形状在同一城市内有分布规律，主体为一种、个别形状集中于特定路段 → 可据此缩小范围
- 红绿灯附带小数字屏 → 属少见配置，可用于筛选
- 多个候选地点均需与照片中同时出现的天气特征吻合 → 才能锁定地点
- 先按经营特征（评价高低、开业新旧）缩小商业店铺候选 → 再与照片中的设施比对确认
- 附属涂层等次级特征可增强关联 → 但证据不足时只能列为候选
- 元数据缺失时 → 定位结论依赖画面经验逐步缩小范围，主观性强、误差大
- 同一发帖者/系列题目常在同一城市或区域 → 可先按同城假设缩小范围
- 从已知地标（机场）反推周边轨道交通与道路网络 → 可逐步缩小范围
- 9 道路左转位置与公交站门口重合 → 可据转弯点和站点门口关系缩小范围
- 照片中出现建筑或商业设施名称 → 检索名称得到候选区域，但结果会偏向检索者所在地，需加限定词或换平台复核
- 某地常见的自然灾害类型 → 可与画面中的天气、植被、建筑损毁特征互证，缩小范围
- 历史照片集中出现在某一城市 → 优先在该城市及周边排查，作为候选范围
- 住宅密集、商业配套稀少的城区 → 城市居住片区，可缩小范围
- 横向安装的红绿灯较少见 → 可作为稀有特征缩小范围
- 放大识别远处地标 → 结合其周边环境特征缩小范围
- 用公交档案类数据库按外观比对车型 → 得到候选车型，再以涂装与运营线路交叉匹配缩小范围
- 某线索检索结果过多 → 不等于该线索错误，应加限定条件缩小范围而非直接排除
