## 中国车牌

*蓝/黄/绿/白牌含义与字母规则*

- 车牌前缀 → 推断车辆注册地，缩小区域
- 车牌简称与格式 → 判定车辆注册地
- 车牌上的地区简称字符 → 直接提示车辆注册省份
- 车辆号牌颜色与文字系统具有国别特征 → 可用于判定国家
- 画面中的车辆牌照 → 车牌可被套用或异地使用，不能单独作为地区判断依据
- 车牌归属地 → 可确定城市或省份范围
- 车牌仅保留一位且其余被遮挡 → 大概率是误导项，应舍弃
- 画面中多辆车牌省份占比 → 出现频率最高的车牌省份可作为首选区域
- 黄色车牌结合左行交通 → 指向特定非洲国家
- 存在外地参展、维保、跨省运营等情形 → 车牌属地不等于拍摄地，应用前先排除这类例外
- 车牌号可能与本地方车辆体系不符 → 不可单独依据车牌判断拍摄地
- 可辨认车牌省份简称和字母 → 可锁定省份及地级市，是最强定位线索之一
- 本地代步车辆的车牌属地 → 通常与拍摄地一致，可作为省市定位线索
- 车牌的字符数量与位置排列格式 → 可判断发牌地区
- 电动车牌照样式不统一 → 表明处于不同行政区域或不同登记时期
- 电动车牌的颜色与样式 → 判断所属省份或城市
- 车辆号牌上的汉字与字母编码 → 对应城市及其下属区县
- 车牌限行/牌照前缀 → 可判断城市或区域
- 限行标识上的车牌前缀 → 可识别城市/区域
- 同一省份的商用车辆一般不跨省使用 → 车牌归属地具备定位参考价值
- 公开平台上未做遮挡的车牌应视为干扰信息 → 不能单独作为定位依据
- 某些地区的车牌在全国各地都常见 → 该类车牌归属地不能作为定位线索
- 车牌归属地不等于拍摄地 → 应转向路灯样式、路面设施等不可移动的固定要素
- 车牌与路边文字标识均可能被刻意设置 → 需独立验证，不可只凭其一
- 画面中多辆车牌一致同属一地 → 可判断该地即拍摄地，并据此排除外地车辆干扰
- 某种颜色或制式的车牌并非某地专有 → 单凭车牌颜色不能定位
- 出现旧版或字母数字自定义的车牌格式 → 可提示当地存在特定时期的号牌规则，作为地区或时间线索
- 欧洲车牌左侧有蓝条，北美车牌更短更窄 → 可据号牌形态判断所在大洲或国家
- 车主的长期居住地与车牌注册地可能不一致 → 车牌归属地不能等同于照片拍摄地
- 黑底白字车牌可依据底色把号牌切成的白色区块数量区分国家（左右两块与左中右三块分属不同国家）→ 区块结构比文字更易在遮挡下判读
- 画面中仅有一两辆外地车牌不足以判断 → 多辆车牌一致时才能确定拍摄地
- 某国车辆与城市整体呈单一色调，易造成误判 → 以车牌制式为准，不采用整车或城市颜色作为依据
- 出租车车牌的注册地通常与所在城市一致 → 出租车车牌可作为拍摄地的强线索
- 同一画面中多辆车牌归属地一致 → 该地即拍摄地的概率上升，但需排除巧合
- 画面中大量相同归属地的车牌 → 可交叉印证拍摄地
- 街边文字被打码或缺失时 → 需转向车牌、基础设施、自然景观等其他线索
- 车牌颜色与车辆类型、当地新能源政策相关 → 可辅助判断地区
- 车牌能通过网络检索到唯一对应车辆 → 为真实牌照，可反查注册地；检索不到则可能为伪造或道具
- 营运车辆（重卡、长途客车）的牌照归属地 → 与行驶地无强关联，不可作定位依据
- 外来务工人口流入多的城市 → 外地车牌常见，不能据车牌判定拍摄地
- 车辆注册地与实际行驶地受人口流动影响 → 车牌仅代表注册地，需结合其他线索
- 相邻地区之间车辆流动常见 → 车牌地可能与拍摄地相邻而非相同
- 影视作品中的车辆多为道具车 → 其车牌不可作为定位依据
- 共享单车颜色、电动车牌照等细节 → 可能是干扰项，需谨慎对待
- 熟悉某地车牌的字母与格式 → 可快速识别车牌归属地
- 多种线索（车牌、文字、基础设施、景观）指向同一地区 → 结论可靠
- 车牌首字为省级简称加地市字母 → 可直接锁定车辆注册地市
- 车牌样式与某地区公开号牌样本高度相似时，可推断车辆注册地为该地区 → 由此定位照片拍摄地所属行政区
- 号牌杂乱程度高说明车流来源分散 → 拍摄地更可能是大城市、景区或交通要道，而非本地车辆为主的乡镇
- 车牌只能辨认个别字符、省份字模糊 → 车牌不作为定位依据，改用固定设施特征
