## 动物识别

*野生动物与鸟类识别*

- 公路两侧为白线、中央为双黄线的路面标线 → 阿根廷
- 公路标线全部为白色的场景 → 阿根廷
- 车辆停放在无车位线的非机动车区域 → 商业步行区或景区周边
- 网络上高频出现的同款地标可能是异地仿建 → 不能作为唯一定位依据
- 门店周边的相邻商家组合 → 用于验证定位结果
- 仅凭同属一个大洲或大区域 → 不能作为定位依据
- 画面中有特定动物或展示设施 → 反查目标区域内动物园及公开视频比对
- 画面中出现校徽、机构徽记等符号 → 可用于识别学校或机构，进而结合机构分布缩小定位范围
- 斑马线与停止线之间出现非常规间距或区域 → 可能反映当地交通标线规范或特殊路口设计
- 同一设计者或出题者的题目风格 → 可作为新题来源与地域偏好的先验
- 建筑内部隔断形式与靠墙关系 → 可辅助判断房间类型与建筑布局
- 交通标线颜色与宽窄比例不符合常见规范 → 可能指向特定地区或特殊路段
- 同名地点或作品名称出现 → 不能直接判定实际取景地，需区分命名来源与实体地点
- 运动物体受光面明亮侧朝向拍摄者 → 拍摄者面向太阳相反方向，可推断物体运动方向
- 同一设施类型在不同地区存在外形相近但配色不同的版本 → 仅凭外形不判定，须结合配色与运营区域
- 设施外观存在多个区域变体时 → 逐项记录配色、过渡段形状、附加结构，用细节差异反推区域
- 知名度低的取景画面 → 先定位主要场景，再逐帧比对边角细节地物
- 田间作物处于某一生育阶段 → 结合农事历与积温条件反推月份并限定南北范围
- 区域风格只能给出城市级假设 → 需再用标志性设施（摩天轮、塔、桥）验证
- 同一地点的不同角度照片 → 需靠共同结构细节确认，而非整体轮廓

## 农作物

*作物类型判断农业区*

- 有人家处伴生竹林、柑橘类果树多 → 南方乡村聚落特征
- 山地附近加蒙古包加果树 → 西北地区常见组合，只能缩小到大区域，难以精确定位
