## 车型与涂装

*动车组/机车/货车车型识别*

- 列车座椅固定朝向行驶方向 → 乘客面向的方位即列车行驶方向
- 站场规模极大 → 多为省会级或首府级城市
- 客场布置形式常见于编组站或客货共用站 → 该布置少见于纯客运站
- 列车为重要干线上的重联高速动车组 → 车次为G字头，运行于高速铁路
- 车次以G开头 → 高速铁路；以D开头 → 动车组线路
- 高架线路使用特定形式护栏 → 该线路为动车组线路
- 列车运行图每日基本固定 → 可按时刻表反推拍摄车次与所在位置
- 跨线车次多数停靠某站 → 该站为线路重要节点，可优先排查
- 仿古建筑形制非传统且用支撑柱而非脚手架 → 属现代仿古建筑
- 铁路相对并行公路的方位 → 可反推列车行驶方向与地理朝向
- 水体靠桥一侧水浅且生草 → 为静水湖库而非流动河道
- 四周无城市建筑且跨水域 → 为城郊或乡野区段
- 车站两端均设信号机 → 为动车组车站
- 列车刚出站即出现信号机 → 该信号机可能为进站信号机
- 桥跨比相邻跨度明显更大 → 为跨河或跨水域桥段
- 特定涂装或颜色的动车组 → 可锁定其配属的少数铁路局或区域
- 停靠车辆为城际型动车组 → 该站位于城际线路
- 航拍中出现圆形环状轨道 → 多为机车掉头线，附近必有铁路
- 地面出现大型厂房与圆形储料设施 → 厂矿工业区，周边常伴铁路专用线
- 画面主体与标签类别不符 → 应按画面主体重新判定场景类型
- 车次号呈连续四段 → 为同一对列车的上下行双向编号
- 已知某开发商楼盘多沿铁路修建 → 可沿铁路线逐一排查
- 沿线人行道宽窄差异明显 → 可区分同城不同路段
- 动车组车窗窗框形状存在型号差异 → 可据窗框类型判定车型
- 同一批次或多张相邻照片 → 拍摄城市可能相同或邻近，可作先验
- 普速列车多在到站时检票，动车组除始发外提前数分钟检票 → 可据检票时间差判断列车类型
- 大跨度拱桥附近出现高处悬挂的馈线 → 多为铁路牵引供电馈线，该桥为铁路桥
- 江面宽阔且两岸为建成区 → 位于大城市
- 公铁两用桥数量稀少 → 出现该类桥可大幅缩小搜索范围
- 桥梁上允许行人与非机动车通行 → 距市区较近
- 物流园位于铁路一侧 → 可作方位参照物
- 动车组车体编号含车型与车组序号 → 可据此识别车型与配属信息
- 夜间列车交替使用相邻编号站台 → 单凭站台号不能确定车次，需结合运行图与晚点状态
- 铁路按左侧行车且照片可判断列车前进方向 → 可辅助判断列车运行方向及起讫方向
- 动车组车体型号可识别 → 可辅助判断线路等级为高铁，但重联编组常见，不能唯一确定车站
- 动力配置与固定编组方式 → 可辅助判断列车制式
- 列车一般不异地过夜 → 出现地应靠近配属局或检修点，可缩小省份范围
- 外观相近的动车组 → 需结合最高速度、线路等级或运用区域区分，不能仅凭外形定位
- 动车组车体编号通常包含车型与车组序号 → 可用于识别车型及配属信息
- 动车组配属区域只能提示运营范围 → 不能覆盖站名文字等直接证据，站名文字优先级更高
- 有砟且轨面偏红黑 → 多指向普速或老线
- 周边地标天际线、POV比对 → 定位相邻站
- 配属信息误导风险 → 车辆信息不能单独定位，站名优先
- 高铁车辆型号说明高铁 → 但重联常见
- 动车组速度与线路等级 → 外观相似需速度区分
- 动车组编号含车型序号 → 识别车型
- 同一时段内某方向仅有少数车站有车次停靠 → 可用列车时刻表的时间窗反推拍摄站点
- 同一车次在不同日期或区段可能更换牵引机车 → 机车外观不能唯一确定车次
- 电线与电杆的分布形态 → 可辅助判断城区与郊区
- 车厢内部的标准配置在各局之间相同 → 无区分度，不能用于确定车次
- 站台编号与列车运行方向存在固定对应关系 → 可据站台号排除方向不符的车次
- 车次显示屏上的终到站集合与车次号段 → 可判断所属铁路局并缩小车站范围
- 桥梁为斜拉索桥且跨越铁路货运站 → 可用桥型与铁路设施组合关键词检索定位
- 机车车辆编号中带有配属段信息 → 可推断列车所属铁路局及运行区域
- 机车牵引交路相对固定且较少套跑 → 可由车型或编号推断常见运行区段
- 某些动车组型号集中配属高寒地区 → 出现该车型可优先考虑寒冷气候区域
- 两条高铁并行区段较少 → 可作为定位约束条件
- 站台编号、拍摄时间与时刻表 → 可推断车次及运行方向
- 正线分离、线间距明显变化的路段 → 多为支线、联络线或低速段
- 某一站台编号区间无高铁动车停靠 → 该区域为普速场或其他场，可据此缩小车次范围
- 车辆动力类型（如CNG或纯电）在不同城市普及度不同 → 可作地域判据
- 同一方向车次通常固定使用相近站台 → 可由站台号反推行车方向与线路归属
- 某站所有客车均必停 → 可作为判断车次路径的锚点
- 车次停站表可反推运行路径 → 与图面设施比对可定位线路
- 图中出现的车次若均始发同一城市 → 可反推拍摄地在该城市
- 圆端形空心墩，墩身粗高、上窄下宽 → 高速铁路
- 清水混凝土等材质 → 不能单独作为高铁判据
- 车辆外观高度统一 → 多为共享车辆
- 列车起讫站随时间变动 → 历史车次信息不能直接套用现行运行图
- 应急逃生标识 → 附近可能有大型空地或公共场所
- 无明显标志性地标 → 应从路网结构、建筑风格、铁路走向入手
- 轨道车辆为动车组 → 不能据此直接判定为高速铁路，地铁也可为动车组
- 提示中出现"因某产业而兴"类表述 → 判断该地该产业规模大、地位重要
- 排队人群的视线朝向 → 其所望目标建筑位于该方向
- 室内空间过高、灯具与陈设不合车厢特征 → 判断实际为室内场所而非车内
- 列车不停站通过某站 → 其下一站为前方邻站
- 路面出现两侧通行标志 → 判断该处开始分道行驶
- 单线采用简支梁 → 判断为另一条铁路的分离正线
- 图上缺少时间与股道信息 → 无法推断具体车次
- 车辆外部环境、内部车灯与涂装特征 → 判断车型与涂装；非车次号 → 可直接检索车组
- 铁路机车配属不出路局 → 可据机车判断所属铁路局范围
- 微型货车、货运面包车一般在本地使用 → 可通过其车牌推测所在区域
- 画面中反复出现同款黑色车头 → 指向阿根廷
- 站台上人群朝轨道同一侧聚集 → 列车即将进站或刚刚出站，结合车次时刻可推断拍摄时间与站台
- 用列车时刻与线路走向交叉比对 → 可筛出符合的车次，再由"下一站"确定行驶方向
- 桥面车辆靠右或靠左行驶 → 可判断所在国家或地区的通行方向
- 能查到某型车的制造厂 → 可优先在工厂周边排查制高点与特征建筑
- 车次等级与画面中的车底型号、涂装不匹配 → 应考虑通勤、工程、回送等非营业列车
- 缺少拍摄时间 → 车次只能给出候选集合，需其他线索进一步收窄
- 站名以市辖区名称命名 → 该站位于该市辖区，可先查主城之外的辖区
- 画面中的摩天轮等大型地标 → 可作为唯一性标识，与建筑细部一起比对定位
- 方向牌上终点站字数等表面特征 → 不足以单独排除车次，应双向核对以免误删
- 建筑密度与形态 → 可判断所处为市区、城乡结合部或乡镇
- 社交账号头像、文案与所传内容不一致 → 判断该视频为转载，需回溯原始发布者
- 已知车次运行区间与光照时段 → 可定位到具体站点区间（这有点具体但通用形式：列车铭牌/车次 + 光照时段 → 缩小到运行区间）
- 已知车次运行区段与光照时段 → 可缩小到具体运行区间或站点

## 车站建筑

*站房规模判断车站等级*

- 停机坪上出现飞碟形广场灯 → 拍摄点位于机场停机坪区域
- 火车站站台为 2 台 4 线 → 多为县级及以下车站
- 大型车站候车室的体型与邻近水塔等构筑物 → 可用于识别车站并推断城市
- 车站出站时间与列车时刻表比对 → 可反推所停靠的车站
- 路名中出现特定语种的街道、广场、林荫道等后缀词 → 可判定国家与语区
- 站台上出现迎新接待点 → 车站邻近高校，拍摄时段多为开学季
- 某站台上多列车始发站集中于同一区域 → 拍摄车站位于该区域
- 多股道并行且均为正线 → 位于大型枢纽站或省会级车站附近
- 车站位于城区且线路外观老旧 → 多为利用既有线设施的老站或老运用所，而非新建站
- 普速与高铁共站且普速场位于高速场一侧 → 可据股道数与相对方位定位车站
- 始发与终到站名均为两字 → 可缩小车站筛选范围
- 车站名直接以城市名命名 → 站址多位于老城区
- 多张照片按拍摄时间排列且其中一站已知 → 相邻未知站可被约束为已知站前后的候选站
- 结合车站站场规模与线路特征 → 可缩小车站候选范围
- 共线车站轨道位于两侧、站台位于中间且前进方向左侧开门 → 站台视觉上更宽，可作为特殊站台布置线索
- 乘客集中朝同一方向乘车 → 该站可能为换乘站或地面/高架站，可结合线路车站类型清单排除
- 利用同线路POV视频比对相邻站外观 → 可确定具体车站
- 车站引导屏为蓝底 → 多见于高铁站；红字LED屏 → 多见于普速站，可辅助判断车站类型
- 站台宽度异常且轨道分居两侧 → 可能是共线车站的特殊布置
- 信息屏颜色和字体样式 → 可区分车站等级/线路类型
- 站内实拍与目标车站站内照片比对 → 可确认车站
- 建筑物细节（站房形制、雨棚、装修）→ 车站识别的主要依据
- 画面中多张图分别属于不同车站 → 不能按同一地点串联线索
- 轨道旁信号机与邻近建筑特征 → 可判断列车刚驶离车站，沿线寻找该站
- 照片中出现高杆灯且周边空旷 → 可能为站前广场或城市广场
- 高架站台护栏具地方特色 → 可作为较新建高架车站的辨识特征
- 老式车站布局且检票口与股道无对应 → 无法由检票口推断停靠股道
- 车站雨棚等结构造型独特 → 可作唯一性标识，直接定位该建筑
- 列车在该站停车时长明显偏长 → 车站等级较高
- 双线铁路并行且一侧为高速、一侧为普速 → 可推断位于车站附近或特定区段
- 车站雨棚结构老旧且形制特征鲜明 → 该线路为较早开通的客运专线
- 站台数量与线路数 → 可推断车站规模等级
- 车站建筑形式、站场规模布局、车型等特化信息 → 可用于铁路场景的精细定位
- 画面中出现高架轨道或高架车站 → 不一定是地铁，也可能是轻轨、城际或铁路
- 地铁系统最早出现于19世纪中后期 → 早期开通地铁的城市可能保留更老的车站或隧道形制
- 车站外观很新且设施未启用 → 可能为新建或未开通车站，应检索近期开通或在建线路
- 可见终点站与列车当前位置关系 → 可推断前方或后方车站
- 人物或报纸造型的雕像 → 常见于步行街、广场等公共开放空间
- 能辨认出车辆型号 → 可锁定该型号的运用线路范围，再缩小到该线路沿线车站的集合
- 沿线车站数量有限时 → 用已知条件逐一排除不吻合车站，以剩余站为候选
- 车站站台与股道数 → 可由各接入线路的既有规模叠加推算，用于校验站场规模
- 站前道路带弧度且邻近河流 → 可判断画面正对的是车站哪一侧广场
- 站前广场的柱子样式、地下通道出入口数量 → 可用于与候选车站逐一比对确认
- 带铭文、浮雕的铺装广场 → 多为文化馆、博物馆、纪念馆一类公共文化建筑前场地

## 雨棚与站台

*无柱/有柱雨棚判断线路与路局*

- 站台背后商铺类型集中 → 可推断街区商业性质，辅助确定具体点位
- 站台与车道形式符合快速公交特征 → 该城市设有快速公交系统
- 站台雨棚形制 → 可推车站建成年代
- 站台上有乘客下车长时间停留 → 该站停站时间较长，非短停站
- 某种站台形式在多地普遍存在 → 不能作为城市定位依据
- 同一站台停靠车厢总数不同的两列车且车型相同 → 该站具备长短编组混停条件
- 站台为高架形式 → 该线路为高架敷设，可排除地下或地面站
- 快速公交与普通公交共用站台 → 该快速公交并非全封闭专用道
- 同方向列车集中停靠同一侧站台且编号呈奇偶分侧 → 可辅助判断列车上下行方向
- 线路走向与地标建筑平行或垂直关系 → 可判断站台朝向和拍摄方位
- 乘客集中上行且站台形式特殊 → 可能为换乘站或地面/高架站
- 列车停靠下行站台编号多为奇数 → 可辅助判断运行方向
- 车体处于无火回送等非运营状态 → 通常不停靠客运站台，可排除高铁站台
- 站台形制普遍、同质化程度高 → 单独不能定位，需配合其他线索
- 站台布局、雨棚样式与站名牌组合特征 → 可用于识别具体车站
- 站台编号位于线路一侧 → 可辅助判断列车上下行方向
- 站台柱后出现卷帘门 → 判断为地面或半地下站台形式
- 无柱雨棚 → 车站等级高、规模大
- 有柱雨棚 → 中小型车站，所属城市规模一般不大
- 站房建筑年代与站台雨棚改造年代明显不一致 → 老站后期翻新
- 站台雨棚为平顶无柱、横梁用工字钢 → 属采用标准化钢构雨棚的高标准车站
- 同一站一侧为无柱雨棚、对面为有柱雨棚 → 该站为线路交汇或站场扩建形成的接算站
- 雨棚结构组合（无柱与有柱、混合柱并存）→ 可排查线路交汇城市及新建、扩建车站
- 站台长度明显超出雨棚覆盖长度 → 属特定线路的典型站型，可缩小线路与车站范围
- 站台雨棚样式与站台规模（站台数、到发线数）组合 → 可唯一匹配到具体车站
- 车站为无柱雨棚且接触网不属高铁标准形式 → 该线路为市域铁路或城际铁路
- 电动车普遍加装雨棚 → 可能为管理较宽松的中小城市/三线及以下
- 接触网硬横跨跨越对侧站台雨棚 → 车站站台与线路规模较大
- 某线路全程地下 → 照片若显示地面或高架站台，可排除该线路
- 建筑带明显门厅、雨棚与机关式围墙 → 办公楼或单位楼，而非居民楼
- 确定为某车次后 → 可调取两端车站的站台视频比对站台、雨棚等特征，确认拍摄位置

## 接触网与股道

*电气化、股道数目判断线路*

- 用航班实际到港时间与拍摄时间区间比对 → 已提前到港的航班可先行排除
- 轨道交通高架线路的涂装颜色对应其线路标识色 → 可用涂装颜色识别线路
- 地铁标识 → 确定城市；线路专属颜色 → 确定轨道线路
- 相邻站点或店名信息 → 判断拍摄区间
- 把画面线索与当地月均气温比对 → 可排除不符合的月份，把时间缩到具体月份区间
- 轨道线路编号 → 可由车辆外观识别
- 牌匾或大门题字辨出小区名 → 可在房产交易平台按名称或价格区间反查位置
- 轨道交通高架段集中分布 → 提示城市外围或新城方向
- 已知某航班在机场的常规停留时段 → 可据此推断拍摄时间区间
- 铁路接触网样式 → 可用于判别铁路系统及其所在地区
- 有砟或无砟轨道及轨道标准 → 可推线路等级与设计速度
- 交通信号灯是否附带路名牌、待行区指示灯等附属设施 → 可作为城市或区域特征
- 轨道交通车辆的涂装与车型具有线路专属特征 → 可直接识别线路，无需读取文字
- 轨道形式与车辆类型（有轨电车、地铁、轻轨） → 可判断城市交通系统类型
- 到发线使用宽枕轨道 → 大型客运站的到发线
- 已知列车终点站方位且线路不绕行 → 可由线路走向推断所在区间
- 仿古塔邻近游乐设施轨道 → 该塔位于主题乐园内
- 信号灯位于列车右侧 → 列车逆向行驶（与常规左侧设灯相反）
- 普速股道为三线及以上 → 该段货运繁忙，多为干线
- 接触网腕臂采用少见结构样式 → 可作为识别特定线路或区段的辅助线索
- 常见且无地域差异的桥梁接触网支柱布置 → 不具线路识别性，不能单独用于定位
- 有砟道床颜色偏深且道砟明显 → 多见于普速或老线；无砟道床整洁偏白 → 多见于高铁或新建线路
- 高架站造型结合周边高楼天际线 → 可辅助识别城市轨道交通系统与具体线路
- 单看轨道难以判断高铁、普速或城轨 → 需综合道床、接触网、车辆、站台等特征
- 轨道结构带无砟且接触网杆型标准化 → 多指向高铁或新建线路
- T梁接触网支柱常见布置不具识别性 → 不能定位
- 普通铁路与高铁道砟差异 → 区分线路等级
- 接触网杆的间距与车头跨越两杆的耗时 → 可估算车速，进而判断在区间中段还是接近车站
- 高架轨道交通采用一体化接触网支柱而非分离式 → 可指向少数特定线路或城市
- 国内多数高架地铁接触网支柱为分离式 → 出现一体化支柱可作为区分线路的线索
- 接触网立柱在两条并行铁路靠近后消失 → 线路已换侧，两条正线发生分离，该段设计速度较低，多为支线或联络线
- 交通信号灯为圆饼灯且中间显示倒计时、非机动车道与人行道合设 → 可辅助判断城市道路断面设计
- 轨道旁有道砟石子 → 判断为普速有砟轨道
- 某区间存在非电气化线路 → 该区间需内燃牵引、可一机直达
- 桥的上下两层均设有接触网 → 判断为双层铁路桥
- 已知乘坐站数与起终城市 → 反推乘车区间与上下车地点
- 接触网与轨道结构复杂 → 位于车站范围内
- 钢轨或轨枕上的印刷字样 → 对应线路名称
- 铁路接触网承力索与接触线间距很小、腕臂极少见 → 采用防台风设计，位于台风影响区
- 市区信号灯有统一朝向或形式 → 图中信号灯形式与之不符时，应转向该市下辖县市排查
- 出租车涂装、人行信号灯杆、监控杆及附属箱体 → 可作辅助判据，但仅凭特有印象不能作为确证
- 交通标志的常规布设位置可反推周边设施 → 如车辆掉头标志多设于信号灯路口前，提示前方有交叉口
- 同一设施沿路重复密排（如连续多个信号灯、路灯）→ 阵列密度与排布可用于判断道路等级与所在区域
- 信号灯尺寸与出租车涂装等道路设施具有地域性 → 可辅助判断城市
- 路口的形态、信号灯样式与路幅具有地域性 → 结合地铁站可缩小城市或环路范围
- 轨道穿楼等独特景观存在多个同类地点 → 不能仅凭搜索中最常见的案例定位，需排查其他同类地点
- 已知拍摄时间且有专列或加开列车时刻表 → 可推算列车当时运行位置，缩小拍摄区间
- 使用广义轨道交通概念筛选城市 → 范围过大且区分度低；应改用具体制式与线路特征排除
- 已知某线路多个相邻站为地上站 → 照片若显示地上站，可将候选站缩小到该线路地上站区间
- 利用同线路POV视频逐帧比对 → 可验证区间与站点
- 桥隧过渡、跨河桥梁 → 可锁定线路特定区间
- 区分不同轨道系统（如S线/U线/地铁/通勤铁路） → 按对应系统图扫描
- 轨道末端是否有下降趋势 → 可判断是否接近地下区间、终点站或车辆段
- 画面中列车与公路之间有轨道或没有轨道 → 可判断公路车流方向及是否与列车相向而行
- 接触网悬挂样式 → 可判断所属路网或国家，缩小到制式相同的范围
- 接触网布置与股道数量 → 可判断站场规模，候选站中规模明显不符者排除
- 已知线路某区间因施工调整运营 → 可据此限定拍摄日期范围
- 桥体可见铆钉 → 钢结构桥梁，常见于轨道交通桥
- 已知列车运行区段与画面光照时段 → 可缩小到具体线路区间或站点
- 路口信号灯为大型立柱式 → 提示道路等级与地区设施习惯
- 轨道与护栏之间的空隙位置 → 判断列车行驶方向及线路所在侧
- 车辆与厢式货车等大型车的相对位置关系 → 推断车辆是在站内还是在排队等信号灯，指向交叉路口
- 信号灯的样式与放行相位（如仅放行单一转向、无直行） → 反映道路形态与当地通行规则
- 城市轨道接触网支柱形制与画面不符 → 排除采用该制式的城市

## 线路与路局

*干线走向与铁路局管辖*

- 某些机场因空域或航路限制，实际航迹会偏离两地直线 → 不能用起降两点的直线路径推断飞机所在位置
- 校园跑道颜色、建筑风格与所在地地铁线路数量 → 可作为校区身份特征用于排除候选
- 线路处于重新涂装阶段（如灰色底漆）时颜色失真 → 此时不可用颜色判断线路归属
- 蓝色指路牌且可掉头可左右转、无高速分隔设施 → 判定为枢纽型路口
- 公交专用道运行时段与本地区常规不同 → 可查时段列表反查城市与具体线路
- 大型公交枢纽常紧邻高铁站或轨道交通线路 → 以枢纽与轨道设施的组合特征缩小到具体位置
- 停车场规模大但车辆稀少 → 说明枢纽交通尚不成熟，可缩小到新建枢纽
- 线路具有专线、通勤、校区等特殊属性 → 可反映客流规模与服务范围，据此缩小城市与线路范围
- 已知某线路早已更换车型 → 与该车型不符的推断应予排除，车辆换代信息可用于证伪
- 车身侧面印有运营方名称 → 直接指向运营公司与所属线路
- 同一站点多条线路车辆涂装统一 → 属同一运营商或同一城市涂装体系，但无法据此区分具体线路
- 车型级别（车长、载客量） → 对应线路客流等级，可缩小线路范围进而定位城市
- 公交线路编号位数与所属公司存在对应规则 → 可用于核验城市与运营主体
- 公交车保有量大且配置线路多的车型 → 不能作为唯一定位依据，只能用于缩小到使用该车型的多个城市/运营方
- 旧POV视频中的线路信息 → 时效性差，不能作为当前线路定位的主要依据
- 公交线路编号有特定字母前缀且车型为支线用车 → 线路编码和车型层级有地域规则，可查当地公交资料确认运营区域
- 有轨电车等交通工具的型号 → 可缩小其运营城市或线路范围
- 站名与线路站点逐一对比 → 可最终锁定城市与具体位置
- 站场规模明显大于普通中间站且非纯高铁站 → 该站为多条线路接轨的枢纽
- 干线高铁不同区段限速不同 → 可由车底配置与线路等级推断车次等级
- 线路设施不规范且与厂区相连 → 企业自建专用线
- 两座高铁接轨并互为计费站 → 该站为枢纽站
- 拍摄者会标注列车信息的前方展望视频 → 可用于比对沿线景物确认线路
- 地铁线路出现地面段 → 位于高架与地下的过渡区段
- 同一区域车型高度集中于某一型号及其亚型 → 该地属于同时配属该型号各亚型的路局
- 周边设施为新建客专或动车所 → 线路应较新，出现老旧设施可直接排除
- 高铁线路旁南北侧出现高速收费站 → 可据出入口方位缩小路段范围
- 桥旁紧邻铁路复线 → 线路并行密度高，可作定位特征
- 特定车型配属路局及检修保障能力 → 可推断该车型常见运营区域
- 铁路按管理主体分为国家铁路、地方铁路、专用铁路 → 可结合标识、线路形态和服务对象判断铁路性质
- 换乘站各线路编号之和及换乘方式（同台/出站） → 可辅助锁定具体换乘站及城市
- 历史工矿运输线路的走向与港口/水路关系 → 可辅助判断沿线城镇与铁路建设背景
- 仅凭铁轨外观无法判断线路类型 → 需综合多特征
- 大量电动车集中停放 → 该站多为线路终点站或通勤枢纽
- 公交线路的走向与沿线是否有高架 → 可排除或锁定拍摄路段
- 同一线路多数动车组配属同一铁路局 → 可由车型配属缩小拍摄地区
- 护栏样式与接触网立柱特征 → 可用于匹配具体高铁线路
- 某附属设施仅见于长隧道 → 可反推隧道长度与线路等级
- 线路固定采用某种编组（如固定8节） → 可反映线路类型与客流等级
- 列车涂装颜色存在地区与线路差异 → 可作城市或线路线索
- 特定形状的箱梁常用于特定线路等级 → 可缩小线路范围
- 列车涂装 → 可辅助判断担当路局或运用区段
- 可辨认的车辆品牌 → 通过车辆数据库反查所属线路与场站
- 画面中有特殊涂装车辆或特殊车型 → 车与线路常唯一对应，可由车型线路反推城市，再沿线路寻找目标建筑
- 降雪后轨面无车辙痕迹 → 该线路车流稀少，多为支线
- 房屋朝向与铁路走向一致 → 可反推线路走向
- 列车车型与配属关系 → 可推断所属铁路局/运行区域
- 连续多站站名含同一通名 → 多属同一城市同一条线路，通名反映当地命名习惯
- 一条线路连续多站均为换乘站 → 该线路走向穿过城市核心区
- 地铁标牌上标注线路编号 → 可据编号反查城市与线路
- 线路编号在多座城市重复使用 → 仅凭编号不能确定城市，需结合其他线索
- 不同城市与线路的站牌配色、字体与排版不同 → 站牌样式是识别线路与城市的依据
- 郊区地铁线路普遍高架、市中心地铁口普遍简易 → 可用于判断拍摄点处于城市中心/郊区
- 主题涂装列车有固定配属线路和发车交路 → 可据此锁定运营线路，并排除不按该交路始发的方向
- 高架下方出现全封闭式隔音屏 → 通常提示附近有地铁地上段，且存在与高架交叉的地铁线路
- 站内吊板无任何文字 → 可能为废弃或未开通线路
- 候选城市不存在照片中的线路组合或换乘关系 → 可排除该候选城市
- 地名或水体名称出现强地域性用字 → 可优先锁定该用字流行区域，再比对同走向线路
- 已知某城市地铁地上段线路很少 → 照片若为地上地铁，可优先排查少数有地上段的线路
- 轨交工程停工或烂尾 → 可能因资金中断或未获审批，应按废弃或未完工项目检索，而非按运营线路定位
- 换乘站结构类型罕见 → 可排除常见该结构的城市，缩小到少数城市或线路
- 公交线路编号+起终点站牌 → 可锁定城市公交线路，进而定位站点周边
- 线路代码/编号系统 → 可用于识别运营者和线路归属
- 先定位离地标最近的目标线路站点 → 再沿线路扫图比对
- 车厢内装/座椅/扶手色带 → 具有线路专属配色，可用于识别线路
- 若已知某城市多条线路配色规则 → 可据色带排除其他线路
- 高架地铁+隔音板 → 可辅助识别特定线路或区段
- 站间延伸方向与已知线路走向 → 可推断相邻站点
- 6 公交线路编号与起终点站名同时可见 → 可锁定具体公交线路并定位其沿线站点
- 主岛周边附属小岛的名称、数量与旅游线路组合 → 可用于判断海岛区域
- 车身铭牌上的车辆型号与线路牌信息 → 可用于查询运营地区并定位客运站，但加油站等遍布性设施排查效率极低
- 某线路不运行画面中的车型或涂装 → 可排除该线路归属
- 已知两条线路存在与公路并行的区段 → 优先在这些并行区段中排查
- 线索中出现"直达某地" → 优先从连接两地的对应线路排查
- 由车型与编组可确定车辆 → 结合该线路近期施工或运营调整公告可反推拍摄时间窗口
- 候选车型的涂装颜色与某线路车辆一致 → 该线路可作为首选验证对象
- 与目标车辆同框的其他车辆车型 → 可用于比对确定其主营线路，辅助锁定行驶范围
- 同一画面中多种地区号牌混杂 → 该地可能为外来车辆聚集的城市或交通枢纽
- 车辆号牌归属地 → 所属运营车队，进而获得固定运营线路
- 同城多条线路共用相似设施 → 先按细微差异锁定线路，再沿线逐站比对

## 桥梁与隧道

*高铁桥型、隧道口特征*

- 城市地铁的地上高架段 → 多分布在中心城区之外
- 高架桥下机位 → 多为环线或进出城快速路
- 高架桥墩形式与路灯样式 → 具有城市与路段特征，可缩小到具体高架线路
- 居高临下的拍摄视角 → 推测位于天桥或高架
