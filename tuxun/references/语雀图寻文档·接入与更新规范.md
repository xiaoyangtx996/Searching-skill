## 3. 更新协议（每次涉及图寻都要做）

### 步骤 1：检查本地是否过期

```bash
python tuxun/tuxun_fetch.py status        # 看缓存与篇数
```

### 步骤 2：拉目录树（拿最新文档清单）

用 Hermes 浏览器打开 `https://www.yuque.com/chaofun/tuxun`，执行：

```js
JSON.stringify(window.appData.book.toc.map(x=>({type:x.type,title:x.title,url:x.url||'',level:x.level})))
```

→ 存 `tuxun/.tuxun_cache/toc.json`（按标题的 DOC 条目即 262 篇）。

### 步骤 3：拉需要的正文

打开 `https://www.yuque.com/chaofun/tuxun/<slug>`，读 **`document.body.innerText`**（语雀正文已渲染在 DOM；`appData.doc.body_asl` 为空是正常的，别指望它）。

> ⚠️ 语雀 **API 需授权**（`/api/v2/repos/...` 返回 401），**不要走 API**；走页面渲染文本。
> ⚠️ 正文页是 JS 渲染，必须等页面加载完（`wait_for_load` + sleep 3–5s）再读。

### 步骤 4：和本地技能对照

- **世界层**：语雀 Plonk It 更新 → 反映到 `region/references/world/<国>.md`
- **中国层**：语雀「精选篇目/寻友教程」更新 → 反映到 `region/references/china/<省>.md`
- **规则层**：若某条规则与语雀最新版冲突 → **以语雀为准**（本地是快照）

### 步骤 5：更新标记

`tuxun/.tuxun_cache/meta.json` 记 `fetched_at`。超过 1 个月未更新 → 判读前重拉。
