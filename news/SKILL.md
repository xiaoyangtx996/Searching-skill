时事与赛事活动线索


## 何时加载

照片中出现 新闻热点 相关元素、需要据此推断地点时加载本技能。

## 使用方式

1. 可见特征匹配规则左侧 2. 抄命中并标倾向 3. 交回总技能互证（本领域不报 L3+）
无命中→换领域；条件冲突→跳过；单规则→不升格点位。
回传行：规则摘要：<线索> → <结论>

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索命中 | 换领域或加载解题方法论 | 写明本领域无可用规则 |
| 规则与季节/半球冲突 | 跳过该条 | 只输出倾向 |
| 仅命中1条 | 结论止于倾向区域 | 请用户补图或交叉其它领域 |

### 🔴 CHECKPOINT · 🛑 STOP

报城市前须另有独立线索；勿把「多为」写成必然；本领域不单独报 L3+。

## 时事线索

*新闻事件定位地点*

- 同类型、同进度的重大工程且新闻热度相近 → 极易与同类工程混淆
- 罕见或极端天气 → 可检索当日新闻确定发生地
- 题图来源为视频截图或网络随手图 → 元数据不可靠，不能依赖 EXIF 或原始分辨率
- 画面中默认属于某常见国家或地区的先验 → 主动检查边界、飞地、海外领土和例外地物
- 提示只在固定整点发布 → 非整点出现的补充信息不应当作官方提示
- 出题图库有限且常被复用 → 同一图源、同一拍摄点或相似构图可能重复出现
- 视频截图通常不作为正式题源 → 视频截图的地理信息可能不完整或经过二次编码，判读价值较低
- 默认拍摄地属于某一常见国家或地区 → 会漏判边界、飞地、海外领土及例外地物，需主动检查画面边缘与反常目标
- 提示只在固定整点给出 → 非整点出现的补充信息不应视为官方提示
- 画面边缘出现与先验区域不符的物体 → 先验范围可能错误，边缘目标应纳入判断

## 赛事与活动 · 工具

- **马拉松赛事库** — https://www.athletics.org.cn/

## 赛事与活动

*马拉松等大型活动定位*

- 行人活动/灯光状态 → 辅助判断天黑或天亮
- 发布者近期动态显示其活动城市 → 可推测其自拍照片的拍摄城市
- 人群年龄结构与着装异于日常 → 推测为展会、漫展等特定聚集活动
- 出题时机和主题随机 → 不能根据日期、活动类型预测拍摄区域
- 出题时机与主题随机 → 不能按日期、活动类型或往期规律预测拍摄区域
- 横幅上带年份的活动名称加主办方名称 → 可检索主办方公众号或宣传推文反查拍摄地点，活动名称越具体越易命中
- 同一城市不同辖区的管理措施与时序存在差异 → 画面中日常活动是否正常进行可辅助判断所在辖区
- 评论区文本 → 可补充人物行程或活动地点的信息
- 官方主页中的赛事与活动名称，结合地形关键词 → 判定具体赛段
- 赛事全程录像中稳定出现的可见标记物 → 反推拍摄位置
