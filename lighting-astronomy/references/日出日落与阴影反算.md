## 一、日出日落反算经纬度

**原理**：日出/日落时刻由**纬度**（季节）+ **经度**（时区/地方时）共同决定。
已知拍摄时间 + 画面有日出/日落 → 可反推经纬度范围。

### 工具

| 工具 | 链接 | 用法 |
|---|---|---|
| **日出日落时刻查询** | https://richurimo.bmcx.com/ | 按**省份**或**经纬度**查日出日落时间 |
| SunCalc | https://www.suncalc.org/ | 影长/位置/时间互算，可视化 |
| Sun Earth Tools | https://www.sunearthtools.com/ | 太阳位置与方位 |
| 本地 | `py geo-sleuth/scripts/sun.py pos --at lat,lon --time ... --tz ...` | 算太阳方位/高度角/影长比 |
| 本地 | `py geo-sleuth/scripts/sun.py locate ...` | 反算全球亮带 |
| 本地 | `lighting-astronomy/ShadowFinder-main/` | 全球亮带图（见其 Colab / README） |

### 用法范式

```
① 从画面读出：日出/日落时刻（或相对位置，如"太阳刚出地平线"）
② 结合照片拍摄时间（EXIF 或用户提供）
③ 用 richurimo 或 sun.py 反推：哪些经纬度在这个时刻恰逢日出/日落
④ 结果是一段**带状区域**（同纬度不同经度会有差异）→ 交区域层收敛
```

> 🔴 走 `docs/技能互联·产出手册.md` 的**主闭环**：光影给出可量化值 → `sun.py locate` → 区域层 → `board.py`。

## 二、阴影长度反算时间（航班案例核心技术）

**原文案例**：破解飞机下方山脉位置（厦门航空 B-5280）。核心是用**垂尾在机翼上的投影**算阴影长度。

### 完整推断链（可复用）

| 步 | 操作 | 结论 |
|---|---|---|
| 1 | Flightradar24 搜飞机注册号 `B-5280` | 厦门航空波音 737-75C |
| 2 | 查历史班次（可下载表格） | 拿到过去 1 年所有航班 |
| 3 | 山脉地貌 + 积雪 | **中国北方，冬季** → 滤掉南方/非冬季航班 |
| 4 | 山脉**影子朝南** → 判断飞机**由南向北**飞 | 滤掉航向不符的 |
| 5 | **用影子长度估算当时时间** | 见下 |
| 6 | 海拔/时间/航线交叉 | 锁定 MF8692、西安市蓝田县蓝桥镇、下方为秦岭 ✅ |

### 阴影长度怎么算

**场景**：飞机右翼上有一道影子——那是**垂直尾翼顶端的投影**。

**几何关系**（构成直角三角形）：
```
垂尾投影顶点 ────────┐
      │              │
      │ 直角         │ 垂尾实际高度 H
      │              │
垂尾本体顶点 ─────────┘
      └── 影长 L ────┘
```

| 量 | 值 | 来源 |
|---|---|---|
| 垂尾顶端距机翼高度 **H** | 9.5 m | 查波音 737-700 侧面视图 |
| 影子长度 **L** | 15.6 m | 画面测量 + 勾股定理（用已知机身尺寸做比例尺） |

**关键**：一定要**先找一张该机型的尺寸图**定比例尺，才能把像素换算成米。

### 代入 SunCalc

```
H = 9.5 m，L = 15.6 m
→ tan(太阳高度角) = H / L = 0.609
→ 太阳高度角 ≈ 31.3°
→ 代入 SunCalc，结合日期/航向 → 得到可能的时间范围
→ 滤掉该时段不在执飞的航班 → 范围大幅收窄
```

> **本地等效**：`py geo-sleuth/scripts/sun.py pos` 可直接算「给定地点+时间」的高度角，
> 反向用 `sun.py locate` 由高度角反算亮带。

## 三、通用解题范式（从航班案例抽象）

```
已知 3 个中任 2 个 → 推第 3 个：
   ① 拍摄时间
   ② 拍摄位置
   ③ 航班/班次信息
```

| 已知 | 可推 | 工具 |
|---|---|---|
| 位置 + 时间 | 航班号 | Flightradar24 历史航班 |
| 时间 + 航班号 | 位置（飞机当时在哪） | Flightradar24 轨迹 |
| 位置 + 航班号 | 拍摄时间 | 轨迹时刻表 |

**配套工具**：
- Flightradar24 https://www.flightradar24.com/
- FlightAware https://zh.flightaware.com/
- VariFlight https://map.variflight.com/（实时/历史航线）

## 四、执行要求

1. **高度角算出来就必须走闭环**（`sun.py locate` → 区域层 → `board.py`），不许停在"大概是上午"
2. **比例尺必须先定**：没有参考物尺寸，阴影长度无从换算
3. **证据分级**：太阳几何计算 = **A 级**（物理约束）；目测阴影 = C 级
4. 半球/季节先判，判错则结论完全反转

---

## 五、局限

- 阴影测量**误差大**：透视畸变、参考物边界不清都会放大误差
- 太阳高度角**只给纬度带**，不给经度；必须靠其他线索定经度
- 航班轨迹**依赖 ADS-B 覆盖**，部分地区/年代数据缺失
- 日出日落**受地形遮挡影响**：山区实际看到日出晚于天文日出
