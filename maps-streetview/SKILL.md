## 卫星影像

*高分辨率卫星图，看地形地貌与建筑*

- 卫星影像更新周期长（约一至两年） → 涉及短期变化的线索应以卫星图为稳定依据
- 冷却塔是发电厂的典型构筑物 → 可在卫星图上搜索电厂并分块排查候选区域
- 双向多车道且带辅路、非高速 → 一般为城市快速路
- 铁路与道路垂直相交在卫星图上特征明显 → 可作为地图定位锚点
- 精美立体的鸟瞰图多为规划效果图 → 效果图与卫星实景差异大，不能与卫星影像直接对应
- 卫星影像中水体出现明显颜色分界线 → 常见于河流入海处，因海域影像分辨率低而呈现色差
- 南北方建筑风格差异显著 → 可据建筑风格区分南北
- 轨道交通地面或高架段的隔音设施形态（隔音板与顶棚）因线路而异 → 可用卫星图比较沿线设施区分线路
- 街景覆盖不可用或缺失 → 改用卫星图比较细节排除
- 图源类型题库的更新滞后于实际影像更新 → 不能完全依赖既有题库与教程，需自行核对
- 多数建筑受采光需求影响呈坐北朝南 → 可据此推断影像方位
- 整幅影像发生旋转时 → 坐北朝南规律失效，且小角度旋转难以肉眼识别
- 由房屋朝向推断远处山脉走向 → 再在卫星图上按该走向就近搜索山脉
- 高楼密度高但明显不处市中心 → 符合经济开发区特征
- 目标区域缺乏街景覆盖 → 改用航拍图或全景影像逐一对位
- 借助路灯、建筑、树木等固定地物在多源影像中比对 → 确认具体位置
- 造型独特、形似已知器物的建筑 → 图像检索可锁定城市
- 大面积雪地且为俯视视角 → 可与卫星影像直接对照定位
- 地物在地图上查不到 → 考虑影像时效落后或平台覆盖缺失
- 卫星影像结合村落级小地名 → 可把定位精度推到村级
- 街景影像年代偏旧 → 目标建筑可能已改造，旧影像不匹配不能否定位置
- 无街景覆盖区域 → 用卫星图上的建筑颜色、体量与排列特征锁定范围
- 商业标识的版本与配色差异 → 推断影像拍摄年代
- 卫星图上屋顶形式的变化 → 判断建筑是否经过改造，避免用旧影像下结论
- 多源信息互相矛盾 → 暂标未解，等待更强证据再定论
- 成片住宅的朝向规律 → 可反推画面的方位与拍摄方向
- 街景影像通常偏旧而网络视频较新 → 涉及现状时优先用视频比对
- 同一关键词的检索结果分布 → 结果集中地可提示目标所在地
- 独特性地物周边相邻的其他地物 → 交叉比对确认位置
- 目标周围只有农田等均质、无特征地物 → 难以定位
- 由光线方向判断拍摄朝向 → 反推画面中目标物相对路口的方位
- 街景影像时效不足时 → 改用网络视频等其他影像源交叉验证
- 卫星图与照片中水体轮廓、建筑布局一致 → 即使个别要素（如桥梁）缺失也可确认位置
- 地标建筑周边建筑的高度与遮挡关系 → 判断拍摄方位，矮房侧为拍摄视野方向
- 配电箱等设施的类型与分布随建筑密度变化 → 据此判断城区或郊区
- 建筑风格的新旧与类型 → 判断城市中新老城区的范围
- 车辆内无驾驶员、积雪厚度或受光存在差异 → 判断为停车状态，可能位于首末站
- 街景影像年份陈旧 → 画面中的地物可能与现状地图不符，二者不一致不构成排除依据
- 同一景区内批量建造的亭、桥等构件样式雷同 → 此类构件不能用于区分具体位置，需依赖其他参照物
- 共享单车等有区域投放特征的交通工具出现在画面中 → 可据此判断城市或城区范围
- 村落形态为典型院落式 → 可用于判断大区域范围
- 卫星图中出现明显的河流分叉形态 → 可据此比对锁定河段
- 街景影像过旧 → 可用搜索引擎的图片结果交叉印证
- 目标区域范围过大时 → 卫星影像逐块排查成本过高，应先用地物线索压缩范围
- 某地区街景影像年份普遍偏早且长期无更新 → 当地新建桥梁、道路、建筑不会出现在街景中，须用卫星影像交叉核对
- 画面中商铺尚未装修、尚未开业 → 可作该影像拍摄时间的下界
- 行人普遍穿着厚外套 → 处于深秋、冬季或初春
- 画面中出现大型储水罐、水箱 → 气候干旱缺水的地区
- 同类设施存在红白、黄黑等多种配色混用 → 不能凭单个样本推定该国统一配色规律
- 卫星图上的标线、箭头、信号灯、监控杆、电线杆、高压电塔 → 与街景画面可一一对应，可交叉验证
- 屋顶颜色鲜明且成排排列的建筑 → 可在卫星图上作为匹配特征定位
- 极高密度的密集楼群 → 多为城市核心商圈或老城中心
- 宽阔多车道主路且带下穿通道 → 多为地级市以上的主干道
- 主干道名称反复出现规律性词汇 → 可辅助判断城市规模与类型
- 街景影像年份过旧、与现状完全对不上 → 单靠街景难以定位，需换用其他影像源
- 卫星影像上出现异常色块 → 可能是地面反光物质或影像制作错误，未必是真实地物
- 影像平台标注的“最新”时间 → 不一定是实际最新，需核对多时相影像
- 画面特征稀少且无文字时 → 用短视频平台的航拍素材与卫星图多源交叉匹配，逐步逼近拍摄角度
- 候选品牌与卫星图周边建筑不符 → 排除该候选
- 高速路机位 → 多位于城市外围
- 卫星图中方形广场与运动场并存 → 多为学校或体育中心
- 卫星图中厂房密集且路灯样式吻合 → 支持县域工业园区的判断
- 卫星图上被打码的区域 → 多为敏感设施，不能作为定位依据
- 无明显独特线索 → 按行政区域逐块排查卫星图
- 卫星图中地点间的距离 → 以地图实测距离为准，不用口述出行习惯推断
- 连锁商场品牌结合航拍图检索 → 先筛出候选城市，再用街景确认
- 卫星图与线路示意图对同一线状设施的表示方式不同 → 可互相参照推断实际配置
- 不同地图平台的影像常相互引用同一图源 → 同一地区多平台影像可能完全相同，判断时效应比对影像日期而非平台名称
- 影像更新更快的平台用于核对现状，更新慢的平台用于回溯地物历史 → 两平台影像差异可反推拍摄时间区间
- 街景覆盖通常止于干道与区域外围，内部街巷常无覆盖 → 目标位于内部巷弄时需改用建筑特征、卫星影像或地物推断
- 少见的路面标线样式具有地区专属性 → 可用于缩小区域范围
- 某平台在目标区域无街景覆盖 → 不能据此排除该地点，需换用其他平台或卫星影像验证
- 官方街景影像存在拍摄年份上限与更新滞后 → 画面中在建工地、未完工地物可用于估计影像年份
- 以画面中已知典型尺寸的物体为参照 → 可推算未知物体的实际尺寸或限高规格
- 卫星影像中的围挡、楼栋角度与相对位置同照片一致 → 可确认拍摄点位
- 边境或偏远地区的聚落即便在卫星影像上也难以辨认 → 判读时不宜假设其不存在，需谨慎排查
- 卫星图分辨率不足时道路标线颜色失真 → 不可用标线颜色判断道路等级或车道数
- 单一候选点与照片高度吻合 → 仍需卫星图或街景实拍佐证才能定案
- 卫星图上同时具备地铁站、河道、与河道平行的道路、特色桥梁等要素 → 以多要素叠加唯一确定位置
- 街景画面被大面积模糊处理时 → 高耸地物（烟囱、塔）常未被遮挡，可借卫星图与电力设施图层交叉定位
- 短视频平台流传的卫星图与实景图常被错配 → 平台图片中的地名与画面不一定对应，需独立验证后再采信
- 区域性交通工具（三轮车、出租车样式）在同一画面出现多辆 → 可交叉验证所属地区，仅一辆时不足以定论
- 区域性交通工具有分布规律但存在例外 → 分布图只能作概率性参考，不能作绝对判据
- 形状独特的地标建筑 → 可通过社交平台检索其外观特征确定名称与位置
- 带分隔的支路等特定路型 → 多位于街区边缘，位置分布有规律可循
- 大型厂区 → 其平面图常存在于官网之外的渠道，可用于厂区内部定位
- 道路交叉处的异常绿化带或线性痕迹 → 可能是道路改线遗留，可用卫星图验证
- 背景山体形态 → 可辅助判断区域归属，缩小搜索范围
- 街景影像年代久远且道路已改造 → 不能依赖街景比对，需改用交警视频等时效性素材
- 地表土地性质 → 可判断所属大区
- 无法判断具体位置时 → 需卫星图等独立证据佐证
- 大型烟囱等地标物 → 可作为方位参照点
- 远处建筑的排列关系 → 可判断拍摄朝向，从而只排查该走向路段
- 已知交通工具位置与朝向加对面陆地建筑分布 → 可反推拍摄时另一交通工具的位置
- 关键词检索无结果且拍摄时间特殊 → 可考虑事物为节庆临时存在，改用卫星图匹配
- 仅在斑马线处设红绿灯 → 可作为该路段的判别特征
- 历年影像最早年份仍找不到目标 → 说明影像可能早于该年份
- 卫星图定位 → 结果可能超出行政边界
- 他人提供的软件显示结果 → 需卫星图等独立证据核验，不可直接采信
- 普通地图不显示线路数目与站场布局 → 判断轨道交通/车站结构需依赖街景或卫星图，不能仅靠地图
- 街景拍摄位置不同 → 可见到不同年代的影像，比对时需确认拍摄点位与日期
- 缺少可验证细节时 → 结论应标注待证实，需本地影像或更新街景验证
- 商业卫星影像供应商不同 → 同一区域影像清晰度、色彩、更新频率不同，比对时需考虑影像来源
- 街景拍摄年份标注 → 可用于判断影像年代，筛选与目标照片同时期的街景
- 题目或图像中的地标暗示 → 先推测可能城市
- 搜索该城市地标建筑 → 与目标照片右侧/左侧建筑比对，确认区域
- 从城市级到地标级再到街道级 → 逐级缩小定位范围
- 卫星图/街景中特殊颜色建筑群 → 可与地图 POI 比对确认
- 街边繁华程度 → 辅助判断城市核心区或环线位置
- 广告/商品信息 → 可作为区域线索，但需卫星图或地图验证
- 沿线服务区数量多且缺影像 → 需用卫星图沿高速逐段排查
- 从车辆到店铺名到工商地址 → 多源信息串联可定位
- 卫星图不同缩放级别来自不同拍摄时间 → 地物形态和色彩会变化，需放大到与目标一致的比例查找
- 卫星图缩放级别与拍摄日期不固定 → 比对时需确认层级和影像日期
- 无法访问境外街景 → 需改用卫星图、本地街景或建筑轮廓匹配验证
- 无法验证时 → 应标注猜测性质，并寻求其他年代/来源影像
- 多级缩放卫星图（低、中、高）组合 → 低级别用于宏观地形/水系，高级别用于建筑细节，逐级缩小范围
- 用低分辨率图定位大区域，再用高分辨率图确认具体位置 → 分阶段定位可提高效率
- 支持历史影像的地图 → 适合比对不同年代街景与卫星图
- 测试机未安装常用工具 → 可换用功能相近的替代应用
- 街景缺失区域 → 应改用卫星图、用户上传照片或较早/较新影像验证
- 道路新旧程度 → 可辅助判断街景是否存在及影像年代
- 实景植被与地图/卫星图覆盖不一致 → 季节或拍摄时间差异可致遮挡差异，不能仅凭植被缺失否定候选
- 限定答题数量限制 → 与定位无关 skip
- 实景中地标周围无植被遮挡而卫星图上植被茂密 → 可能是季节或拍摄时间差异，不能直接否定候选
- 卫星图植被遮挡建筑 → 需借助街景/航拍/实地确认
- 初步推测不确定 → 需交叉验证
- 依赖第三方接口查询时 → 注意配额和限流
- 多数影像中文字不可辨识或根本不存在 → 应转向文字之外的线索，如交通、建筑、植被、路牌形制
- 建筑风化与桥下影像状态 → 判断建成年代的早晚区间
- 识图结果中出现机构、单位名称 → 用该名称反查其所在建筑，再用卫星图确认
- 影像缺少某地常见棕榈等标志植被 → 可降低该地可能性
- 画面为卫星影像截图 → 无街景细节时依靠路网走向与地块形态判读
- 地图与街景平台信息更新滞后 → 需交叉使用多个平台，优先取用新媒体上的近期影像
- 同一账号持续发布同一地区的影像 → 该账号可能与当地存在稳定关联，可作为地区先验线索
- 地图数据由不同编辑者维护 → 地物属性可能有个体差异，需交叉核对多种数据源或影像
- 多来源影像中出现相同的地点特征 → 可交叉印证为同一位置
- 影像中可识别人物身份 → 检索其公开发布的时间与行程记录，获取地点线索
- 站点沿用旧机构名称 → 提示地名与影像存在年代差
- 画面中同类商品店铺高度集中 → 该地存在对应品类的专业或批发市场，可用品类加市场作关键词检索定位城市
- 道路走向、高压线排布、电杆规格 → 与卫星图和百科信息交叉核对确认具体厂区
- 画面中出现舰载机停放于甲板 → 判定为航母
- 卫星图上出现颜色或形态特殊的临时建筑 → 可作为高辨识目标物用于定位
- 目标照片中的山脉走向与卫星图山脉走向比对 → 走向一致者确认方位

## 历史影像

*多年份卫星图对比，判断建成年代*

- 同一地点的历史影像与现状差异大 → 地貌会变迁，不能以旧影像否定当前判断
- 影像时效以数据源的最新版本为准 → 无最新影像时以历史影像的最新日期为判读基准
- 不同地图应用功能不同 → 按是否支持境外搜索、历史影像、街景选择工具
- 历史报纸与剪报数据库 → 可反查老照片中的建筑、广告与事件，用于历史影像定位
- 都是现在用的旗帜，不用考虑历史旗帜 → 判读旗帜时优先使用当前官方旗帜，除非明确历史影像
- 旗帜判读优先使用当前官方版本 → 除明确历史影像外，不考虑历史旗帜
- 画面中出现已废止的国家电话区号 → 该标识不能用于现行定位，可能来自历史影像或误导性内容

## 街景平台

*Google/百度街景、Mapillary 等实景照片*

- 过于常见、易被本能否定的街景元素 → 仍应纳入判读，常是定位关键
- 新闻类检索结果通常标注发生地点 → 用搜索引擎检索后可在地图定位实景
- 街景中植物成像普遍模糊 → 只需记忆大致形态，不必精确辨认物种
- 在候选区域内逐点比对街景中的标志物 → 可确认具体位置
- 已确认街景图源类型 → 可排除无该图源覆盖的区域
- 特定房地产开发商有辨识度极高的建筑样式，同一城市内往往仅个别楼盘采用 → 可据此定位楼盘，再查周边街景验证
- 高架路灯多外置安装，安装于隔音板上的情况罕见 → 路灯安装方式可作线索，但需考虑街景时效与新建成设施的例外
- 已确定城市后逐段比对街景 → 定位到具体路段
- 同平台街景车的颜色与涂装 → 随地区不同，可用于排除区域
- 某平台街景年份过旧 → 换平台或改用其他数据源
- 连锁品牌网点结合街景 → 逐点比对确认位置
- 街景覆盖度存在地区偏倚 → 可将覆盖密集区作为优先搜索范围
- 街景车随机分配、同城多车、相邻街道可能由不同车辆拍摄 → 街景车类型不能作为判定城市的唯一依据
- 街景路线的可见性随客户端而异 → 多客户端交叉查看可发现更多覆盖点
- 街景视角与照片完全重合 → 街景相机位置背后即拍摄点
- 由官方或非官方运营的特殊街景车有其固定特征与分布规律 → 掌握后可显著提高定位准确率
- 旧街景仍具定位参考价值 → 时效差不影响使用，但需注意时间差
- 实地街景中找不到照片中的显著构筑物 → 排除该候选位置
- 街景的覆盖与更新受运营方资金与政策影响 → 有无街景、新旧街景的分布存在规律而非随机
- 街景覆盖不全时 → 定位精度可能只到地貌或区域级别
- 街景与网络图片比对站台周边细节 → 确认具体站点
- 画面中存在可辨认的独特建筑 → 用其名称在电子地图检索并进街景核对可完成定位
- 楼顶设红色大字招牌 → 此类建筑多为公司、酒店、宾馆、医院，可按这类关键词检索后进街景确认
- 官方街景覆盖稀少的国家或地区 → 需依赖第三方或非官方街景补充
- 非官方街景中车牌常未打码 → 车牌可读时是有效定位线索
- 道路为复杂高架立交 → 街景稀少且难以定位，应优先用其他线索
- 只有具备街景覆盖的道路才能逐点排查 → 无街景覆盖的候选无法验证，需靠其他线索
- 街景覆盖图上标有覆盖的范围 → 基本为城镇及以上聚落，乡村与荒野通常无覆盖
- 街景覆盖的下限一般为县城级聚落 → 画面中出现街景本身即可推断该处至少为县城规模
- 画面为个人上传、无文字水印的街景 → 官方街景覆盖薄弱的少见国家
- 大型桥梁机位 → 多在城市外围，街景覆盖可能缺失
- 店铺招牌与当前街景不一致 → 以楼体、颜色、排列等建筑外观对比确认
- 画面中的车辆与街景中同一位置车辆相同 → 两者拍摄时间接近
- 街景中的车辆、店铺状态 → 可交叉印证拍摄年份
- 同一区域内各城市街景拍摄日期不同 → 可用日期先后差异推断相对方位或行进顺序
- 街景中打码的人脸、车牌或车顶盖形状特殊 → 可据此辨认街景来源类别
- 辨认出街景拍摄车的类型 → 可锁定国家或地区范围
- 非官方街景车的覆盖范围有限 → 出现即指向特定国家或地区
- 非官方街景画质参差不齐 → 判读时应减少对细节的依赖
- 题目限定机位均为街景机位 → 只在有街景覆盖的区域内搜索
- 山地区域山峰众多且无街景、地图无名称 → 定位难度极高，须依赖其他线索
- 街景画面中的水印年份 → 为该区域街景拍摄时间，可判断是否已被覆盖
- 照片与街景相隔数年但街道设施一致 → 可确认为同一地点
- 候选点的街景多个方向都能看到楼房、而原照片中没有楼房 → 可用于排除该候选点
- 画面中出现完整店名 → 用店名检索地图；结果唯一时直接对街景验证
- 照片与街景相差数年 → 比对窗户、水管等不易变动构件的相对位置
- 街景覆盖密度城区高于乡村 → 乡村点位常无街景可验证，只能判断所属辖区
- 区域内无街景覆盖、但路口造型高度重复 → 精度只能到区域级，难以定位到点
- 街景中车辆号牌前缀 → 可判断车辆注册地，是街景认证缺失时的强线索
- 街景中出现某年代常见、近年已少见的车型 → 可判断街景拍摄年代
- 地图对同一设施只画一条线 → 属简化表示，与实景或其他图源不一致属正常
- 目标国家或区域无街景覆盖 → 只能判读国家，无法进一步定位
- 街景车的车型、颜色、天线长度、是否带随行车辆 → 具有国别特征，可用于判定国家
- 不同国家或岛屿可能使用完全相同的街景车 → 街景车外观不可单独用于区分地区，须结合覆盖范围与地理特征
- 非官方街景覆盖通常范围极小且集中于城市或个别岛屿 → 出现非官方连续街景时优先在小范围内搜定
- 某区域可用的街景全景数量稀少且年代久远 → 判读难度高，需转向其他线索
- 街景覆盖缺失的位置不能作为地点不存在的证据 → 需用其他数据源交叉验证
- 公交行车记录视频 → 在无街景覆盖区域可作为街景替代用于比对，但须注意部分线路为反方向行驶
- 同一城市存在多个同类枢纽或同名地点 → 必须用街景逐一筛选比对，不能凭名称直接定案
- 多城市候选点逐一比对护栏样式与招牌样式 → 以高度相似的招牌配合街景交叉确认
- 街景拍摄年份过早、与现状差异大 → 只能逐段盲扫，比对时须计入时效偏差
- 除城市信息外，街景车类型与拍摄时间同样是有效线索 → 先整合全部线索把范围缩到可把握区间，再逐点验证
- 同一点位存在不同年份街景 → 以后景建筑、井盖等固定参照物位置一致确认同一地点，道路编号可辅助定位
- 街景中的文字被涂抹或去除 → 不能依赖街景画面内的文字信息
- 某地名在网上搜不到任何实景 → 该地街景覆盖缺失，应改用其他类型线索定位
- 目标位置无街景覆盖 → 可依据可见建筑的编号与相对方位推断具体位置
- 无街景区域中可见公园外部的建筑 → 通过建筑相对公园的方位反推拍摄点
- 小城镇范围小、街景稀少 → 确定大致区域后逐条巷子排查，成本较低
- 画面被树木遮挡或无街景 → 该类线索不可用，需另寻可判读元素
- 街景覆盖范围本身 → 可作为判断依据，特定岛屿或地区是否覆盖具有特征
- 新施划的道路标线 → 常意味着街景尚未覆盖
- 场景为大学校园且紧邻湖泊 → 可直接锁定到具体学校并比对街景确认
- 近年改造过的著名地标 → 街景可能与现状不符
- 街景覆盖不全或更新滞后 → 可能导致无法定位具体拍摄点
- 街景更新滞后 → 现场情况可能与街景不一致
- 目标点无街景覆盖 → 可用同一道路其他位置的路牌替代参考

- 特定形态的建材在街景中高频出现 → 可锁定其集中分布的区域
- 高速公路车道数、护栏形态、街景覆盖范围组合 → 可用于推断南北区域或具体城市规模
- 街景存在年代差异 → 建筑/道路变化可能造成比对失败，需按拍摄日期筛选
- 实景地图日期早于目标照片 → 新建筑在旧街景中缺失，不能据此否定位置
- 街景中可找到同侧建筑 → 可反向定位具体街道
- 候选位置需点开街景确认 → 不能仅凭地标方位下结论
- 未找到相似街景 → 不能仅凭道路特征确认，需继续寻找直接匹配
- 街景变化大 → 旧照片与现街景差异会干扰核对，需按年代或建筑物锚点比对
- 街景拍摄日期早于目标照片 → 无法验证新出现的地物，结论可靠性下降
- 依赖早于目标年代的街景 → 只能作为辅助，不能作为最终确认
- 品牌门店仅存在于某城市 → 可据此锁定城市，再用街景确认
- 近年新建道路或新区 → 街景覆盖可能缺失，不能因无街景否定位置
- 题目素材可能来源于公开街景视频/截图 → 可检索相同来源或近期同类视频辅助定位
- 街景覆盖沿道路分布，湖泊等区域仅沿岸有街景 → 拍摄点应在有街景的道路附近

- 无街景区域难以证实 → 需依赖其他证据
- 题目素材可能来自公开街景视频 → 可检索同源最新视频比对
- 公交调度站、场站的固定设施与配色长期稳定 → 可作街景比对的锚点

- 视频画面中的弹幕或评论 → 常直接给出拍摄地点，可用地图实景核验

- 街景仅覆盖较早年份 → 需考虑目标拍摄时间与街景时效差，不能以当前街景否定位置

## 地图查询与OSM

*道路、POI、行政边界查询*

- 与目标机场的实际距离与道路特征不符 → 排除该候选机场
- 高架或高速的车道数等道路规格 → 可区分同一城市的不同快速路
- 图中标志性建筑可与地图逐一比对 → 用于确认最终位置
- 地图数据中的名称标注不一定采用常用写法 → 应查数据库中该地物最常用的标签再检索
- 商家倾向在地图软件登记店铺 → 地图POI中的店面信息相对全面，可用于核实位置
- 城市内铁路线数量稀少 → 铁路与公路的交叉点可作为地图定位锚点
- 地名的权威来源 → 以官方地图与政府文件为准，网络俗称不可采信
- 人物口音或群体特征 → 提供大致区域线索，再以地图距离核对
- 目标物与相邻设施的组合形态具有地域集中性 → 用固定组合特征缩小到某条道路
- 第三方开源地图数据存在更新滞后 → 不能作为最新事实的依据
- 山脉相对道路的位置关系 → 判断道路走向
- 路灯样式完全一致 → 可锁定具体道路
- 学校类设施用"学校"这类笼统关键词检索地图时结果多为中学 → 笼统关键词的检索结果会偏向多数子类，需再按类型细分
- 河流两岸的山脊、道路、村落走向彼此平行且顺直 → 属平行岭谷地貌，可据此对照地图锁定河段
- 居民楼多为坐北朝南 → 由建筑朝向可推断相邻道路的走向
- 开放地图中要素多以路径表示 → 学校等设施为闭合路径并带类型标签，可用标签批量筛选目标地物
- 车牌中的区域代码对应行政区 → 查表可把范围缩到县级，无需记忆全部代码
- 单侧温室大棚通常朝南、东西走向 → 可据此推断与其相邻道路的走向
- 地物与道路存在夹角 → 由夹角可推断道路走向，再与候选路段比对
- 当地民居朝向统一 → 可据此推断道路走向
- 企业信息查询平台可获取招牌对应的完整名称 → 用全称在电子地图检索更易命中
- 缺乏文字与建筑等硬线索时 → 从路面材质、标线样式、护栏形式等道路样式入手
- 画面中出现机构主题标识牌 → 按标识主题检索该机构在各地的分支点位，再比对地图
- 画面中出现专名标志性建筑 → 名称可作检索关键词配合地图定位
- 道路设施带有邻近地区风格 → 目标城市位于该地区影响范围内
- 画面显示特定设施类型 → 按该类型 POI 逐点筛选比对
- 有招牌、有店面的经营场所 → 一般能在地图 POI 中检索到，可作定位切入口
- 法规禁止公开表示的设施（站内线路、专用铁路、编组站等） → 地图上不显示属合规原因，不代表实际不存在，需换图源核实
- 自动生成或众包的地图数据集精度不保证 → 使用前需核对官方覆盖范围与地点数量
- 地图上查不到某地物的名称或机构标识 → 不能据此排除该地物存在，地图标注本身不完备
- 需要按地物类别批量检索标注 → 使用 Overpass API 一类接口按标签查询开放地图数据
- 特定造型的华灯类路灯多出现在政府机关门前与广场旁大道 → 据此把目标限定在行政机构或广场周边主干道
- 地图上被刻意模糊、无标注或显示异常的区域 → 提示敏感设施（政府、军事、电力等）所在
- 地图检索结果不完整 → 不能因搜不到而排除，应扩大范围或更换检索词
- 地图POI头像多为门店招牌实拍 → 可作为招牌样式比对的素材

- 与已知站点的步行距离量级 → 可用于约束候选范围
- 乘坐站数乘以平均站间距 → 可估算两站间距离
- 山区公路旁密集出现货车加水摊点 → 位于长距离连续下坡的山区公路段
- 距离关系（下车点到入口的距离等于另两点距离差） → 可作为几何约束缩小候选范围
- 车牌字符因遮挡、模糊而大面积空白 → 不要强行判读其归属地
- 多个连锁品牌门店同框 → 用品牌组合检索并计算相互距离，按距离匹配候选城市
- 以某一标志店铺为原点计算到其他已知店铺的距离并取均值排序 → 在候选城市间排序
- 地标建筑间距离近、中间仅隔一栋楼 → 拍摄方向接近正南或正北
- 港区后方出现长距离连续传送带 → 为散货装卸港，多用于矿石、煤炭、粮食等
- 画面缺少参照物 → 不能由目标物大小判断距离或高度
- 结合拍摄时期的社会状况 → 可限定拍摄地与已知地标的距离范围
- 航母紧邻公园式岸上建筑且可近距离拍摄 → 该舰已退役并改造为博物馆或主题公园
- 移动端作答且需提前选点 → 时间受限时优先给出大区域判断，不追求精确坐标
- 公路两侧为白线、中央为双黄线的路面标线 → 阿根廷
- 公路标线全部为白色的场景 → 阿根廷
- 车辆停放在无车位线的非机动车区域 → 商业步行区或景区周边
- 斑马线与停止线之间出现非常规间距或区域 → 可能反映当地交通标线规范或特殊路口设计
- 交通标线颜色与宽窄比例不符合常见规范 → 可能指向特定地区或特殊路段
