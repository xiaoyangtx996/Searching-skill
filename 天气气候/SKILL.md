## 云型识别

*积云层云卷云，判断天气与气候*

- 主体建筑周边为简易板房、无硬化路面 → 疑为工地临时设施，不宜作为稳定聚落特征判读
- 地面有降雪且能积存、未融化 → 拍摄地为冬季长期低于零度、积雪可留存的地区
- 画面疑似影视取景地或明显合成 → 部分元素不可用于地理定位
- 高海拔山体山顶积雪、山腰入云 → 拍摄地临近高海拔山系
- 刚下过雪、地面湿润未结冰 → 拍摄时气温接近零度，为初冬或早春
- 车辆把手无防寒手套、仍有电动车通行 → 拍摄时气温并不严寒
- 沿海地区且有积雪 → 拍摄地属冬季有降雪的沿海地区
- 画面中可辨认标志性建筑并判断其相对方位 → 可反推拍摄机位与拍摄点
- 手机号归属地或运营商显示为某国内省份 → 不等于拍摄地在该省境内，边境地带常接入邻国网络
- 远景出现烟囱等工业设施 → 附近有工业区或工业城市
- 画面中没有人工地标 → 可用山峰轮廓的天际线剪影作为定位依据
- 建筑具有独特且成系列命名的风格 → 可用其名称在全国范围检索反查位置
- 检索到疑似地点后 → 用附近固定地标交叉验证
- 跨线天桥配合电气化支线 → 可缩小到同时具备该设施组合的位置
- 得到气候类型初判后 → 用气候数据与天气网站剔除与画面矛盾的区域
- 从基准城市按温度梯度逐点向北或向南比对 → 寻找与画面物候吻合的地点
- 街头商业形态（早市、地摊、三轮车等）→ 指示地域风格
- 山体裸露呈黄色多石、落叶林呈深色、天空灰蒙 → 北方冬季景观
- 云系集中在一侧、另一侧晴好 → 可判断天气系统方位与绕飞方向
- 云底低而平坦 → 为积云，云底高度可反推当地湿度与气候带
- 低云型与度假类建筑叠加 → 指向沿海度假气候区
- 体量突出的公共设施（体育场、跳台等）外形鲜明 → 可优先用于快速定位
- 沿海扫描时养殖设施类型 → 标示特定海域段落，用于跳过或锁定区段
- 行人身着短袖且天空少云 → 拍摄于暖季，越靠低纬越常见
- 仅有网络说法或口述作为依据 → 需以可验证的独立证据交叉确认
- 画面或文本中出现商户名称、地址、楼层 → 可直接检索该商户位置从而定位
- 画面被云层等大面积遮挡、无可辨识地物 → 不具备定位判读条件
- 云底贴近地面、云层极低 → 拍摄地海拔较高或纬度较高
- 阳台长期放置易被风吹落的物品 → 该地大风天气少，多为内陆或背风环境
- 同类型聚落形态在某一区域分布更密集 → 可作为偏向该区域的弱证据
- 常规气象数据仅有大范围温度与天气 → 不足以精确到点定位
- 账号IP属地 → 不等于照片拍摄地，不能作为拍摄地证据
- 站名以方位词结尾 → 该站位于所在城市的相应方位
- 电动车普遍加装遮雨布 → 多雨地区或南方城市
- 外卖骑手密集、共享设施与便民设施齐全 → 经济发达的大城市
- 工业城市主干道+中度雾霾 → 可锁定北方工业城市类型
- 特定云型配合高能见度 → 可指示特定气候区或区域
- 冬季持续阴天/雾天的典型天气型 → 可匹配特定气候区
- 照片中出现电商或商业标识 → 可辅助定位
- 多张照片 → 应分别判断拍摄地点与天气，并交叉验证

## 降水与湿度

*雨雪雾，判断地域气候*

- 潮湿地面与河道并存 → 可排除干燥气候区，判断所处气候带
- 路面长期潮湿、砖石破旧且通行痕迹少 → 拍摄点位于人迹罕至的后门或背街
- 云状为积雨云、天色阴沉 → 拍摄时段处于对流性降水天气
- 晴天但地面仅有少量积水 → 刚经历短时降水或对流天气后转晴，且降水量不大
- 判断湿度、气温等气象要素等级 → 须按当地气象部门的定时观测统计口径核对，不能凭画面直觉
- 房屋普遍为平顶 → 当地降水较少
- 旱作农田种植小麦且无灌溉沟渠 → 降水虽少但能满足旱作农业
- 积云在潮湿热带常见 → 拍摄地湿度大，指向湿润热带或亚热带
- 屋顶以大挑檐、陡坡等防雨构造为主 → 降水充沛的湿润地区
- 树冠白色附着物呈雾凇形态而非积雪 → 拍摄于冬季清晨的低温高湿环境
- 天空阴但地面干燥 → 降水可能为阵雨/小雨且已停，非持续大雨
- 晴空无云且空气干燥但能见度低 → 可能是雾霾/颗粒物污染
- 云底高度较高 → 可能指示偏北或干燥地区
- 已知候选日期与地点时，查历史天气与照片中云量、降水、地面干湿比对 → 可排除不符合的日期/地点
- 照片中降水强度与已知当日降水过程时段对应 → 可推断拍摄时间窗口
- 高耸建筑采用平顶 → 当地积雪少，指向冬季温和或降水充沛地区
- 平顶建筑上加建轻质钢构斜顶且坡度平缓 → 目的为排水防积水，指向降水充沛而少积雪地区
- 建筑屋顶坡度整体明显偏大 → 指向以降雪为主要降水形式的气候区

## 气候带判断

*由气候反推所处纬度带*

- 舷窗外出现高纬度自然地貌 → 可缩小到特定气候带或国家范围
- 积雪厚度与季节特征 → 推断所在气候带
- 侧面或剖面裸露红土 → 指向亚热带南方地区
- 常绿植被结合物候特征 → 可用于判断所处气候带
- 草地枯黄而树木常绿 → 秋冬季节的亚热带或暖温带
- 连续多日降雨 → 处于雨季或季风、热带气候
- 树木种类与高度 → 可推断南北气候带
- 识图识别出典型树种 → 可据此判断大致气候带
- 画面中出现三角梅 → 拍摄地属热带、亚热带南部
- 建筑紧贴水边且与水面高差很小 → 水位年变化小，非季风气候或受人工调节的水体
- 植被稀少且水位稳定 → 可排除季风气候区
- 植被组合（常绿针叶比例、需水性、耐寒性）→ 指示气候带与冷暖干湿
- 植物为需水且不耐寒类型 → 气候温暖湿润，可排除寒冷或大陆性气候区
- 已知植物种的适生温度与降水区间 → 反推拍摄地的气候带与纬度带
- 识别典型热带水果或植物 → 可推断拍摄地属于热带气候区
- 树木形态 → 可判断高海拔地区或南北气候带
- 树木形态具有高海拔或特定气候带特征 → 可据此推断拍摄地所处海拔或气候区域
- 植被类型与生长状态 → 可判断所属气候带与大致纬度区间
- 画面呈现流动沙丘、稀疏旱生植被、极少水体 → 该地处于热带荒漠气候区
- 河面结冰 + 植被类型 → 推纬度/气候带
- 河面结冰与植被类型 → 判断所处纬度与气候带
- 典型地貌形态（峰林、溶洞、丹霞、雅丹）→ 可限定岩性类型与气候带
- 植被物候状态 → 排除纬度或气候带不符的候选地
- 植被只能指示气候带与纬度区间 → 无法直接确定城市，需与其他线索叠加
- 植被类型反映气候带 → 可缩小纬度与地域范围
- 庭院风格与植被、气候迹象同时出现 → 将建筑区划与气候带交叉匹配，锁定候选地理区域
