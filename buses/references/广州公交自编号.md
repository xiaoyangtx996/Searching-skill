# 广州公交：自编号与线路编号规则

> **旁挂**：`SKILL.md` 是通用「线索 → 结论」规则表；本文是**广州专属**的编码解码表。
> 素材来源：豆瓣「炒饭网络迷踪」小组教程《广州公交（1）——关于各种"号"》（作者 夜阑/Kevin，2026-02 修订）。

## 一、线路编号

| 前缀 | 对应区域 |
|---|---|
| **无前缀** | 中心六区（越秀、荔湾、天河、海珠、白云、黄埔） |
| **广** | 跨市线路 |
| **番 / 南沙（南）/ 花 / 从 / 增城（增）** | 番禺 / 南沙 / 花都 / 从化 / 增城 |
| 特殊 | **B**=BRT、**夜**=夜车、高峰快线、旅游/大学城/商务专线 |

- 后缀含：长线、短线、支线、快线、字母（如 `B4B`、`广12A`、`花17C`）
- 编号印在车辆**前后上部与右侧**

## 二、车牌

- 全为 **粤A**，**黄底**（7 座以上）
- 多数新能源：**6 位**，电车 **D 结尾**、氢能源 **F 结尾**；其余 5 位纯数字
- 中右侧**绿色**

## 三、自编号（巴士集团）

格式 `x-xxxxx`，`-` 前为运营公司：

| 码 | 公司 |
|---|---|
| 1/2/3/4 | 巴士集团一/二/三/四分公司 |
| D | 巴士集团**电车**分公司 |
| E | 巴士集团二巴公司（第二巴士） |
| P | 番南片区（番禺公汽、番广） |
| N | 番南片区（南沙巴士） |
| H | 花都分公司（花都恒通） |
| C | 增从片区（从化公汽） |
| Z | 增从片区（增城荔通公汽） |
| Y1/Y2/Y3 | 一汽巴士一/二/三分公司 |
| XS | 新穗巴士 |
| J | 珍宝巴士 |
| W | 白马巴士 |
| M | 马会巴士 |
| F | 佛广公汽（属**佛山**公交，非广州） |

**其它公司**：创大/锦信公交=3~4 位无含义；南沙交通=`C-xxx`/`CZ-xxx`；从化顺途=`xxyy`（前两位为线路）；增城粤运=`-` 前数字为线路。

> 实例：`D-84009` = 电车分公司、氢能源、完整号 84009；该号段可读出车型 **金龙 XMQ6851DGFCEV**。

## 四、查询工具

- **巴士档案站** — https://buspedia.top/ （全国公交可查，可能更新不及时）
- 微信公众号「**巴士收风机**」（市区公司，约半月~1月更新）
- 微信公众号「**湾区枢纽 TransHub**」
- **维基（ctwiki）** — https://ctwiki.top/
- 小程序「**广州公交行讯通**」（查线路在运车辆车牌号）；增城用「**增城公交出行服务**」

## 提醒

自编号的**前段码只保证到运营公司**，具体车型/线路要靠档案站反查；调度原因可能与实际不符。
