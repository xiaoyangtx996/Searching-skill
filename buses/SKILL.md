## 自编号与涂装

*自编号与车身配色锁定城市*

- 同型号车辆的涂装用于区分归属单位，通常出现在车尾或车门 → 可由车辆涂装归属反推所在地区
- 车身标识使用英文 → 说明拍摄地非中文地区；同时出现多家国际航司标识 → 说明该地为重要国际机场
- 机身涂装样式相同的飞机属于同一批次或同一用户 → 可由涂装一致性归类机型与所属单位
- 机队采用地方主题涂装 → 可指示所属地区或运营基地
- 同一涂装系列在不同地区存在差异 → 该差异可作为地区判据
- 出租车涂装与颜色具有地域特征 → 可由出租车外观推断所在城市或地区
- 公交涂装具有城市专属性 → 可用图片检索比对涂装反查城市与线路
- 同一涂装可对应不同型号装备 → 需借助结构细节区分
- 缺少公交前方展望视频时 → 改用短视频平台按站名检索
- 警车的涂装颜色与车队样式 → 具有地域特征，可作为定位线索
- 照片中宣传栏、车身等处可辨认出公交公司字样 → 据此锁定所在城市或公交枢纽范围
- 公共自行车或共享单车涂装具有城市区分度 → 可先据此确定城市
- 出租车涂装与地方性银行标识具有城市指向性 → 可据此确定城市，本地银行名称常与所在城市同名
- 出租车涂装与方言用词 → 具有城市特征，可缩小到具体城市
- 出租车涂装配色 → 具有城市专属性，可用于判断城市
- 公交涂装与步行道铺砖符合某城市样式 → 作为该城市的正向线索
- 公交车外形与涂装可识别 → 通过检索车辆涂装可推断城市公交系统，进而缩小城市范围
- 公交涂装与地铁入口样式组合 → 可交叉验证城市
- 公交车特征可识别 → 可先锁定城市
- 工业烟囱涂装以红白条纹最常见 → 出现异色涂装时属高辨识度特征
- 烟囱等工业设施的涂装颜色存在地域差异 → 颜色与资料照片不符时应更换候选地
- 画面整体偏白，多种本应非白的物体也发白 → 考虑过曝、积雪或涂装因素，不宜据此判断地域
- 公交车前挡电显规格只能显示路号、不能显示首末站 → 属区域性车辆配置特征，可缩小城市范围
- 市政设施（控制箱、站牌、护栏）与公交车涂装风格一致 → 涂装体系属同一城市或同一运营商，可互相印证归属
- 涂装在整个城市范围内统一 → 不能作为市内区域细分依据，需另找线索
- 车身或车内标注的服务电话 → 多为车辆制造厂电话而非运营公司电话，不能用于定位城市
- 存在可检索的公交车辆或线路档案数据库 → 以运营公司、涂装、车型等特征做交集检索，唯一命中即可锁定城市
- 车辆特征通常只能把范围压到城市一级 → 精确到具体点位需依赖建筑几何特征（楼层高度、建筑间距、轮廓）
- 公交、出租、警车、消防、工程车等区域性公共车辆 → 通常不驶出所属地域，其车牌属地多等于拍摄地
- 公交专用道在路口断开让位右转车道 → 属常规设计，定位价值低
- 公交专用道连续穿过路口并设社会车辆借道区 → 属少数城市的特殊设计，可作强定位特征
- 公交涂装配色与线路色带具有地域专属性 → 可缩小到特定城市或城区
- 卧铺车厢下铺被拆分为多个座位、中上铺兼作行李架 → 该车为卧铺代座位编组
- 公路上出现未上牌、成队行驶的新公交车 → 多为新车交付转场运输，不代表本地运营
- 同一城市公交车型与外观高度统一 → 车型可作城市级判据
- 出租车车型与涂装具有城市专属性 → 可作城市判据
- 潮汐公交专用道仅见于少数城市的放射线高速且限时段启用 → 出现即指向特定城市类型
- 收费站及其前后路段形态固定 → 可作定位锚点
- 公交车内座椅靠背的样式与颜色具地域特征 → 可反查运营城市
- 公交车未悬挂新能源专用号牌 → 提示该市新能源公交推行程度或城市层级
- 公交专用道在不同路段的连续性不一致 → 不能假定全线形式统一
- 充电桩仅设于公交场站且不对外开放 → 出现充电设施即可判定为公交场站
- 公交车与人行道护栏样式具地域专属性 → 可据此圈定城区范围
- 公交涂装的细节配色组合在同省城市间仍有差异 → 可精确到城市层级
- 直辖市公交的编号与涂装体系独立于省辖市 → 出现直辖市特征时不能套用省级规律
- 公交车左侧也设车门 → 属少见配置，多与封闭式专用道或双侧开门运营相关
- 路牌制式与公交涂装是最易先行判断城市层级的线索 → 适合用于初筛
- 公交车外观直觉像某城市但存在不一致细节 → 直觉印象只能作为假设，需用涂装、车牌、自编号、电显等可核对特征验证
- 公交车为特定鲜艳涂装色 → 公交涂装颜色有地域倾向，可缩小到使用该涂装色系的公交系统
- 公交车身有统一喷码或贴纸车号且与涂装无关 → 车辆自编号标注方式具有运营公司特征，可反查所属公交集团
- 可辨认车辆自编号 → 可直接反查车辆所属公司、线路和注册地，优先级高于车型筛选
- 某客车品牌在特定地区公交中占比高 → 可作为地域倾向线索，但需结合涂装、车牌等确认
- 车牌省份简称字模糊但字形特征明显 → 可通过候选省份集合排除，先锁定省份再查该省公交特征定位城市
- 公交车返回场站且周围有特定路灯样式 → 场站布局和路灯样式可对比公交总站位置
- 特定涂装与特定车型固定搭配 → 可反查采购批次和运营地区
- 公交车和出租车涂装均呈同一城市样式 → 多种交通工具涂装交叉验证可提高城市定位可信度
- 公交车电子显示屏的品牌、字体、颜色特殊 → 电显由采购方指定，具有公交集团或城市特征，可反查运营方
- 出租车涂装颜色与车型 → 具有强地域性，可作为地区判据
- 出租车车身颜色 → 地域线索
- 车身标语与专用车型 → 可佐证机构性质与作业类型
- 栏杆与人行红绿灯杆上的警示涂装一致 → 多要素同源，可确认同一地点或同一管理区域
- 站口/门口的黑黄色栏杆等特殊涂装/设施 → 可作为独特视觉锚点定位
- 8 门口或站口出现特殊涂装栏杆等固定设施 → 可作为独特视觉锚点用于定位
- 画面中可辨识的城市细节（路牌、车牌、公交、招牌）→ 找到一两处即可大致锁定城市
- 画面主体配色与常识相反 → 可能是翻新或临时涂装，不能据此排除
- 车辆涂装无地域特征 → 不可作为定位依据
- 号牌或车身上重复出现同一地名标识 → 该地名即车辆所在或到达地
- 车牌归属地混杂时，车身上本地商业广告比车牌更能指向拍摄地 → 优先采信本地商业标识
- 车牌被直接喷涂或印在车身上而非正规悬挂 → 多为营运货运车辆，其文字内容可靠性低，不可作为地区依据
- 出租车的涂装与车型具有城市特异性 → 可作为城市线索
- 画面中出现飞机、船舶等可移动目标 → 不能默认其注册地或涂装所属地与拍摄地一致，应以背景固定地物定位
- 出租车涂装样式 → 可判断其所属地区，进一步收窄范围
- 车辆涂装特征 → 可与特定城市出租车样式比对
- 路面出现黄色公交专用道标线 → 可判定该路段设有公交专用道，用于缩小到已施划公交专用道的城市或路段
- 公交车整体采用非通用涂装颜色 → 可据此在公交涂装数据库中筛选对应城市
- 公交车前显示屏采用特定配色组合 → 可作为该城市公交的标志性识别特征
- 同一涂装同时出现在多个城市的运营车辆上 → 不能单凭涂装定位，需与其他线索交叉验证
- 无法凭记忆辨认公交涂装或车型 → 应检索公交涂装、车型数据库比对，而非凭印象判断
- 照片中同时出现公交车与车身自编号 → 自编号可唯一对应车辆及所属公司，属于高优先级定位线索
- 车辆自编号与某城市公交集团编号规则不符 → 可排除该车辆属于该公交集团
- 车身或站牌出现"某市公交"字样 → 可锁定所属城市
- 地面或设施上出现公交专用字样 → 表明处于公交场站或公交专用道范围内
- 由涂装确定运营公司后 → 该公司的运营范围即为车辆可能出现的城区范围
- 画面出现统一着装人群 → 可能为学校或企业，结合鞋类颜色与年龄特征可区分学校与企业
- 以城市名加机构类型作为关键词检索 → 可查到照片中的具体地点
- 照片中出现的车辆段或停车场特征，且该区域只有一处同类设施 → 可推定具体车辆段位置
- 缆车、索道等设施的涂装配色由运营方和地区决定 → 配色可作区域判据，外形相同的车厢靠配色区分
- 车辆、设备涂装的过渡段形状（平直、凸起、瓶形）→ 可作为区分相近涂装的判据
- 公交车车身涂装与外观细节可辨识车型 → 通过反向图片搜索匹配同款车辆，缩小其可能存在的地区范围
- 公交与出租车的涂装风格 → 指示所在城市或地区
- 公交涂装、车辆型号与是否停靠该站 → 可反推线路与站点关系

## 站牌与站台

*站牌样式判断城市*

- 公交车为罕见车型、前置发动机且线路号数值大 → 可排除部分城市，缩小到特定区域的大城市
- 公交站牌名称字数与候选地点站牌字数吻合 → 可作进一步验证
- 画面中的公交站名或线路文字 → 可直接给出所在城市范围
- 图片中被刻意涂抹或改动的文字（单位名、电话、车牌、线路号） → 该处即最可能泄露所在地的关键信息，应优先还原或反向推断
- 公交站牌制式（尺寸、颜色、字体、支架） → 地域特征明显，可作城市识别依据
- 公交站台设在道路中央并以护栏分隔 → 该路段为快速公交或封闭式公交专用道走廊
- 公交站名由两条相交道路命名 → 站点位于该交叉口附近
- 同一方向仅一条车道且公交站候车人多 → 多为老城区主干道，车辆常越线借道行驶
- 公交站牌样式及是否带电子显示屏具城市与年代特征 → 可同时作地点与时间线索
- 站牌标注的运营公司与车辆标识不一致 → 该市存在多家公司混营，需交叉验证
- 同一线路存在区间、绕行等非常规走向 → 仅凭线路号不能唯一确定路径
- 公交站牌相邻站名均带括号 → 站名命名格式有地域集中性，可用于筛选特定城市或公交系统的线路数据
- 公交站间距明显大于常见城区站距 → 可能位于郊区、新区或低密度区域
- 站牌文字使用繁体字并含多种外语 → 可指向使用繁体及多语标识的地区或运营系统
- 路灯与公交站台的样式在县区级范围内保持一致 → 可排除样式不符的城市
- 站台位于道路中央 → 多为BRT站台，而非地铁站或路边公交站
- 站台数量与多块站牌 → 判断为换乘站；线路平行 → 判断为平行换乘结构
- 路牌、站牌的颜色与制式 → 具有地方专属特征，可作为强定位线索
- 应该是东13路，地铁三岔站→空港新城政务服务中心，左转位置是在地铁三岔站公交站门口，主要特征是门口的黑黄色栏杆
- 公交站牌/车头显示起终点 → 拍摄点可能在起点或终点站附近
- 左转位置 near bus stop → 道路转弯处与公交站门口重合
- 站牌字体/配色/版式/边框等制式具有地域性 → 可作城市判据
- 7 公交站牌或车头显示起终点 → 拍摄点可能位于线路起点或终点站附近
- 确定候选道路后 → 用路灯样式、电线杆、公交站牌等细节逐一比对确认具体路段
- 车内或车头出现起讫站牌文字 → 可反查具体线路号
- 线路号确定后 → 可查所属分公司，进而判断其服务区域为城区或郊区

## 车型识别

*公交车型与品牌*

- 某车型在特定区域保有量高、其他区域罕见 → 出现该车可框定大致区域
- 能辨识出 BRT 专属站台 → 即可确定该 BRT 线路及所属城市，另一端站台无需识别
- 车内配置（如显示屏安装位置）在某一车型年份之后统一改变 → 可推断车辆购入年份，进而缩小运营商与城市范围
- BRT 通常配备双向专用车道 → 若车辆混行于普通车道，则 BRT 站台与专用道特征不可用
- 路牌形制之外，交通参与者（踏板车、营运车辆）的普及度差异 → 罕见车型的出现即为强地域线索
- 画面中出现保有量极少的罕见车型 → 拍摄地可缩小至极少数配属站段
- 车辆号段首位数字 → 对应特定生产厂家或车型
- 公交或BRT设施的标识书写习惯因城市而异 → 可用于排除不符合惯例的城市
- 多种罕见要素同时出现（特殊颜色护栏、双层护栏、桥头小构件）→ 组合特征比单一特征辨识度更高，应优先比对组合
- 某地护栏普遍为双层结构 → 护栏层数属国家或地区级特征
- 画面中的车型上线年份与拍摄时期不符 → 排除该地区，改从该型车服役的地区排查
- 需先判别车辆为普速还是动车 → 若为动车可搜索范围大得多，判别车型能大幅收窄范围
