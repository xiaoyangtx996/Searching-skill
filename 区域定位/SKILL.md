# 区域定位

元素层（22×`wlmz-*`）答「**这是什么**」；本技能答「**这里是哪**」。先解元素线索，再比对国家/省份特征。

## 何时使用

- 已排除中国，要定**国家**
- 已定国家，要缩到**省/州/大区**
- 疑似某国，要**验证或排除**
- 中国境内，要定**省份/城市**

## 输入 / 输出

| | 规格 |
|---|---|
| **输入** | 已由总技能/元素层列出的可见线索（车型、电杆、植被、文字、行车方向等） |
| **中间** | 候选大洲/国列表；已读的 `references/` 路径 |
| **输出** | 候选国/省（带节名命中句）；L 级建议回传总技能；未读文件不得当作已证伪 |

| 路径 | 何时读 |

## 定位流程

### 1. 元素层线索已就绪

若总技能尚未解出元素含义，先回到对应 `wlmz-*`，再进入本流程。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索可比对 | 请总技能补线索表 | 输出「无法定国」，建议 L0–L1 |
| 只有 1 条软线索（植被/电杆） | 加读 1 个 `元素/` 主题文件 | 并列多国，不定一国 |

### 2. 用跨国元素收窄

优先（最强前置）：`元素/街景车与相机代数.md` → `电线杆meta.md` → `植被.md` → `语言文字.md` → `电话区号.md` → `水箱.md`。

例：`木杆 + 英文路牌 + 右行 → 北美倾向`；`左行 → 排除美国，指向澳/肯/南非等`。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 元素文件名不符 | 打开 `_index.md` 对名 | 用已有线索直接进步骤 3 |
| 候选仍 >5 国 | 再加一条独立线索（文字/行车方向） | 只输出大洲级，回传 L1 |

### 3. 读候选国/省文件比对

读 `世界/<国>.md` 或 `中国/<省>.md`。节名多呈 `## 大区 > 子区域`；只摘与画面匹配的条目，抄进「规则摘要」。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 文件不存在 | `_index.md` 查近义/旧称 | 不定该国；保留其它候选 |
| 节内无匹配 | 试邻省/易混国文件 | 降级 L1–L2，列已排除项 |

### 4. 易混国专项

候选为常见混淆组时，读 `元素/易混国家对比.md`（墨/西/希/土；东南亚；塞内/尼日/肯；哥/厄/秘）。

### 5. 精确定位

需要路网级时读 `元素/精确定位方法论.md`；点位级结论仍须总技能 CHECKPOINT（≥2 互证 + 可核验文本）。

### 🔴 CHECKPOINT · 🛑 STOP

回传「某国/某省」前，任一项为否 → **不得单国断定**：① 已读 `_index.md` 或等价确认文件存在；② ≥2 独立线索支持同一候选；③ 摘要句来自已读 references，非记忆臆造；④ 易混组已查对比表或显式声明跳过原因；⑤ 单文件命中 ≠ 定城，定城交回总技能升 L3+。

## 回传行（给总技能）

```
规则摘要：<区域文件节名>：<特征句> → <国/省倾向>
候选国/省：<列表> | 建议等级：L1–L2（本技能不报 L4）
已读路径：references/...
```

## 反例黑名单

- 一上来通读全部 161 个区域文件
- 单条植被/电杆线索就定国
- 把区域层地名规则当成元素层「去地名」输出
- 未读文件却写「该国无此特征」
- 本技能单独报 L3 城市 / L4 点位
- 忽略街景代数与画面年份差异
- 线索不足仍硬猜一国
