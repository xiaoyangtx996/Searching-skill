# 区域定位

元素层（22 个 `wlmz-*` 技能）回答「**这是什么**」；本技能回答「**这里是哪**」。

两者配合：先用元素技能把线索解出来（车型、电线杆、植被、文字），再用本技能拿这些线索去比对**国家/省份特征**。

## 何时使用

- 已排除中国，需要确定**是哪个国家**
- 已确定国家，需要进一步**缩小到省/州/大区**
- 看到疑似某国的特征，需要**验证或排除**该候选
- 中国境内：需要判断具体**省份/城市**

## 定位流程

### 第 1 步：先用元素层把线索解出来

- 街景车/相机代数（**最强前置判据**，直接限定国家范围）→ `references/元素/街景车与相机代数.md`
- 电线杆 / 贴纸 → `references/元素/电线杆meta.md`
- 植被 → `references/元素/植被.md`
- 文字系统 → `references/元素/语言文字.md`
- 电话区号 / 车牌前缀 → `references/元素/电话区号.md`
- 有无水箱 → `references/元素/水箱.md`
- 气候与生物群系 → `references/元素/气候与生物群系.md`

### 第 2 步：多线索交叉，收窄到大洲/候选国

**至少两条独立线索**。例如：

```
木制电线杆 + 英文字母路牌 + 靠右行驶 → 北美
左行 + 靠左驾驶 → 排除美国，指向南非/肯尼亚/澳大利亚等
```

### 第 3 步：读候选国的区域文件，逐条比对

读 `references/世界/<国>.md`。多数国家文档已按「从北到南」或「行政区分节」排列，
节名形如 `## 大区 > 子区域`，直接按你看到的景观找对应节。

### 第 4 步：易混国家专项

候选有多个且都是常见混淆项时，读 `references/元素/易混国家对比.md`
（墨西哥/西班牙/希腊/土耳其；东南亚；塞内加尔/尼日利亚/肯尼亚；哥伦比亚/厄瓜多尔/秘鲁）。

### 第 5 步：需要精确定位时

读 `references/元素/精确定位方法论.md`（道路特征、道路节点识别、关联道路识别）。

## 铁律

- **先收窄再细查**：不要一上来读具体国家文件，先用元素线索把范围压到大洲/少数国家。
- **至少两条独立线索**才能定国；单条线索（尤其植被、电线杆）常有跨国重叠。
- **注意街景代数与拍摄年份**：同一国家不同年份覆盖特征不同，看画面本身而非「现在长什么样」。
- **本层保留具体地名**（州名、公路编号），这是区域定位必需的对照点；与元素层「去地名」策略相反。
- 线索不足时说明「无法确定到国」，不要硬猜。置信度要标注。
