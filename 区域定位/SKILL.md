# 区域定位

元素层（22×`wlmz-*`）答「**这是什么**」；本技能答「**这里是哪**」。先解元素，再比对国/省特征。

## 何时使用

- 已排除中国 → 定**国家**
- 已定国家 → 缩**省/州/大区**
- 疑似某国 → **验证或排除**
- 中国境内 → 定**省份/城市倾向**

## 输入 / 输出

| | 规格 |
|---|---|
| **输入** | 总技能/元素层已列可见线索（车型、电杆、植被、文字、行车方向等） |
| **中间** | 候选大洲/国；已读`references/`路径列表 |
| **输出** | 候选国/省+节名命中句；回传L级给总技能；未读文件≠已证伪 |
| **禁报** | 本技能单独不报 L3 城市 / L4 点位 |

## 定位流程

### 1. 确认元素线索就绪

若「电杆/植被/文字」含义尚未由元素层解出 → 先加载对应 `wlmz-*`（如`wlmz-jijian`）再进入本流程。无线索可比对 → 回总技能补线索表 → 仍无则「无法定国」L0–L1。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索 | 请总技能补线索表 | 输出无法定国，L0–L1 |
| 线索未解码（只见杆未见类型） | 先读元素层`wlmz-jijian`等 | 再回本技能步骤2 |
| 仅1条软线索（植被/电杆） | 加读1个`元素/`主题 | 并列多国，不定一国 |

### 2. 跨国元素收窄（强制顺序）

1. `元素/街景车与相机代数.md`（最强前置）
2. `电线杆meta.md` → `植被.md` → `语言文字.md` → `电话区号.md` → `水箱.md`
3. 例：`木杆+英文路牌+右行→北美倾向`；`左行→排除美国，指向澳/肯/南非等`

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 文件名不符 | 打开`_index.md`对名 | 用已有线索进步骤3 |
| 候选仍>5国 | 再加文字或行车方向线索 | 只输出大洲级，回传L1 |

### 3. 读候选国/省文件

读`世界/<国>.md`或`中国/<省>.md`；只摘与画面匹配条目进规则摘要。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 文件不存在 | `_index.md`查近义/旧称 | 不定该国；保留其它候选 |
| 节内无匹配 | 试邻省或易混国文件 | 降级L1–L2，列已排除项 |

### 4. 易混国专项

候选属混淆组 → 必读`元素/易混国家对比.md`（墨/西/希/土；东南亚；塞内/尼日/肯；哥/厄/秘）。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 未读对比表 | 立即读取后再裁断 | 并列两国+写明未读原因，不定一国 |

### 5. 精确定位交接

需路网级 → 读`元素/精确定位方法论.md`；点位结论交回总技能 CHECKPOINT。

### 🔴 CHECKPOINT · 🛑 STOP

回传「某国/某省」前任一项为否 → **不得单国断定**：①已读`_index.md`或等价确认文件存在 ②≥2独立线索支持同一候选 ③摘要句来自已读references非记忆臆造 ④易混组已查对比表或显式声明跳过原因 ⑤单文件命中≠定城；定城交回总技能升L3+。

## 测试题执行路径（dim8 · 对照 `test-prompts.json`）

无真图时按文字线索干跑；下列样例为 golden。本技能不报 L3/L4。

| id | 用户说法 | 路径 | 封顶 | golden |
|---|---|---|---|---|
| 1 | 左舵+英文路牌+粗木电杆，美/加 | `_index`→元素电杆/文字→世界≤2国 | L2 | 样例P1 |
| 2 | 墨 vs 西，拉丁路牌+干热植被 | 必读易混对比；并列或倾向 | ≤L2 | 样例P2 |

**dim8 验收门禁**：①三路径均走 ②回传行含已读路径 ③P3=L0且无县名 ④P1/P2 摘要来自 references 文件名。

## 回传行（给总技能）

```
规则摘要：<区域文件节名>：<特征句> → <国/省倾向>
候选国/省：<列表> | 回传等级：L1–L2
已读路径：references/...
```

**golden 样例**

- **P1美/加**：`规则摘要：元素/电线杆meta：粗木杆+英文路牌+左舵→北美｜候选：美国|加拿大｜L2｜已读：_index.md,元素/电线杆meta.md｜缺州名牌→不定州`
- **P2墨/西**：`规则摘要：元素/易混国家对比：干热+拉丁路牌→墨西易混｜候选：墨西哥|西班牙｜L1｜已读：易混国家对比.md｜并列不单定`
- **P3无线索定县**：`规则摘要：无命中｜候选：无｜L0｜补证：可见文字/电杆/行车方向后再加载本技能`

## 反例黑名单

- 一上来通读全部161个区域文件
- 单条植被/电杆线索就定国
- 把区域层地名规则当元素层「去地名」输出
- 未读文件却写「该国无此特征」
- 本技能单独报L3城市/L4点位
- 忽略街景代数与画面年份差异
- 线索不足仍硬猜一国
- 测试题「无线索定县」仍输出具体县名
