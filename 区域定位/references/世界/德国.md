# 德国
> 洲/分类：欧洲
> 来源：德国

## 第一部分：辨别德国
- 德国的所有汽车街景都是使用 四代 相机拍摄的。
- 有极少二代和三代的徒步拍摄街景（trekker），以及较旧日期的越国界溢出街景。
- 德国使用这些 黑白配色 路桩，带有 白色/浅灰色 反光板，十字路口旁边路桩的反光板则会是橙色的。他们有时有包含道路编号以及潜在的其他有用信息的标签。许多路桩的侧面还带有蓝色附件。
- 许多欧洲国家都有类似的路桩，但大多数国家都有不同颜色的反光板。卢森堡使用几乎相同的路桩，但它们在反光板上的螺栓有3个而不是2个。
- 德国的官方语言是 德语 。德语使用特殊字母Ä、Ö、Ü 和 ß。
- 其他有谷歌官方街景的德语国家是瑞士和奥地利。此外，比利时东部和意大利 南蒂罗尔省 也使用德语。
- 德国的大多数木质电线杆都会贴有 矩形白色贴纸 。
- 德国有各种不同的电线杆和杆顶。最常见的杆顶是 带有不对称悬挂绝缘子的水平 杆（如下图1）、 三角形杆顶 和（如下图2）各种 T形杆顶 （如下图3），它们可以有不同的绝缘子设置。
- 德国也有各种各样的警示标牌。值得注意的是这些标牌背面通常是 黑色 或 深灰色 的，这在欧洲相当罕见。大多数标志也会有上图这个贴纸，其中在黑色矩形上有一个倒置的红色三角形。
- 意大利，罗马尼亚和阿尔巴尼亚也有黑色牌背，但景观应该足以区分它们。
- 与奥地利一样，德国使用各种各样的区域巴士站牌，所有巴士站牌上都有大大的 黄绿配色的H符号 。
- 德国的邮箱是 亮黄色 的，并带有这个黑色徽标。
- 德国的大多数道路上会有很多路桩，大概每50米就有一个。
- 德国的城镇入口标志是 黄色 的，使用黑色文字，并带有 金属框架 。
- 这些标志也可以包含许多有用的信息：
- 顶部——城镇/城市名称
- 德国使用这些 蓝色 矩形公里标记，边缘略微看出圆角，边框为白色。
- 在极少数情况下，它们也可能是白色的。
- 这些单向交通标志上写着“ Einbahnstraße ”字样，是德国独有的。
- 在奥地利，标志上会写着“EINBAHN”。
- “禁止停车”和“禁止等待”的牌子上面经常画有白色箭头。
- 在德国，几乎每辆车的挡风玻璃右下角都能看到这种圆形贴纸，通常是绿色的。 虽然知道这点可能没太大用，但绿标上面会写着数字 4。 极少数情况下也会有黄标或红标，上面分别写着数字 3 和 2。
- 在德国， 风力涡轮发电机 比任何其他欧洲国家都要普遍得多。
## 第二部分：辨别区域/州的线索
- 在德国，使用周围的海拔高度对于获得良好的猜测至关重要。以下是一些一般性规律：
- 北部，尤其是西北部非常平坦。
- 另请注意，尽管海拔较高，但德国南部的许多地区仍然可以是平坦的。
- 德国的区号的第一位有分布规律。
- 德国邮政编码从 0 （萨克森）到 9 （巴伐利亚北部）大体上呈逆时针排布。
- 每个德国州都有自己的旗帜设计。不过其中许多很少见。
- 每个德国州都有自己的徽章。
- 这些是一些有用和常见的地名后缀，您可以使用这些后缀来区域猜测德国。由于受斯拉夫民族影响，-ow 和-itz 后缀主要在东部找到。-weiler 和-ach 主要在南部。
- 虽然德国大部分地区使用 B型 护栏，但西北部分却主要使用A型护栏。了解哪些地区如何使用它们可能会很有用。
- 注意 ：总会有极少数例外。
- 德国的自行车标志牌设计一般都是白底绿字。在汉堡、北莱茵-威斯特法伦和临近的下萨克森州的一小部分您能看到红字。萨尔州有独特的设计，是绿底白字的。

- 三角形标志上的双连接器之间通常更宽。
## 第二部分：辨别区域/州的线索 > 景观和植被
- 德国阿尔卑斯山区是德国山区最多的地区，主要位于奥地利边境。
- 波罗的海松（ Pinus sylvestris） 通常更集中在德国 东北部 ，您可以通过橙色的树干来识别它们。
- 这张示意图非常粗糙。
- 您可以在东北部发现靠近树干底部涂成白色的树木。
- 您很少会在上图标记区域之外找到它们。
- 雷根斯堡（Regensburg） 东南部的平坦平原可以通过其东北方向可见 轻微山脊 来识别。平原本身是 平坦 的，而且相当 农业化 。
- 葡萄园主要集中在德国 西南部 ，但注意在更东边也有几个地区种植。
- 您可以在这些区域找到啤酒花种植园（hop）。它们常见于慕尼黑北部。
## 第二部分：辨别区域/州的线索 > 建筑
- 这种砖房通常集中出现在德国 西北部 。
- 茅草屋顶 和 石墙 在 北弗里西亚群岛（North Frisian Islands） 以及石勒苏益格-荷尔斯泰因州大陆区域最常见。您也可以在梅克伦堡-前波美拉尼亚州的 沿海度假小镇 找到它们。

## 第二部分：辨别区域/州的线索 > 基础设施
- 在这些区域能找到带有 深色反光板 的路桩。
- 北莱因-威斯特法伦的一些路桩的顶部有 绿色 的帽子。这些帽子也可以是其他颜色的。
- 北莱因-威斯特法伦州南部有一种独有的路桩，它们戴着绿色的帽子，上有 LVR 的字样，并且带有小 蓝色附章 。
- 这种带有油漆过的顶部的 圆形木制 路桩出现于巴伐利亚。
- 这种路桩外形不规则，下半部没有白色部分包围，出现于 下萨克森州 图示区域的K级别道路。这一地区的K级别道路不会有其他式样的路桩。
- 这些 简陋的橘色立柱 在巴伐利亚最常出现，也经常出现于其他着色区域。
- 勃兰登堡与梅克伦堡-前波美拉尼亚的许多树干上都有这些小小的 绿色金属标记 。它也罕见地出现于下萨克森。
- 巴伐利亚采用这种白色矩形道路标，它们被黑线分为 三个区域 。左部分告诉您现在所在的道路。
- 在下萨克森，可以找到这种带有 弧形边缘 的 四边形 简约道路标。
- 这些在四周有 金属边框 的道路标出现于石勒苏益格-荷尔斯泰因和下萨克森。
- 下萨克森标识上的小数点后的数字往往更小。
- 这些 三角状 的杆子在这些地区很常出现，你可以在下列描述中深入了解：
- 莱茵兰-普法尔茨和萨克森使用的杆子没有经过漆色，长得像石头，四周贴有白色盘状标识。
- 萨兰、图林根和巴登-符腾堡使用的白色杆子有相同的标识，但在除了巴登-符腾堡外的两州，它们通常很高。
- 巴登-符腾堡也会使用灰色的杆子。
- 北莱因-威斯特法伦也使用白色杆子，但四周没有盘状贴纸。
- 黑森很少使用这些杆子，它们的分布很随机。
- 路桩上的这些简单的 白色板 出现在这些州。
- 立于这种 黑色底盘 上的路桩常出现在德国 东部 。
- 莱因兰-普法尔茨是唯一在路桩上使用 橙色板 的州，而其他州使用白色板。
- 与之类似，巴登-符腾堡州是唯一在路桩上使用 灰色 而非白色标识的州。
- 这些带有 红顶 的 白色柱子 遍布整个前东德，但最常见于萨克森-安哈尔特州。
- 在勃兰登堡州可以发现 纯黄 的柱子。
- 萨克森–安哈尔特州有带有白色铭牌的黄色柱子。
- 有时只有一面有这种白牌子，这使其难以与上述勃兰登堡的柱子区分开来。
- 这些 圆形混凝土杆 几乎是前东德独有的。
- 这些 类似三叉戟 的杆顶可以在巴伐利亚州、萨克森-安哈尔特州和巴登-符腾堡州找到。
- 类似于捷克斯洛伐克的 三角形 杆顶在德国西部很常见。
- 在示意图突出显示的区域之外可能会有一些例外情况。
- 这些 中间较厚 的单横杠杆顶可以在前东德的所有地方找到。
- 在巴伐利亚州可以找到具有 弯曲 单横杠的杆顶，尽管它们很少见。
- 这种比较罕见的黑白两色四代街景车会出现在汉堡和法兰克福周围。
- 伦敦和爱尔兰也有。
- 德国全国被Aldi连锁超市一分为二：南部的Aldi Sud和北部的Aldi Nord。
## 第三部分：聚焦
- 柏林 （ Berlin ） 使 用灰边白色标示牌，在街道名下方有一段独立的数字。并请注意字母 ß的特殊字体。
- 慕尼黑（ Munich ） 使用蓝色的路标，并镶有接触不到四角的白边。同样地，请注意特殊的字体。
- 斯图加特（Stuttgart） 使用无边框的 黑色 路标。
- 杜塞尔多夫（Düsseldorf） 的路标与慕尼黑相似，带有白边且为 黑色 ，并且有 金属镶框 。
- 多特蒙德（ Dortmund ） 使用白边灰框蓝色路标，这些路标同样也有一段在街道名下方的独立数字。
- 埃森（Essen） 使用的蓝色路标有非常 厚 的金属边框。
- 德雷斯登（ Dresden ） 使用的蓝色路标有独特的铅字字体。
- 汉诺威（Hanover） 使用的白色路标的标识和金属框之间有较 宽 的间隙。
- 纽伦堡（ Nuremberg ） 使用的蓝色路标有独特的铅字字体。另外，这些路标的四周有距离标识较近的灰色边框。
- 伍珀塔尔（ Wuppertal ） 使用的白色路标有独特的铅字字体。这些路标的四周还有距离标识较近的白色边框。
- 美因茨（Mainz） 的路标分为两种，一种是蓝色路标，另一种是如上图所示的独特 红色 变种。
- 法兰克福（ Frankfurt ） 使用的蓝色路标四周有金属框，并且同样有一段位于街道名下方的独立数字。
- 少数时候，一些小镇也会使用与上图所示路标相似的标识牌。
- 索布语是一种 斯拉夫 语，在德国靠近波兰和捷克的边境通行，会出现在这些地区的各种标识上。
- 每个城市州都会有自己独特易识的公交站牌。
- 柏林使用 分段式 站牌，路标为 黄色 。
- 汉堡公交站的路标为 红色 ，路线编号在一个 六边形 之中。注意，它也在汉堡以外的地区出现。
- 不莱梅通常使用简约的公交站牌，在 一段红色区域 内写有站名。它的边缘也可能是圆弧。
- 不来梅哈芬是不莱梅的一部分，它使用的公交站牌在路标的另一面有一个 灰色的部分 。在一段 黄色 区域内写有 红色 的公交站名。
- 每个市州都遍布标识性的垃圾桶。
- 柏林使用 亮橘色 桶，其上有白色文字。
- 汉堡使用 亮红色 桶，其上有 白色的对话框 。
- 不莱梅使用绿色搭配灰色的桶，其上有 橘色的对话框 。
- 不莱梅哈芬使用更普遍的设计，桶呈 绿色 ，其上有 黑色的标识 。
- 科隆的路灯柱通常具有这些 黑色塑料块上的亮黄色数字 。
- 长相类似的物件也能出现于其他地区。
- 这种在一楼有 拱门 的 半木架结构 房屋在萨克森的这一块十分常见。
- 灌木 和 沙子 覆盖的山丘是西尔特岛独有的。另外，与北弗里斯群岛的其他岛屿一样，岩壁、砖房、茅屋顶非常常见。
- 在这个野生动物园中，你可以发现一辆第三代街景的黑车。
- 这辆黑车是在全欧洲独有的。
- 在汉堡市中心，你可以发现这种稀有的 第三代有天线 的街景车覆盖。
