## 使用方式

1. 可见特征匹配规则左侧 2. 抄命中并标倾向 3. 交回总技能互证（本领域不报 L3+）
无命中→换领域；条件冲突→跳过；单规则→不升格点位。
回传行：规则摘要：<线索> → <结论>

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索命中 | 换领域或加载解题方法论 | 写明本领域无可用规则 |
| 规则与季节/半球冲突 | 跳过该条 | 只输出倾向 |
| 仅命中1条 | 结论止于倾向区域 | 请用户补图或交叉其它领域 |

### 🔴 CHECKPOINT · 🛑 STOP

报城市前须另有独立线索；勿把「多为」写成必然；本领域不单独报 L3+。

## 以图搜图引擎

*各大搜索引擎的反向图片检索*

- 确认开发区后在地图搜索其中的公园等开放地标 → 比对附近建筑形态确认位置
- 特定机构名称配合地图搜索 → 可直接定位到具体点位
- 店名未打码但地图搜不到 → 可换搜索引擎或企业信息平台查地址
- 已知目标在某城市后 → 只需排查该市同类地点逐一验证
- 图中人物为网络热点人物 → 用识图配合短视频平台关键词搜索可定位到城市
- 视频/图片自带评论区的补充信息 → 常比原图本身更接近精确位置
- 手机端识图 → 应按整体、局部、特殊点三个层面分别尝试
- 整体识图返回的是无关类别 → 应改用图中形制特殊的局部物件再识图
- 找到同款物件的图片发布账号 → 可从该账号的其他信息反推地点
- 灯具形制 → 可直接判定特定城市或地区
- 拿"最相似的一张"去识图 → 结果多为同风格建筑，需警惕把仿建当成原型
- 常见、知名地点 → 识图往往直接出结果
- 图中场景明显非拍摄者本人所拍 → 多为网络图片，以图搜图容易命中
- 建筑具有对称性而图中只出现一半 → 镜像补齐缺失部分后再识图可提高命中率
- 识图命中但结果链接失效 → 不能据此确认地点
- 识图结果页无具体位置信息 → 不能据此猜测具体地点
- 以图搜图找到原作者 → 浏览其作品集中背景相同的其他照片可定位地标
- 识图与垂直社区均无结果 → 改用"目标类型+关键词"的图片搜索逐条排查
- 图中主体被树叶遮挡 → 通用识图易优先识别树叶而误导，可换用另一平台的识图功能
- 建筑造型独特 → 值得优先投入通用识图引擎尝试
- 识图给出多个相似目标 → 需用图中独有的细节特征区分，并在另一平台逐个核对
- 以图搜图识别出特定的游乐或园区设施 → 可反推拍摄场景为公园
- 推理链容易出错 → 应以识图结果作为交叉验证手段
- 目标为刚建成的建筑 → 识图通常无结果
- 拍摄角度特殊、非正面外立面 → 识图通常无结果，需想象补全正面形态后再搜
- 知名景区 → 一般可直接识图定位，此类图难度低
- 搜图结果全为同类场景却无完全一致者 → 不能据此确定具体地点
- 同类招牌在多个地区广泛分布 → 识图结果会集中在某一片区域，只能缩小到大范围
- 图片在网络上被大量转载、反复引用 → 识图命中的多为重复转载页，线索价值低，需另找角度
- 图片原址已删除或不可见 → 不要放弃，继续追查发布者、同系列图或存档，常有额外收获
- 图上无文字且整体识图无结果 → 拆出局部区块分别识图，不要用整图一次搜
- 图上存在醒目干扰元素（涂鸦、贴纸、水印、渐变） → 先抹除或裁剪掉再识图
- 识图结果指向一篇图库文章 → 进入该图库检索同系列、同机位的其他图，往往能拿到更清晰的版本
- 识图得到候选图后 → 逐张与原图比对轮廓、地平线、建筑细节，不一致的立即排除
- 照片以天空、晚霞、逆光为主 → 识图命中率低，应转用天文方位、时间与光影推断
- 目标为造型独特、辨识度高的建筑 → 识图成功率高，可优先识图
- 识图返回的商业推广图、广告页、电商图 → 直接过滤，改换图库、街景或专业图片源
- 要确定具体站点、门牌等固定点位 → 用识图锁定；要确定车次、班次等动态信息 → 改用对应的专类数据工具
- 识图成果只确认了地标名称 → 再用该地标的山形、轮廓判断拍摄方位，配合距离推算拍摄点
- 著名标志性地标 → 直接按名称检索即可定位，不必依赖识图
- 识图只能解出常见、特征直白的图 → 特征普通、依赖识图的图解答率最低，应预设其他线索通道
- 同类型题目反复出现用同一张老图 → 识图路线已被穷尽，需从辅助线索（天气、阴影、植被）切入
- 工具有能力边界，识图并非唯一解 → 一题多解，识图只作为路径之一，与其他判读手段并行
- 限制或不使用识图工具 → 会显著降低判读效率，工具辅助应视为常规手段
- 图中有可辨识的山体 → 依据山形与轮廓相似度确认山名，再结合方位与尺度推算拍摄位置
- 已确认大致流域但干流沿线找不到匹配点 → 转向该水系的支流逐段比对
- 建筑外形有辨识度、可能为地标 → 优先识图，命中概率高
- 大图识图无结果 → 裁切局部特征明显的区域单独识图
- 识图无结果 → 将图片旋转后再试
- 识图指向的网站内容缺失或被删 → 改查内容重叠的邻近地区站点
- 识图无结果但返回大量相似主题的标题 → 提取标题关键词到视频平台二次检索
- 同一画面在关键词搜索与以图搜图中结果不一致 → 两种方式应配合使用，不可只信其一
- 识图结果与实景明显不符 → 换用画面中独特小物件（灯具、标识、铺装等）在附近实景中扫查
- 识图反复锁定同一错误结果 → 视为误锁定，更换引擎或改换局部重试
- 识图返回大量同款涂装、同型号的对象 → 命中的是该类产品的典型样本，不能直接当作拍摄地
- 识图给出的多个候选外形相似 → 逐一核对细节差异，排除仅形似的，不取最像者
- 同组照片存在相同室内装饰、光位、家具 → 可判定为同一地点拍摄，定位一张即可推及全组
- 识图命中单栋显著建筑 → 结合周边建筑轮廓、相邻高楼与相对方位，反推拍摄角度与站位
- 分别框选图内多处显著建筑识图 → 结果收敛到同一城市时可信度显著提高
- 拍摄视点位于高处、观景设施或移动载具上 → 可用视角与地平线关系反推站位
- 某类建筑形制在特定类型场所高频出现 → 可由建筑类型反推场所性质
- 画面中的以图搜图结果长期错误率高 → 识图结论必须人工复核，不可直接采信
- 此前识图无结果的图 → 隔较长时间后重新识图，搜索引擎能力升级后可能突然命中
- 对画面中心的多处目标分别识图 → 用于交叉验证，结果一致才作为定位依据
- 识图返回的链接点开后内容为空或已失效 → 该结果不能作为定位依据，需另寻线索
- 识图结果全部指向同一图库或转载站点 → 说明图片是网络泛传图，缺少唯一地理指向
- 画面含标志性建筑且识图可直接命中 → 属于易定位类型，该地标知名度高、被拍摄频率高
- 上一轮识图得到的结果图本身含地标 → 以其为输入继续识图，可逐级逼近目标地点
- 同一地点存在大量游客以同一角度拍摄的照片 → 识图易命中，该角度可作为检索入口
- 某一识图引擎无结果 → 换用其他引擎或平台，各引擎覆盖的图库不同
- 背景中功能不明的建筑 → 识图常无结果，需结合其形制判断用途作为辅助线索
- 原图分辨率不足或模糊 → 识图易失败，应改用画面中清晰的小物件单独截图识图，再用其他特征筛选结果
- 单一线索无果 → 不说明方法无效，应更换识图入口或多方法并行尝试
- 图片角度倾斜、偏色或明暗异常 → 先转正、校正色彩与明暗，使其接近常见拍摄效果，可提升识图命中率
- 识图命中相似图 → 点进原网页或原视频常能获得更多画面，重新截图后再识图可继续推进
- 图片来源为他人随手拍摄 → 拍摄点通常离画面中的地标不远，可在地标周边范围内搜索
- 由地标得到粗略区域后 → 用画面中的其他结构性特征进一步收敛到具体位置
- 可被识图直接命中的图片 → 说明网络已有同源图像，其唯一性受限，定位时需注意来源交叉污染
- 识图结果多为历史照片 → 需考虑拍摄年代与当前街景差异
- 手机端与电脑端识图结果可能不同 → 多端交叉验证
- 具有特色但重复率高的设施（泳池等）识图 → 结果泛化严重，不能直接定位
- 截图识图可能丢失原图元数据/上下文 → 需结合原图
- 多个独立识图引擎指向同一地点 → 定位可信度提高
- 识图只能确定城市级别 → 更细位置需肉眼/街景比对
- 部分题依赖肉眼辨认而非识图 → 识图非唯一手段
- 著名旅游景点/地标有固定机位 → 同构图大量存在，识图易命中
- 摩天大楼等地标 → 可用识图匹配打卡点
- 同款图片多 → 识图结果可信但需排除重复转载
- 画面信息量大、文字清晰未遮挡 → 识图通常可直接命中
- 画面含少量文字和一定信息 → 识图可能失效，需辅助检索
- 画面信息少、文字被去除 → 识图难以命中，需用少量线索在地图上逐点排查
- 文字被刻意去除/打码 → 难度升高，识图不可依赖
- 识图指向的地点与画面周边建筑不符 → 不能直接采信识图结果
- 识图高相似但环境不匹配 → 可能为同名/相似建筑误导
- 画面出现与某地大量相似的同款元素 → 识图会集中指向该地
- 不是依靠文字，而是依靠视觉相似 → 识图也能定位
- 年代久远/低质量老图 → 识图成功率低
- "远古" old images → 识图命中率低，需降低预期
- 常见识图引擎均无法命中 → 需换非常规方法/手动比对
- 多引擎尝试无果 → 说明画面缺乏可检索特征
- 全图识图 → 返回大量相似视频/图片，需从中筛选有效信息
- 手机端识图结果多，网页端结果少 → 端侧差异会影响召回，需多端尝试
- 单一引擎可能命中部分图片但无法覆盖全部 → 需多引擎互补
- 识图结果需向下翻页深挖 → 有用线索可能不在首屏
- 某些目标在公开图库中无匹配 → 识图存在盲区
- 不同识图引擎结果差异大 → 需交叉比对，不能只看一个
- 某引擎返回大量相似结果而另一引擎无关 → 以一致性高的结果为准
- 建筑类照片识图效果好 → 优先用识图定位建筑
- 非建筑/特征弱照片 → 识图不一定适用
- 不使用识图而靠关键词搜索 → 命中依赖运气，稳定性差
- 环境有独特差异 → 仍可通过其他检索找到
- 同类型桥梁等结构识图 → 易被引擎归并到常见同类地标
- 识图反复指向同一知名结构 → 可能是算法偏好/热门图库，不一定准确
- 结构相似度高的目标 → 识图区分难度大
- 识图识别出工业产品型号/出口区域 → 可据此推断使用地区
- 识图识别出道路设施颜色/样式 → 可判断某类高速/公路的地域特征
- 找到并行的大站/建筑 → 可进一步定位到具体路段
- 识图返回大量相似图片 → 需人工筛选其中有地理信息者
- 常规Web识图结果与检索属性结合 → 可判断大致地域倾向
- 识图命中结果的地理属性集中 → 可据此推断目标所在区域
- 路灯等街道设施可识图 → 特定型号可对应特定城市/地区
- 重复出现的市政设施 → 可作为稳定地理标识
- 同一识图引擎多人验证同一结果 → 结果一致性增加可信度
- 识图结果需落实到行政区级别 → 才算完成定位
- 识图结果多为历史照片或旧图库影像 → 目标可能为旧拍，需比对当前街景与年代差异
- 同一张图在手机端与电脑端识图结果不同 → 多端交叉验证，不依赖单端结果
- 截图识图会丢失原图信息与上下文 → 尽量用原图识图，截图仅作补充
- 多个独立识图引擎指向同一地点 → 该地点可信度较高，可作为定位候选
- 识图仅能命中到城市或大区域级别 → 更细位置需结合肉眼辨认与街景比对
- 画面信息充足且文字清晰无遮挡 → 识图通常可直接命中，优先使用识图
- 画面仅含少量文字与部分信息 → 识图可能失效，需用文字与图像特征辅助检索
- 文字被刻意打码或抹除 → 题目难度升高，识图不可作为主要手段
- 识图高相似但周边环境不符 → 警惕同名地点或相似建筑造成的误匹配
- 画面出现大量与某地相似的同款元素 → 识图易集中指向该地，但仍需环境验证
- 年代久远、画质低或经过压缩的图片 → 识图命中率低，成功具有偶然性
- 常见识图引擎均无法命中 → 说明画面缺乏可检索特征，应转向手动比对或地图排查
- 全图识图返回大量相似视频或图片 → 需人工筛选其中含地理信息的画面
- 手机端识图召回多而网页端召回少 → 端侧结果差异明显，应多端尝试并翻页深挖
- 识图返回的相似内容标签与地点无关 → 需区分内容主题与地理线索，避免被主题误导
- 单一识图引擎可命中部分图片但无法覆盖全部 → 需用多引擎互补检索
- 有用线索可能不在识图结果首屏 → 需持续翻页或更换关键词深挖
- 某目标在公开图库中无匹配 → 识图存在盲区，需改用其他定位方法
- 不同识图引擎返回结果差异大 → 以多引擎一致性高的结果为准，不能只看单一引擎
- 建筑类照片的识图效果通常较好 → 优先用建筑外观进行识图定位
- 非建筑或弱特征照片 → 识图不一定适用，需依赖环境特征与手动检索
- 同类型结构（如桥梁）反复识图均指向同一知名地标 → 可能是算法偏好或热门图库，不能直接认定为准确位置
- 相似度高的结构目标 → 识图区分难度大，需寻找局部差异特征
- 识图识别出工业产品型号或出口流向 → 可据此反推使用地区与地理范围
- 识图识别出道路设施的颜色与样式 → 可判断其所属路网或地域特征
- 将识图结果与检索属性结合 → 可判断目标的大致地域倾向
- 多人使用同一识图引擎得出一致结果 → 结果可信度增加
- 识图结果需落实到行政区或具体点位 → 才算完成定位闭环
- 加油站内便利店居中、两侧均可加油且规模偏大 → 位于交通干道旁，而非市中心加油站
- 门店外地面铺设地砖 → 地处城区边缘，而非远离城区的荒野路段
- 市场正在搬迁或已搬迁 → 地图搜索旧市场名称，街景可能仍保留搬迁前的建筑外观

## 浏览器扩展与采集

*截图工具、右键识图扩展*

- 街景影像采集年份与路面标线样式 → 可互相印证年代与地区
- 城区内部不同片区建筑密度与景观风格有差异 → 先按景观类型筛选片区，再从目标片区向外扩展搜索
- 邻近地区同期采集的影像可能共用同一批次编号 → 编号相同不能作为判定同一地点的依据
- 建筑外观新且周边无街景覆盖 → 该区域建成时间晚于街景采集时间
- 街景中某道路尚未建成 → 该道路及沿线建筑晚于街景采集年代
- 境外街景的采集范围可深入荒野 → 荒郊野外的街景画面不排除位于国外
- 同一地区多处街景的拍摄日期一致 → 属同一次采集批次，可用来锁定影像时间
- 街景标注采集时间与画面内容（商铺是否装修、是否开业）相矛盾 → 以画面内容为准判断时间上下界
- 街景采集车没有两侧横杆 → 特定采集车款式，对应特定国家
- 老旧款街景采集车已被大量替换 → 见到它可往更新迟缓的边境地区推测
- 画面由人手持设备拍摄而非车载采集 → 官方采集覆盖薄弱或为特殊采集
- 查遍某一区域仍无匹配 → 排除该区域并向外扩展
- 采集车前部为红白蓝三色涂装 → 可判断街景采集方及覆盖区域
- 非官方覆盖可能由个人设备拍摄，视角与画质区别于官方采集 → 可据此判断该区域无官方街景
- 搜索应从符合画面城乡形态的密集城区开始 → 街景采集集中于人口密集区，偏远公路极少被覆盖
- 同一辆特殊街景采集车 → 可在不同地区重复出现，但显示的街景图标不同
- 已知素材采集渠道 → 优先在该渠道近期内容中找相同街景
- 市政路灯多按批次成批采购 → 同款路灯会在采购单位辖区内重复出现，可沿行政辖区扩展搜索
- 图片来自视频截图或网络采集 → 元数据与原始分辨率不可信，不依赖 EXIF 或文件信息

## 图片增强与处理

*放大、去杂物、去雾、镜像、调色*

- 起飞后高度低、地面细节清晰 → 拍摄点距机场约1至3公里，可据此划定搜索半径
- 验证渠道需按素材清晰度选择 → 模糊图优先用街景实地比对，清晰标识才用视频平台复核
- 城市路灯的款式与高度 → 可与候选路段逐一比对，但需清晰影像支撑
- 地图放大后可悬停预览路网小图 → 用于快速筛查宽路面候选路段
- 街景相机世代及其清晰度、拼接特征 → 可约束拍摄年份下限
- 部分地图服务访问受限 → 需准备可替代的数据源或本地镜像
- 清晰照片中识别出标志性建筑 → 可用建筑名称反查地图，确定路口或街区
- 车窗、玻璃、水面等反射面 → 可能映出拍摄者视线外的招牌，值得放大细读
- 画面中文字朝向与拍摄者相反 → 可能是镜像或透射成像，水平翻转后再辨识
- 画面中车辆行驶方向明确 → 可判断当地道路通行方向，进而推知所属国家或地区，并反推图片是否被镜像
- 图片存在镜像/翻转 → 先校正方向后再识图定位
- 图片存在镜像或翻转 → 先校正方向再执行识图，避免因左右颠倒错失匹配目标
- 画面仅经调色、加水印，无合成增删 → 云形与光影真实，可用于天气与光照判读
- 画面文字左右反向或场景镜像异常 → 可能是镜面图，翻转后再判读文字与地标
- 能清晰辨认的车牌在实景判读题中常被故意设置 → 不应优先采信，需交叉验证其他线索
- 清晰、完整、未打码的车牌 → 可能是刻意设置的误导线索
- 大船上出现需放大才能分辨的移动小色点 → 说明拍摄距离远、船舶尺度大，且船处于作业或航行状态
- 建筑构件比例明显失调、风格混杂 → 疑似放大仿建或拼接，不能作为真实地域风格线索
- 门窗相对建筑体量异常巨大 → 该建筑为按比例放大的仿制品
- 数字的印刷间距与字体特征可辅助判断模糊号码的位数 → 数字不清晰时仍可推断号码长度
- 照片中道路与建筑的相对方位清晰 → 反推拍摄朝向，据此锁定具体路口
- 阴影方向与画面内已知方位参照矛盾 → 先校正镜像或镜头朝向，再用于地理位置判断

## 局部裁剪与拼接

*截取局部区域单独识图；多图拼接比对*

- 路牌被遮挡只剩局部 → 仍可依据该城市特有的路牌样式定位
- 街景水印、拼接痕迹、色彩风格 → 可判断街景来源平台，进而确定可用街景库
- 城市局部特征（阳台、户型布局）→ 可用于判定建筑朝向与取景方位
- 照片各元素风格高度统一但来源存疑 → 应怀疑拼接或摆拍，单点线索须交叉验证
- 全图与局部裁剪分别识图得到一致结果 → 结果可互相印证，可信度提高
- 画面元素过多、结构复杂 → 只截取最具辨识度的局部识图，减少干扰
- 原图分辨率高 → 可放心裁剪局部识图，清除旁边易混淆的干扰物可提高命中率
- 锁定局部特异标识后 → 周边环境可逐步推导
- 画面局部存在独特招牌或门头 → 先锁定该局部检索，可带动整体位置推导
- 站名英文局部字母露出 → 可与站名英文拼写比对锁定站名
- 整体场景可识别但局部细节无法识别 → 先用整体场景定位，再靠局部特征验证
- 整体场景可识别但局部细节不可识别 → 先据整体环境确定大致区域，再靠局部特征验证
- 画面主体与背景的光照、色温不匹配 → 可能是拼接素材，须排除该主体线索
- 题图常被故意压缩或降低画质 → 细节缺失是常态，不因局部模糊排除大尺度特征吻合的地点
- 网络上高频出现的同款地标可能是异地仿建 → 不能作为唯一定位依据
- 同名地点或作品名称出现 → 不能直接判定实际取景地，需区分命名来源与实体地点
- 知名度低的取景画面 → 先定位主要场景，再逐帧比对边角细节地物
