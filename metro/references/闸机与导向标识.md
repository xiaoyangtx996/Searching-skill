# 地铁内景：闸机与导向标识（分城市判读）

> **旁挂**：`SKILL.md` 是「线索 → 结论」规则表；本文是从社区教程整理的**分城市对照表**，补足「只给内景怎么判城市」。
> 素材来源：豆瓣「炒饭网络迷踪」小组教程《中国各城市地铁内景教程》（2025-10 起连载，华北/东北/华东）。
> **说明**：原文配图为网络图片，**未能随文归档**；下表为文字要点。未列城市 = 原文未覆盖。

## 判读优先级

内景题只给闸机/导视时，按此顺序：

1. **闸机门型**：剪式门（二段/一段）vs 三棍机 vs 透明门
2. **刷码/刷脸位置**：顶部平面 / 中部 / 支出来 / 面向左侧
3. **禁止标样式**：`🚫` 圆标 vs `❌` 叉标，有无「禁止出站」汉字
4. **出口标识**：单字「出」vs「出口」；绿底 / 黄底 / 白数字+方框
5. **线路色块形状**：圆形 / 方形 / 与「号线」汉字是否分离
6. **导视字体**与吉祥物轮廓

> 通病：**上海与南通内景极像**，必须核对吉祥物轮廓。

## 分城市要点

### 华北
| 城市 | 闸机 | 导视/出口 |
|---|---|---|
| **北京** | 标准款：**黄色刷码框**，中部有优惠票指示灯；三星款加粗显示屏黑边；大兴机场线加刷掌 | 导向箭头常为**点阵屏**；出口为**单字「出」** |
| **天津** | 与北京相似 | 关键差：出口写**「出口」二字**，非北京的单字「出」 |
| **石家庄** | — | 出口标识**箭头细长**，为京津冀地区唯一 |
| **太原** | 与上海新款类似，**扫脸屏朝左** | **出入口用黄色**标识，站内乘车指引为白色 |
| **呼和浩特** | 刷脸机**支出来**，闸门透明带公司 logo；**六段管**指引检票 | 线路数字色块与「号线」**分离**；蒙文与站名等大 |

### 东北
| 城市 | 闸机 | 导视/出口 |
|---|---|---|
| **哈尔滨** | 参考 JR 配色但仍是**剪式门**；与京冀不同处：哈尔滨用**一段门**，京冀用**二段剪式门**。上方 LED **宋体字**是最强判据 | 乘车标比北京**多一个隧道图形**；出入口黄底、站内白色，用**数字出口** |
| **长春** | **六段管**箭头；刷码区**红色且在刷卡区上方**；银灰闸机 | 出口用**「出」字**，**不用**绿底「出」；无绿色踪迹+提示北方 → 八成长春 |
| **沈阳** | 2/3 号线款刷码区在**顶部平面**；4 号线款相似但提示贴在箭头上方；基本款顶部有优惠灯 | 禁止标为**圆形 🚫 + 「禁止出站」汉字**；站内有**吉祥物**指引；线路色块**圆形** |
| **大连** | 基本款与沈阳同款，但禁止标是 **❌ 非 🚫**；机身贴**云闪付**通道；有三段闸 | 与北京较像，**需核对后**再定城市 |

### 华东
| 城市 | 闸机 | 导视/出口 |
|---|---|---|
| **上海** | 有**三棍机**（注意箭头指向）与新款（看门板形状+五大卡贴纸） | 色块按开通年代不同；世博期老照片为**黄色指向+数字出口** |
| **南京** | 刷码区位置独特，**投票孔两面为斜面** | 出口为**白色数字+正方形边框**；2005 前由港铁外包设计（色块圆形、标志色不同），2010 后新风格 |
| **南通** | **透明闸门**，两侧各一道指示灯 | 导视**很像上海**，极易做错，核对吉祥物轮廓 |

## 提醒

- 内景**判城市不判站点**；精度止于城市，报站需另有线索（店招、站名、线路图）。
- 闸机款式常**同城多款**（不同线路/年代），单款不足以定城，需 2+ 特征交叉。
