## 招牌与广告

*店招品牌与广告语线索*

- 小众品牌多为当地品牌 → 遵循就近原则优先搜索品牌所在地
- 广告牌上的小众品牌通常为当地品牌 → 搜索品牌可初步定位所在城市
- 某类店铺或品牌在区域间的密度差异 → 可辅助排除或锁定区域
- 画面中出现连锁店招牌 → 在电子地图检索该品牌可得其分布区域，再与候选城市逐一比对
- 招牌为全国连锁品牌 → 不能用于缩小地理范围
- 车辆或商品品牌为地方性企业 → 优先在其产地大城市的周边县域搜索
- 无招牌的店面、民房、村庄建筑 → 通常检索不到，不能依赖店名线索
- 同一店名对应多个城市 → 需按店面建筑外观逐一比对排查
- 小众店名、酒店名检索结果少且集中于一省 → 可快速收敛到省级范围
- 画面中直接可见的品牌、楼层号、同层品牌组合 → 可推断商业体类型与连锁商场品牌
- 连锁品牌门店逐点排查均未命中 → 可排除该城市，或该品牌已下沉至乡镇导致大城市检索失败
- 地名检索结果被同名商品或品牌淹没 → 叠加业态关键词后再检索
- 远处店招可辨认出完整品牌名 → 直接地图检索该品牌，再以门店周边建筑与街道设施比对确认
- 远处广告牌的品牌标识或招牌结构可识别 → 结合品牌产地/分布可推断省份或地区
- 边境附近设施 → 可结合品牌跨国分布与边境位置定位
- 商品包装、品牌与地名关联 → 可推断产地或销售区域
- 行业命名限制导致品牌与地名不一致 → 不能仅凭品牌名判断地点，需查包装、产地信息
- 画面中的电话号码区号 → 可直接推断城市或区域
- 连锁商业名称模糊可见 → 按名称模式推测品牌，再查该品牌门店分布
- 画面出现知名品牌或专有名词 → 搜索名称可定位到具体城市或地点
- 商场同时出现多个连锁品牌和特定广告类型 → 品牌组合与广告投放可辅助判断商圈、城市等级和地区
- 家用设备品牌经销网点具有地域集中性 → 可据品牌反推区域范围
- 店面广告或门头上出现可读电话号码 → 可直接联系商家核实位置
- 并排出现的商户组合（银行、连锁品牌、统一定价标语）→ 可用商户组合检索锁定街区
- 宣传标语、口号具有地方专属性 → 全文检索常可唯一指向某地
- 出租车顶灯的形制、颜色与安装方向存在地域差异 → 可据顶灯样式判断城市
- 加油站品牌与站内标识的组合 → 可定位到具体站点
- 同一品牌的赞助式招牌在某地高度普及 → 只反映地域，不能指向单一店铺
- 市政设施为城市统一制式，但其附着的广告内容更新频繁 → 设施样式可判城市，广告内容时效性不可靠
- 护栏广告公司名 → 锁定地区。→ 护栏等市政设施上的广告/厂商信息 → 可检索厂商所在地缩小区域
- 可更换的户外广告内容 → 可作网络检索线索，但受更新周期影响，不能单独断代
- 市政设施上的广告或厂商名称 → 可检索厂商所在地以缩小区域
- 商业品牌出现于画面 → 只能证明该地曾有该品牌，不能精确断代或单独定位
- 路边地产广告中的项目名或宣传语 → 可用于检索，且项目通常距广告位不远

## 路牌与地名

*路牌样式反推城市*

- 路牌是否含英文或双语 → 可快速排除大量城市
- 用"地名加建筑类型"检索地标时先精确关键词、无结果再逐步放宽 → 可提高命中率
- 路牌用 alto 表示停车 → 西语区国家
- 同一片区中路名、社区名、商业街名共用相同前缀 → 多为统一规划的新建城区
- 同一牌面出现多个路名 → 通常同属一个城市，可组合检索
- 画面中同时出现电话号码、路牌、建筑 → 组合线索可用于交叉定位
- 地名用字中的罕见汉字 → 具有地域集中性，可缩小区域范围
- 路牌上的完整道路名 → 可直接检索确定城市与具体位置
- 红绿灯带路名牌和左转待行区指示灯 → 某城市/区域特征
- 模糊蓝底白字路牌、路灯、红绿灯均有特征 → 可判读
- 图中地名出现在校园场景中 → 该地名所指城市的高校可作为排查范围
- 沿线出现蓝色顶棚或路牌 → 存在并行公路
- 路口处指路牌常见 → 路口是指路牌高概率出现位置 → 优先在路口寻找方向/地名标识
- 路牌拼音若保留通名或专名音节 → 可反推道路名称与所在城市命名习惯
- 路口是方向牌、路名牌高概率出现位置 → 优先检查路口
- 地名来源可指向邻国 → 可建立跨国城市关联
- 邻国中与地名相关的城市可能为名人故乡 → 可作历史人物线索
- 路牌、公厕标牌、车位样式、地面标线的统一风格 → 可锁定所在省份或城市范围
- 站牌、路牌的文字字数 → 可推断站名或地名长度
- 站名字数、共有前缀、命名方式（如以路名命名）等文本特征 → 可作区分与筛选线索
- 门牌号出现连续相邻号码 → 该处为小路或非主干道
- 关键文字、路牌、门牌被完全遮挡 → 仅凭道路与巷道形态难以定位，因同类场景普遍
- 地名通名或后缀重复出现且具有地域分布特征 → 可用于缩小地域范围
- 道路指示牌上的地名 → 可确认当前位置
- 同一地点可有多个等价名称 → 判读时接受别名/旧称，但不能用上位地名替代
- 同一地点存在多个名称或别名 → 等价名称可接受，但不能用上级地名替代具体地点
- 已知地名与设施类型组合成关键词检索 → 比单一关键词更快命中具体地点
- 从广告内容难以入手时 → 转向交通信号灯等设施上的路牌文字识别道路名
- 门牌信息、光影条件与庭院风格相互印证 → 提高定位置信度，排除单一线索造成的误判
