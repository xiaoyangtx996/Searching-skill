# 文字残缺推断与补全（旁挂）

> **旁挂文件**：`SKILL.md` 是「线索 → 结论」规则表；本文补足**「文字看不全时怎么办」**。
> 素材来源：用户提供的《网络迷踪入门指南》第 1.1 节案例。

---

## 一、核心原则

> **模糊、残缺、甚至打码的字，都要善加利用——它们很可能成为解题关键。**

**三个不要**：

| ❌ 错误做法 | 为什么错 | ✅ 正确做法 |
|---|---|---|
| 只搜完整的字 | 图里往往只剩残缺字 | **按笔画特征推断**缺失字 |
| 用大品牌当起点 | 全国上千家，搜不动 | 找**独特名词**（见第三节） |
| 车牌当铁证 | 车会跨市跨省跑 | 车牌只作**倾向**，不作锁定 |

---

## 二、残缺字符推断（笔画反推）

**原理**：汉字有结构规律——记住**偏旁部首的形状**，就能从残字反推全字。

### 实例（原文案例）

画面招牌只剩「会□□日」「□公寓」，中间字不可辨。推断过程：

| 观察 | 推断 |
|---|---|
| 第二个字有**厂（尸）字头** | 候选：展 / 屋 / 层 / 居… |
| 第三个字有**单人旁（亻）** | 候选：假 / 住 / 休 / 位… |
| 前后文「会□」 | → **会展** |
| 前后文「□日」 | → **假日** |
| 合起来 | **会展假日**（酒店） |

→ 地图搜「会展假日酒店」→ 深圳市宝安区凤塘大道 612 号 B2 栋会展假日酒店鸿利来分店 ✅

### 常见偏旁速查（判读用）

| 残字特征 | 可能部首 | 常见字 |
|---|---|---|
| 厂 / 尸 字头 | 厂、广、户、尸 | 展、屋、层、居、广、店、府 |
| 亻（单人旁） | 人 | 假、住、休、位、作、伟 |
| 氵（三点水） | 水 | 江、河、湖、海、洗、汽 |
| 钅（金字旁） | 金 | 银、行、铁、钢、镇 |
| 辶（走之底） | 辵 | 道、达、运、通、远 |
| 艹（草字头） | 草 | 花、苑、园、茶、药 |
| 宀（宝盖头） | 宀 | 家、宫、宾、宅、室 |
| 扌（提手旁） | 手 | 招、接、推、提、指 |
| 讠（言字旁） | 言 | 请、话、语、说、记 |
| 礻/衤 | 示/衣 | 社、神、初、补、装 |

**用法**：
1. 先数**字数**（几个字、几个偏旁）
2. 按偏旁列出候选字
3. 与**常见词搭配**组合（会展假日、XX公寓、XX银行…）
4. 组合结果去地图/搜索引擎验证

## 三、大品牌不能当起点（重要反例）

**原文案例**：图里留了一个硕大的「**汉庭优佳酒店**」——这是最显眼的文字。

**但这是陷阱**：

```
地图搜「汉庭优佳酒店」→ 全国近千家，光上海就有 112 家
```

**正确做法**：找**不显眼但独特**的字。
→ 注意到照片最右侧**垂直招牌上还有三个字** → Photoshop 透视变换 → 认出「**陶源丰**」
→ 搜「陶源丰」→ **唯一检索结果** = 晋中市平遥县陶源丰新天地（顺城路店）✅

### 判据：选哪个词当起点

| 词的性质 | 数量 | 该不该当起点 |
|---|---|---|
| 全国连锁大品牌（汉庭/肯德基/中石化） | 上千 | ❌ 不 |
| 区域性连锁（某省某市的中型品牌） | 几十~上百 | ⚠️ 需配合其他线索 |
| **独特专名**（陶源丰、某某花园、某某大厦） | 1~几个 | ✅ **最佳起点** |
| 门牌号 + 路名 | 唯一 | ✅ 最佳 |

**口诀**：**宁可找角落里的独特小字，不要用正中央的连锁大名。**

## 四、楼盘广告补全法（原文案例）

**场景**：画面有楼盘围墙广告，文字被打码，只剩「**公园洋房 6850 01\*\***」。

**场景知识**：这种广告用于**正在开盘中的楼盘附近** → 知道楼盘名 ≈ 知道拍摄位置。

**推断链路**：

| 步 | 内容 |
|---|---|
| 1 | 城市已知（作者称重庆）→ **区号 023** |
| 2 | 房产营销电话图吉利，尾号常见 **88 / 66 / 00** |
| 3 | 号码**倒数第三位是 1** → 后两位很可能是**连号 11** |
| 4 | 从 `023-68500188` 开始试 → 查到是**化工公司**（不对） |
| 5 | 再试 `023-68500166`、`023-68500111` |
| 6 | `023-68500111` 命中 → 排名第一是「**金地首创两岸风华**」楼盘，**明确给出售楼部地址** ✅ |

→ 定位：重庆市南岸区福民路 24 号两岸风华，西门向南 50 米处。

**可迁移的经验**：
- **区号 + 残缺号码 + 尾号习惯** → 逐个爆破
- 房产/服务类电话的**尾号有行业习惯**（88/66/00/11/888/666）
- 电话一旦搜到**企业名**，企业名往往能反查**地址**

## 五、配套工具

| 用途 | 工具 |
|---|---|
| 提高可识别性、防抖、**透视变换**（把斜拍招牌拉正） | Photoshop / [photopea](https://www.photopea.com/)（免装） |
| 去除遮挡物 | [cleanup.pictures](https://cleanup.pictures/) |
| **模糊 logo 重绘** | 肉眼看个大概 → 手动描一遍 → 再用重绘稿去搜图 |

| 长途电话区号 | https://www.ip138.com/post/ |
| 全国车牌查询表 | https://www.ip138.com/carlist.htm |
| 世界车牌样式库 | http://www.worldlicenseplates.com/ |

> **透视变换是读招牌的关键操作**：垂直招牌、斜拍文字直接 OCR 会失败，
> 拉正后成功率大幅提升（本地可用 `imgprep.py zoom` + 手工拉正）。

## 六、局限

- 笔画推断**有失败率**：偏旁相同字数很多，必须**回地图验证**（推断只是假设）
- 电话号码爆破**可能全错**：号码可能已停用、非吉利号
- 大品牌虽然不能当**起点**，但当**交叉验证线索**仍有价值（如"有汉庭"说明是城区）
- 手动重绘 logo 属于主观操作，**重绘稿只能用于搜图，不能当画面证据**
