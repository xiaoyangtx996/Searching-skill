## 船型识别

*货轮/邮轮/渔船等船型*

- 画面出现飞机/船舶等移动目标 → 不能默认其注册地、所属国与拍摄地一致，需结合背景地物定位
- 沿河高层建筑密集 → 城市规模较大，可按大城市排查
- 出现已逐渐淘汰的渔具或作业方式 → 该区域仍保留传统渔业，可用于缩小地域范围
- 船舶能与码头平行并横向平推靠泊 → 该船具备侧推或全回转推进，多为港作、工程或渡运船，说明近旁有码头
- 船上出现桁杆等渔具结构 → 可识别作业类型，进而锁定对应渔场海域

## 船籍与舷号

*船名与舷号判断船籍港*

- 悬挂国旗、横幅的具体方式与朝向具有地方习惯性 → 可作为城市或地区的弱线索，需与其他要素互证
- 场所悬挂外国国旗或使用外文标识 → 提示经营者国籍或菜系，间接指向侨民聚居区
- 国旗出现在非官方场合 → 可能为装饰或仿制品，不能直接等同于所在国
- 船首船名清晰可辨 → 可依船名的文字加编号规则检索船舶登记信息，反推船籍港与作业水域
- 区域氛围相似的国家可能多个 → 优先寻找国旗、车牌、语言等确定性标识而非凭氛围定国

## 港口与码头

*码头设施判断港口*

- 海岸线走向与轮廓具有地域特征 → 可用于排除或锁定沿海区域
- 居民建筑成群且沿河分布 → 居民点通常临水而建，可沿岸线搜索房屋群
- 岛屿周边水色偏灰浊、多泥沙且岸线受侵蚀 → 多位于近大陆的浅海大陆架
- 岸线或水线异常杂乱且呈人工切割状 → 倾向港口、运河或填海密集的城市
- 北半球河流受地转偏向力影响右岸侵蚀较强 → 港口码头多分布在河流右岸，右岸经济更发达
- 画面中出现多台起重机械与成片规则正方形房屋 → 判断为港口或临水工业区
- 码头岸线一侧为散货堆场、另一侧为集装箱堆场 → 属大型综合性港口，可据功能分区反推岸线走向与拍摄方位
- 画面中集中出现集装箱与半挂车短驳 → 位于集装箱码头或集疏运通道附近
- 路面宽阔、非高速但大型货运车辆密集 → 大概率为港口城市或重工业城市
- 河堤高度低且不向河道凸出 → 难以建设大型塔吊码头，可排除大型内河港口
- 夜间为高亮度白色泛光且照明连片 → 多为港口或工业区，而非旅游区
- 水体边缘有规则突出的码头构筑物 → 为公园游船码头，可据此搜索城市湖公园
