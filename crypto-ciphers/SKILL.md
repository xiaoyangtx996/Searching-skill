# 密码与加密

古典密码、编码转换、隐写与多层解密——**为主技能提供"文字被加密了怎么办"这一步**。

> 含《凯撒密码加密解密说明》《网迷×解密 奖励至少400fbi 答案解析》《密寻杯-2024秋季特别活动 答题思路》
> 《2024冠军联赛春季赛第十六期解题思路》《秋季赛第十七期解密思路》等。
> 收录**可复用的判读与解密规则**，不收录单题答案。

## 何时加载

画面或题目中出现：密文串、Base64 样字符、摩斯码、二维码/条形码、二进制串、
「解密/破译/密码/编码」字样、图片/音频隐写线索时加载本技能。


> **产出去哪**：解出的明文 / 编码类型 → **必回灌** `language-script` 做文本判读（字体、语言、地名）。详见 `docs/技能互联·产出手册.md`。
## 使用方式

每层必须留下记录，格式固定三行（缺一行=跳步）：

```
层号：N
形态：编码 | 加密 | 哈希 | 隐写 | 未识别
结果：<本层输出原文或「缺密钥/仍乱码」>
```

| 步 | 输入 | 立刻做 | 输出 |
|---|---|---|---|
| 1 | 密文/点划/二维码/文件 | 对指纹表（下）取形态；`U2Fsd`→加密勿当 Base64 | 形态 + 是否需要密钥 |
| 2 | 形态=编码 | 剥一层（Base/摩斯/扫码等）；记下完整输出 | 本层结果；可读→进步 4；仍乱码→多层，回步 1 |
| 3 | 形态=加密 | **先找密钥**（日期/期号/答案回填/UID）；有密钥再解 | 明文或「缺密钥」；禁止硬猜 |
| 4 | 可读明文 | **必回灌** `language-script` | 本领域不报 L3+ |
| 5 | 复制后长度异常 / 图文件异常 | 零宽、改扩展名、文件尾；或交 `reverse-image` | 隐写结果进步 1 |

指纹（步 1 先查这里）：

| 看见 | 形态 | 动作 |
|---|---|---|
| 以 `U2Fsd` 开头 | OpenSSL **加密** | 找密钥，不硬解 |
| `A-Za-z0-9+/` 常带 `=` | Base64 **编码** | 剥一层；乱码=多层 |
| 仅 `.` `-` / `·` `—` 与空格 | 摩斯 **编码** | 解码；不需要密钥；不定城 |
| 仅 `0-9A-F` 偶长度 | Hex **编码**（或 MD5 等哈希） | 先转文本；32/16 位再试 cmd5 |
| 仅 `0`/`1` 长串 | 二进制 **编码** | 转进制再判下一层 |

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 看不出是何种编码 | 开 https://gchq.github.io/CyberChef/ 自动识别 | 记录字符集与长度，按长度反查 |
| 解出一层仍是乱码 | 判定为**多层**，层号+1 再跑步 1 | 逐层记录，禁止跳步下结论 |
| 需要密钥 | 回题目找日期/期号/UID/答案回填 | 标记「缺密钥」，不硬猜、不定点 |
| 疑似隐写 | 查零宽字符、改扩展名、看文件尾 | 交 `reverse-image` 做像素级分析 |

### 🔴 CHECKPOINT · 🛑 STOP

**不要跳步**：每解一层都要记下结果，多层解密跳步必错。
**不要硬猜密钥**：密钥通常在题目/用户名/答案里，猜不出就标记缺密钥。
本领域**不报 L3+**，解出的明文交回主技能落地定位。

## 反例黑名单

- 把「加密」当「编码」硬解；多层解密跳步；无密钥硬猜；
  只看一层就下结论；忽略零宽字符（复制后长度异常）

## 第一判断：编码还是加密

- 密文可**直接**解出可读文本（无需密钥）→ **编码**（Base 系列/XXencode/UUencode/摩斯/二维码）
- 密文需**密钥**才能解 → **加密**（凯撒/维吉尼亚/Atbash/DES/AES/RC4/Rabbit/3DES）
- 编码可**无限叠加**，逐层剥即可；加密必须**先找密钥**
- 密文以 `U2Fsd` 开头 → OpenSSL 系加密（AES/DES/3DES/RC4/Rabbit），**非编码**，必须找密钥

## 古典替换密码

- 单表位移且可枚举 → **凯撒密码**；英文字母表长 26，偏移量对 26 取余；正数左移、负数右移
- 凯撒枚举无解 → 试**维吉尼亚**（多表位移，需密钥）
- 字母表首尾对应（a↔z、b↔y、m↔n）→ **Atbash（埃特巴什）**；对应表即字母表正序对倒序
- 多表位移且密钥常来自题目 → **维吉尼亚**；密钥是题目给的词/用户名，不一定是数字
- 单表代换且正文较长 → 用**字频分析**（英文字母 e/t/a 频率最高；中文查常用字频）
- 数字串对应键盘按键 → 试**键盘代换**，按美式标准键盘还原出拼音/英文
- 凯撒密钥为数字且题中给了多个数字 → 常见组合方式：年份+期号+位数（如 2022 年 + 17 期 + 10 位 → `20221710`）

## 编码转换

- 字符集为 `A-Za-z0-9+/` 且常以 `=` 结尾 → **Base64**
- 仅含 `0-9A-F` 且长度为偶数 → **Base16（十六进制）**；先转文本再判断下一层
- 十六进制定长（32 位/16 位）→ 可能是 **MD5** 等哈希，优先在线反查（cmd5）
- 全由 `.`/`-`（或 `·`/`—`）和空格组成 → **摩斯电码**；中文站点常用 `·`=点、`—`=划，需用中文摩斯站点解
- 只有 `0`/`1` 的长串 → **二进制**；可转 32 进制等再解
- Base 系列按进阶顺序试：Base16 → 32 → 58 → 64 → 85 → 92 → 99 → 100
- XXencode / UUencode 常用于**多层链路**中段，解出后继续套下一层
- 「与佛论禅（佛曰）」是中文圈特有编码，用专门站点解
- 二维码/条形码 → 先扫码，扫不出再考虑图片隐写

## 隐写与容器

- 文本复制后**长度异常**或含不可见字符 → **零宽字符隐写**（U+200B/200C/200D/FEFF），用零宽解密工具
- 图片直接解不出 → 试**图片隐写解码**（LSB 等）
- 图片反相后出现 0/1 串 → 反相即得二进制，再转进制
- 图片改扩展名为 `.zip` 能打开 → 容器隐写，解压后常得**加密文件 + 音频**
- 音频文件 → 试 **SSTV** 解码（可得二维码/图片）或频谱隐写
- 文件尾部异常、EXIF 异常 → 检查二进制尾部追加数据 / 元数据
- 短链接短码、文件名本身可能是**隐藏入口**（如视频名 `NIVhyB` → `mdl.ink/NIVhyB`）

## 密钥获取（网迷特色）

- 密钥常在**题目线索**里：日期、期号、位数、字数等组合
- 密钥常**回填**：把前序关卡/题目的答案当下一层密码（如航班号 `GJ8060` 作密码）
- 密钥常与**社区账号**有关：炒饭 UID → 用户名 / 个性签名
- 提示中出现「keyword:数字」→ 数字多为社区 UID，去查该用户信息
- 可枚举的短密钥（如纯数字）→ 写脚本枚举，不手工试
