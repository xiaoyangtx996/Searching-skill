# 密码与加密

古典密码、编码转换、隐写与多层解密——为主技能提供「文字被加密了怎么办」这一步。只收可复用规则，不收单题答案。

## 何时加载

画面或题目中出现：密文串、Base64 样字符、摩斯码、二维码/条形码、二进制串、
「解密/破译/密码/编码」字样、图片/音频隐写线索时加载本技能。

**产出去哪**：解出的明文 / 编码类型 → **必回灌** `language-script`（字体、语言、地名）。详见 `docs/技能互联·产出手册.md`。

## 使用方式

每层必须留下记录，格式固定三行（缺一行=跳步）：

```
层号：N
形态：编码 | 加密 | 哈希 | 隐写 | 未识别
结果：<本层输出原文或「缺密钥/仍乱码」>
```

| 步 | 输入 | 立刻做 | 输出 |
|---|---|---|---|
| 1 | 密文/点划/二维码/文件 | 对指纹表（下）取形态；`U2Fsd`→加密勿当 Base64 | 形态 + 是否需要密钥 |
| 2 | 形态=编码 | 剥一层（Base/摩斯/扫码等）；记下完整输出 | 本层结果；可读→进步 4；仍乱码→多层，回步 1 |
| 3 | 形态=加密 | 按「密钥清单」自上而下找；命中再用下方命令解 | 明文或「缺密钥」；禁止硬猜 |
| 4 | 可读明文 | **必回灌** `language-script` | 本领域不报 L3+ |
| 5 | 复制后长度异常 / 图文件异常 | 零宽、改扩展名、文件尾；或交 `reverse-image` | 隐写结果进步 1 |

指纹（步 1 先查这里）：

| 看见 | 形态 | 动作 |
|---|---|---|
| 以 `U2Fsd` 开头 | OpenSSL **加密** | 密钥清单 → `openssl`/`CyberChef`；无密钥停 |
| `A-Za-z0-9+/` 常带 `=` | Base64 **编码** | CyberChef Recipe: `From Base64`；乱码=多层 |
| 仅 `.` `-` / `·` `—` 与空格 | 摩斯 **编码** | 中文摩斯站或 CyberChef `From Morse Code`；不定城 |
| 仅 `0-9A-F` 偶长度 | Hex **编码**（或 MD5 等哈希） | `From Hex`；长度 32/16 → cmd5，不硬逆 |
| 仅 `0`/`1` 长串 | 二进制 **编码** | `From Binary` 后再对指纹表 |

### 密钥清单（加密必走，自上而下，找到即停）

1. 题面日期 / 期号 / 位数 / 字数 → 拼接（例：`2022`+`17`+`10` → `20221710`）
2. 前序关答案回填（航班号、站名、上一关明文）
3. 提示 `keyword:数字` → 按社区 UID 查用户名/签名
4. 题面可见英文词 / 用户名（维吉尼亚密钥常为此）
5. 仍无 → 输出「缺密钥」，**🛑 STOP**，不问用户猜、不定点

### 命令级动作（有密钥或编码层才跑）

```text
# Base64 / Hex / Morse（浏览器）
https://gchq.github.io/CyberChef/  → 粘贴 → Recipe 选 From Base64 | From Hex | From Morse Code → Bake
记下输出全文，再对指纹表。

# OpenSSL 盐头（本机，密钥已知时）
openssl enc -d -aes-256-cbc -a -in cipher.txt -k "<密钥>" -out plain.txt
# 失败再试 -aes-128-cbc / -des；仍失败 → 结果写「密钥不对或算法未命中」，不换随机密钥扫街
```

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 看不出是何种编码 | 开 https://gchq.github.io/CyberChef/ 自动识别 | 记录字符集与长度，按长度反查 |
| 解出一层仍是乱码 | 判定为**多层**，层号+1 再跑步 1 | 逐层记录，禁止跳步下结论 |
| 需要密钥 | 回题目找日期/期号/UID/答案回填 | 标记「缺密钥」，不硬猜、不定点 |
| 疑似隐写 | 查零宽字符、改扩展名、看文件尾 | 交 `reverse-image` 做像素级分析 |

### 🔴 CHECKPOINT · 🛑 STOP · 缺密钥

密钥清单 1–4 全空 → **立即停**。只出黄金出货 A 形态（缺密钥）；禁止猜钥、禁止报城。

### 🔴 CHECKPOINT · 🛑 STOP · 层记录

缺「层号/形态/结果」任一行 → 视为跳步，退回补记后再继续。
本领域**不报 L3+**；可读明文 → 必回灌 `language-script`。

## 黄金出货（对照即用）

**A · `U2Fsd` 开头要解密定位**
```
层号：1
形态：加密
结果：OpenSSL 系；缺密钥；不硬解；不定点
```

**B · Base64 解完仍乱码**
```
层号：1
形态：编码
结果：<Base64 输出原文>
层号：2
形态：未识别｜编码｜加密
结果：多层，继续剥；禁止跳步定城
```

**C · 点划串、无密钥、问城市**
```
层号：1
形态：编码
结果：摩斯；不需要密钥；明文交 language-script；不定城
```

## 反例黑名单

| 不要做 | 为什么 | 改做 |
|---|---|---|
| 把 `U2Fsd…` 当 Base64 硬解 | 那是 OpenSSL **加密**头，不是编码 | 先找密钥；缺密钥就标记，停本层 |
| 多层解密跳步 / 不记中间结果 | 中间层丢失后无法回退核对 | 每层写「层号/形态/结果」三行 |
| 无密钥硬猜 AES/DES/维吉尼亚 | 密钥在题目线索里，猜错会假明文 | 标「缺密钥」；仅短数字钥可脚本枚举；否则停 |
| 只剥一层就下定位结论 | 网迷题常见编码叠加密 | 乱码=继续剥；可读才回灌 `language-script` |
| 忽略复制后长度异常 | 常是零宽隐写 | 先查 U+200B/200C/200D/FEFF |
| 摩斯/Base64 明文未出就报城市 | 本领域不报 L3+；编码≠地点 | 明文交 `language-script`，由总技能落地 |
| 把 MD5/哈希当可逆编码硬解 | 哈希不可逆 | 走 cmd5 等反查；查不到就记「哈希未命中」 |
| 把密文串本身当地名/坐标 | 密文无地理意义 | 只报形态与解密状态 |

## 扩展指纹 · 古典替换（步1 主表未命中时）

| 看见 | 形态 | 立刻做 |
|---|---|---|
| 单表位移、可枚举 26 偏移 | 凯撒 | 偏移对 26 取余；枚举 0–25；正数左移、负数右移 |
| 凯撒枚举无解 + 题面有词/用户名 | 维吉尼亚 | 密钥走「密钥清单」；多表位移 |
| a↔z、b↔y…首尾对应 | Atbash | 正序对倒序替换 |
| 长英文单表代换 | 字频分析 | 英：e/t/a 最高；中文查常用字频 |
| 数字串贴键盘位 | 键盘代换 | 美式 QWERTY 还原拼音/英文 |
| 题面多个数字可拼 | 凯撒数字钥 | `年+期+位数`（例 `20221710`）→ 密钥清单第 1 条 |

## 扩展指纹 · 隐写与容器（步1/步5）

| 看见 | 形态 | 立刻做 |
|---|---|---|
| 复制后长度异常 / 不可见字符 | 零宽 | https://330k.github.io/misc_tools/unicode_steganography.html |
| 图解不出 | LSB 等 | 隐写工具；或交 `reverse-image` |
| 反相后见 0/1 | 二进制图 | 反相 → `From Binary` |
| 改扩展名 `.zip` 能开 | 容器 | 解压；常得加密文件+音频 |
| 音频 | SSTV/频谱 | SSTV 解码或看频谱 |
| 文件尾/EXIF 异常 | 尾部追加 | 查二进制尾与元数据 |
| 短码文件名 | 隐藏入口 | 例 `NIVhyB` → 试 `mdl.ink/NIVhyB` |
