# 云识读

**先认出这是什么云，再由云反推拍摄地点的地理条件。**

元素层答「这是什么」；本技能答「**这是哪类云、它意味着什么地理条件**」。
云是少数能同时约束**纬度、地形、海陆、季节**的线索——荚状云指着山，平流雾指着海，
珠母云指着高纬冬季，环天顶弧要求太阳高度角 ≥58°。整片天空无法被移除或替换。

> 收录 78 条判读规律。云属分类与拉丁名取自世界气象组织《国际云图》公开标准。

## 何时加载

- 照片里**天空占据较大比例**，或出现明显的云型、晕、虹、霞、雾
- 画面缺少文字、车牌、建筑等强线索，需要从**天空**这一维度收窄范围
- 已有候选地点，需要用云型**验证或排除**（气候带、季节、半球是否吻合）

## 输入 / 输出

| | 规格 |
|---|---|
| **输入** | 总技能已列的可见线索（云型、天空比例、有无日/月、降水迹象） |
| **中间** | 云族 → 云属云种；命中的「云 → 地理」条目 |
| **输出** | 云种判定 + 地理条件约束（有山/靠海/高纬/暖季）+ 命中句；回传 L 级 |
| **禁报** | 本技能单独**不报 L3 城市 / L4 点位**，只给地理条件约束 |

## 判读流程

```
① 定云族（看云底高度：低 <2000m / 中 2000-6000m / 高 >6000m）
② 定云属云种（用「易混对判据」逐对排除）
③ 读「云 → 地理指向」，得到纬度/地形/海陆/季节约束
④ 与 wlmz-guangying-tianwen（太阳方位）、wlmz-tianqi（气候）交叉验证
```

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 看不到云底高度 | 用日/月轮廓与地物尺度估族 | 只报「高云/中云/低云」不报云属 |
| 分不清相近云种 | 用「易混对判据」逐对排除 | 写明两种可能，标注不确定 |
| 只有一朵云 | 换其它维度（地物/植被/建筑） | 只输出地理条件约束，不定点 |
| 云型与季节冲突 | 核对半球与纬度 | 以画面实际特征为准，不硬套 |

### 🔴 CHECKPOINT · 🛑 STOP

云给出的是**地理条件约束**（有山/靠海/高纬/暖季），不是坐标。
**单朵云不报 L3+**；无第二独立线索时不报城市/点位。
云形态会相互转化，单张照片易误判 → 不确定就写明不确定。

## 反例黑名单

- 见到圆盘状云就断言荚状云（还需：边缘锐利光滑、多层叠置、驻留不动、伴山）
- 把「积云 → 好天气」当成绝对判据（浓积云、积雨云同样是积云类）
- 由单一红霞推断具体时间（红霞只能给出日出/日落区间）
- 把航迹云当成自然云种参与气候判断
- 用云型单独定位到城市或点位

## 识别基础 · 三族与云属

*由云底高度分族，先定族再定属*

- 云按云底高度分三族：低云族（云底 <2000 米）、中云族（2000~6000 米）、高云族（>6000 米）
- 中云族高度随纬度变化：两极附近偏低、热带附近偏高 → 同一云属在不同纬度外观尺度不同
- 低云族 积云 Cu · 层积云 Sc · 层云 St · 积雨云 Cb（积雨云垂直发展，可贯穿三族）
- 中云族 高积云 Ac · 高层云 As · 雨层云 Ns
- 高云族 卷云 Ci · 卷积云 Cc · 卷层云 Cs（高云族全部由冰晶组成，呈半透明）
- 命名优先级：云种 > 云亚种 > 云变种 > 补充特征 > 附属结构；多种云共存时按主导者称呼

## 识别基础 · 易混对判据

*用手、影、光晕等可操作特征区分相近云种*

- 层积云 vs 高积云：地平线 30° 以上伸直手臂，小云块宽度大于三指并拢宽度 → 层积云（近、块大）
- 卷积云 vs 高积云：小云块表观宽度小于一指宽、无阴影、无光晕 → 卷积云（约 9500 米高空）
- 浓积云 vs 积雨云：有闪电/雷击/冰雹，或顶部出现砧状平顶 → 积雨云；仅花椰菜状塔、无雷电 → 浓积云
- 雨层云 vs 蔽光高层云：有连续性降水且有碎雨云（破片云）相伴 → 雨层云；无降水或降水不连续 → 高层云
- 卷层云 vs 高层云：薄到能透出日/月轮廓（低太阳时除外）→ 卷层云；已看不清日/月轮廓 → 高层云
- 层云 vs 雾：同属贴地云，被楼顶或山腰截断、能见度尚可 → 层云；贴地遮蔽地面目标 → 雾/霭
- 积云典型云底高度 300~1500 米；高云族典型高度 5000 米以上 —— 可用于反推画面中的高度尺度
- 碎积云/碎层云（云缕状碎片）→ 未成形或正在消散，不能作为天气趋势的稳定判据
- 云的形态会相互转化（卷积云冻结后转卷云/卷层云）→ 单张照片易误判，需结合其他线索

## 识别基础 · 光学现象

*晕、虹、彩、光柱的成因与出现条件*

- 晕（22° 晕、46° 晕）→ 由六角冰晶折射，必背靠卷状云或钻石尘（高云/极地低温）
- 幻日 → 冰晶水平板折射，出现在与太阳同高度的两侧，跨地平线低空
- 环天顶弧 → 需太阳高度角 ≥58°，中纬度地区只有夏季正午前后才可能出现
- 日柱 → 冰晶竖直板反射，出现在太阳正上方或正下方
- 虹彩云（云虹彩）→ 小云滴/冰晶衍射，出现在高积云、卷云或幞状云边缘，太阳高度角约 10°~40° 时最明显
- 华 → 光源穿过薄云中极小水/冰粒衍射，呈同心圆环包住日/月；靠云粒大小决定环径
- 宝光/布罗肯弧 → 背对太阳、面向云雾（山顶、云海）时，自己的影子被彩环包围
- 曙暮光条 / 云隙光 → 地平线以下的太阳被云层遮挡，光线自云隙射出；辐合点即太阳方位
- 反云隙光 → 出现在太阳对面的天顶反侧，两条光带辐合于反日点；有反云隙光则必有云隙光
- 维纳斯带 → 日出前/日落后地平线上 10°~20° 的玫瑰粉色带，其下黯淡带为地球本影
- 彩虹 → 太阳在背后、雨滴在前方，虹心即反日点；地面遮挡时看不到半圆以上
- 雾弓 → 雾滴代替雨滴形成，需雾滴细小均匀，常见于清晨雾将散时
- 霞（晨/暮）→ 太阳接近地平线、大气水汽多；红霞程度反映低层大气含水量

## 识别基础 · 人为与特殊云

*航迹云、火积云、雨幡洞云等非自然云*

- 航迹云（凝结尾迹）→ 飞机飞行产生；短时间快速变化，或持续拉长扩散为人为转化卷云
- 火积云 / 烟积云 → 由热源（山火、冷却塔、工业排热）触发对流形成，指示人为热源地物
- 雨幡洞云（空腔云）→ 飞机穿过含过冷液滴的中层云（多为高积云）触发冻结形成孔洞
- 糙面云（asperitas）→ 翻腾起伏的云底，多见于层积云/高积云，指示大气不稳定
- 开尔文-亥姆霍兹波 → 云层边缘卷曲成波浪；条件合适时卷云、高积云、积云、层云、层积云都可能产生

## 云 → 纬度与半球

*由云种反推纬度带或南北半球*

- 珠母云（极地平流层云）→ 只出现在高纬度冬季，斯堪的纳维亚北部、加拿大北部、南极洲等高纬地区
- 夜光云（极地中层云）→ 只出现在纬度 50° 以上；北半球 6~7 月、南半球 12~1 月可见
- 极光出现于高纬；南极光常比北半球极光更偏红（观测距离更远所致）→ 可区分南北半球高纬
- 气辉（夜间天空微绿/微红）→ 全球可见，但需光污染极少处，可作荒野环境的弱证据
- 钻石尘 → 严寒晴夜的高纬或高海拔环境，配合日柱/光晕出现
- 中云族高度按纬度上抬：两极附近偏低、热带偏高 → 可用于交叉核对候选纬度
- 环天顶弧需太阳高度角 ≥58° → 中纬度只有夏季正午可达，低纬则全年常见
- 高云族（全部冰晶）在热带也能达 9~10 公里以上高度 → 热带高云常显得更白、更亮

## 云 → 地形

*由云种反推山体、谷地、坡向*

- 荚状云（透镜云/飞碟云）→ 稳定气流越过丘陵或山脉，在背风侧驻波中形成 → 必临近山脉或丘陵
- 帽云 → 直接栖居山峰顶部；旗云 → 被风吹离峰顶，两者都指示正下方或紧邻处有山峰
- 「塞拉波云」为局部术语，专指内华达山脉背风侧的荚状云 → 局部云名可作区域线索
- 地形云 / 山腰入云 → 湿润空气被山坡抬升凝结，指示迎风坡与山体位置
- 迎风坡大积云/积雨云 → 空气被迫抬升致对流增强，可判断盛行风向与坡向
- 山谷雾 → 晴夜、微风、谷底有水汽时形成，日出后消散 → 指示山谷地形
- 峡谷雾（辐射雾）→ 陡峭峡谷内夜间积聚，指示深切河谷地形
- 山峰云海 → 拍摄点海拔高于云顶 → 可反推拍摄点处于高山或高地
- 山脉阻挡低层云/雾霾 → 山脊两侧干湿、能见度可能截然不同（Foehn 效应）→ 可判断坡向
- 火山地形的陡峭山峰能塑造风场，峰顶常现荚状云、帽云 → 指示孤立火山锥地貌
- 分形云（山坡碎雾）→ 潮湿空气沿斜坡上升形成的雾缕碎片，指示坡度与湿度

## 云 → 海陆

*由云种反推海岸线、海洋性与大陆性*

- 平流雾 / 海洋层积云 → 冷海面上空湿空气漂向内陆，在海陆交界处最常见
- 海风锋云 → 海风与陆风交汇产生的弧形云、卷云带，指示海岸线走向
- 山体自海面陡升扰乱海风 → 沿海山脉的典型云型，可判断海岸山脉位置
- 冷雾在夏季更常见（海风把冷海面空气吹上暖陆地）→ 指示夏季受海洋调节的沿岸气候
- 雾带沿岸/沿河谷分布且极有规律 → 可据雾区范围反推海岸线与低地轮廓（卫星视角）
- 干燥沙漠上空的卷云 → 高空湿度仍可成云，低层干旱 → 可区分沙漠与湿润区
- 三角洲平坦低地、河道蒸发旺盛 → 秋冬清晨易成片浓雾 → 指示大河三角洲地貌

## 云 → 季节物候

*由云种与雾型反推季节与物候*

- 辐射雾 → 晴朗少云、风弱的长夜，地面辐射冷却致近地水汽凝结；秋冬清晨最常见
- 山谷雾夜间形成、日出后散去 → 记录拍摄时刻可交叉验证时间信息
- 积云多于夏季午后因地表受热上升形成，日落前消散 → 指示拍摄于暖季日间
- 冬季总云量少于夏季；冬季以高云为主，夏季高云与低云大致平分 → 可判断季节
- 夜光云季节性强（北半球 6~7 月）→ 可确定半球与月份区间
- 珠母云出现于冬季 → 结合高纬定位季节
- 雨季/旱季交替区的对流云集中期 → 可指示季风或热带草原气候区
- 过冷水滴云（高积云等中层云）→ 云中温度约 -30~-40°C → 反推云层所处的低温高度

## 云 → 时间与光照

*由云与光学现象反推时段、朝向*

- 太阳高度角低、光路长 → 霞色偏红、可见维纳斯带 → 拍摄于日出/日落前后
- 彩虹出现需太阳在观测者背后且高度较低 → 可判断拍摄朝向与时段
- 卷云在日落时被照成红色/橘红（孤悬高空而无云影）→ 日落时段特征
- 云底被下方地物反光染色（如红砂岩映红云底）→ 暗示下垫面岩土颜色
- 日出日落方向结合影子 → 可推拍摄朝向（与光影天文技能交叉）

## 云 → 气候带

*由云型组合反推气候区（弱证据）*

- 同一云属在不同气候区出现频率差异显著 → 可作气候带判定的弱证据
- 积云在潮湿热带常见、晴好积云指示暖湿 → 指向湿润低纬
- 层云/平流雾长期笼罩的沿海山地 → 海洋性气候（夏凉冬温、湿度大）
- 高云族（冰晶）在热带可极高 → 热带高云景观与中纬不同
- 云底高度高 → 指示偏干燥或偏北地区；云底低平 → 反推当地湿度与气候带
- 沙漠区卷云由沙漠地表加热促进形成 → 干旱区也能有显著高空云
