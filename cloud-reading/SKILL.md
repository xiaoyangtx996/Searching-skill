# 云识读

**先认出这是什么云，再由云反推拍摄地点的地理条件。**

元素层答「这是什么」；本技能答「**这是哪类云、它意味着什么地理条件**」。
云是少数能同时约束**纬度、地形、海陆、季节**的线索——荚状云指着山，平流雾指着海，
珠母云指着高纬冬季，环天顶弧要求太阳高度角 ≥58°。整片天空无法被移除或替换。

> 云属分类与拉丁名取自 WMO《国际云图》。步 1–3 + 速查/补充表为执行主路径。

## 何时加载

- 照片里**天空占据较大比例**，或出现明显的云型、晕、虹、霞、雾
- 画面缺少文字、车牌、建筑等强线索，需要从**天空**这一维度收窄范围
- 已有候选地点，需要用云型**验证或排除**（气候带、季节、半球是否吻合）

## 输入 / 输出

| | 规格 |
|---|---|
| **输入** | 总技能已列的可见线索（云型、天空比例、有无日/月、降水迹象） |
| **中间** | 云族 → 云属云种；命中的「云 → 地理」条目 |
| **输出** | 云种判定 + 地理条件约束（有山/靠海/高纬/暖季）+ 命中句；回传 L 级 |
| **禁报** | 本技能单独**不报 L3 城市 / L4 点位**，只给地理条件约束 |

## 判读流程

输出固定四行（缺一行=未执行本技能）：

```
云族：低 | 中 | 高 | 未估
云种：<属/种或两种候选>
地理条件：<有山/靠海/高纬/暖季等；可写「无」>
档位：倾向 | 不确定 | 本领域无可用规则
```

| 步 | 输入 | 立刻做 | 输出 |
|---|---|---|---|
| 1 | 天空画面 | 按下表「云底估族」取低/中/高 | 云族 |
| 2 | 云族 + 形态 | 「易混对判据」；圆盘状先过「荚状云四条件」 | 云种或双候选 |
| 3 | 云种 | 抄「云 → 纬度/地形/海陆/季节」命中条 | 地理条件（不定城） |
| 4 | 有日/影或降水 | 交 `lighting-astronomy/` / `weather-climate/` | 交叉结果；本技能仍不报 L3+ |

### 云底估族（步 1 必用）

| 观测 | 云族 | 备注 |
|---|---|---|
| 云块贴楼顶/山腰，或遮挡近景地物 | **低** &lt;2000m | 积云底常见 300–1500m |
| 太阳轮廓仍清晰，云块有阴影/光晕 | **中** 2000–6000m | 高积云等 |
| 丝缕半透明，日/月轮廓清晰且常伴晕 | **高** &gt;6000m | 卷云/卷层云 |
| 以上都估不出 | **未估** | 只报「高/中/低云」之一若勉强可见，不报云属 |

### 荚状云四条件（圆盘状必须全过，缺一不可报荚状）

1. 边缘锐利光滑  
2. 多层叠置  
3. 驻留不动（非快速飘动积云）  
4. 伴山/丘陵  

缺任一条 → 按积云/层积云等其它属写，**禁止**写荚状云。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 看不到云底高度 | 用日/月轮廓与地物尺度套「云底估族」 | 云族填未估；不报云属 |
| 分不清相近云种 | 用「易混对判据」逐对排除 | 写明两种可能，标注不确定 |
| 只有一朵云 | 换其它维度（地物/植被/建筑） | 只输出地理条件约束，不定点 |
| 云型与季节冲突 | 核对半球与纬度 | 以画面实际特征为准，不硬套 |
| 用户要城市/点位且无第二线索 | **🛑 STOP** | 套黄金出货 C 或只报地理条件 |

### 🔴 CHECKPOINT · 🛑 STOP

云给出的是**地理条件约束**（有山/靠海/高纬/暖季），不是坐标。
**单朵云不报 L3+**；无第二独立线索时不报城市/点位。
用户追问「哪个城市」且画面仅天空/霞 → **停**，套黄金出货 C，不编城名。
云形态会相互转化，单张照片易误判 → 不确定就写明不确定。

## 黄金出货（对照即用）

**A · 低云棉絮 + 远景山脊**
```
云族：低
云种：积云 Cu（边缘圆钝≠荚状云）
地理条件：有山（画面山脊）；暖季日间弱倾向
档位：倾向
```
不定城。

**B · 日晕 + 高薄云（问半球/季节）**
```
云族：高
云种：卷层云 Cs（透日+晕→冰晶）
地理条件：高空冰晶；半球/季节不定（非珠母/夜光/环天顶弧）
档位：不确定
```

**C · 只有红霞要城市**
```
云族：未估
云种：无（仅霞）
地理条件：日出或日落前后；不定城
档位：本领域无可用规则
```

## 反例黑名单

| 不要做 | 为什么 | 改做 |
|---|---|---|
| 圆盘状就断言荚状云 | 还需锐利边缘/多层/驻留/伴山 | 边缘圆钝→积云类 |
| 「积云→好天气」绝对化 | 浓积云/积雨云也是积云类 | 只报云种与条件 |
| 单红霞定时刻或城市 | 红霞只有日出/日落区间 | 套模板 C |
| 航迹云当自然云种 | 人为凝结尾迹 | 不参与气候判断 |
| 单靠云定城/点位 | 禁报 L3+ | 只给地理条件 |

## 识别基础 · 三族与云属

*由云底高度分族，先定族再定属*

- 云按云底高度分三族：低云族（云底 <2000 米）、中云族（2000~6000 米）、高云族（>6000 米）
- 中云族高度随纬度变化：两极附近偏低、热带附近偏高 → 同一云属在不同纬度外观尺度不同
- 低云族 积云 Cu · 层积云 Sc · 层云 St · 积雨云 Cb（积雨云垂直发展，可贯穿三族）
- 中云族 高积云 Ac · 高层云 As · 雨层云 Ns
- 高云族 卷云 Ci · 卷积云 Cc · 卷层云 Cs（高云族全部由冰晶组成，呈半透明）
- 命名优先级：云种 > 云亚种 > 云变种 > 补充特征 > 附属结构；多种云共存时按主导者称呼

## 识别基础 · 易混对判据

步 2 逐行对照；命中右侧即定属。

| 对比 | 判据 | 结论 |
|---|---|---|
| 层积云 vs 高积云 | 地平线 30° 以上伸臂，小云块宽 > 三指并拢 | → 层积云 |
| 卷积云 vs 高积云 | 小云块宽 < 一指、无阴影、无光晕 | → 卷积云（约 9500 m） |
| 浓积云 vs 积雨云 | 闪电/冰雹/砧状平顶 | → 积雨云；仅花椰菜塔无雷 → 浓积云 |
| 雨层云 vs 高层云 | 连续降水 + 碎雨云 | → 雨层云；无或间断降水 → 高层云 |
| 卷层云 vs 高层云 | 透出日/月轮廓（低太阳除外） | → 卷层云；看不清日/月 → 高层云 |
| 层云 vs 雾 | 被楼顶/山腰截断、能见度尚可 | → 层云；贴地遮蔽地面 → 雾/霭 |

积云底典型 300–1500 m；高云族典型 ≥5000 m。碎积云/碎层云不作稳定天气判据。单张照片形态可转化 → 不确定就写双候选。

## 步3 · 地理速查（先抄这里）

下表不够用再翻「补充表」。仍只报地理条件，不报城。

| 云种/现象 | 地理条件 | 禁 |
|---|---|---|
| 荚状云（过四条件） | 必临近山/丘陵 | 不定城 |
| 帽云 / 旗云 | 紧邻山峰 | 不定城 |
| 平流雾 / 海洋层积云 | 海岸/海陆交界倾向 | 不定城 |
| 珠母云 | 高纬冬季 | 不定城 |
| 夜光云 | ≥50°；北半球 6–7 月 / 南半球 12–1 月 | 不定城 |
| 环天顶弧 | 太阳高度 ≥58°（中纬≈夏季正午） | 不定城 |
| 22°/46° 晕 + 高薄云 | 冰晶高云；**不定**半球/季节 | 套黄金 B |
| 仅红霞 | 日出或日落前后 | 套黄金 C |
| 航迹云 | 人为；不参与气候 | 当自然云种 |

## 补充表（速查不够时再翻）

| 类 | 线索 → 地理条件 |
|---|---|
| 光学 | 22°/46°晕→高云冰晶；幻日→同高两侧；环天顶弧→太阳≥58°；日柱→冰晶竖直板；华→薄云小粒；宝光→背日向雾；云隙光辐合点=太阳方位；彩虹→日在背后；霞→日出/日落 |
| 人为/特殊 | 航迹云→人为勿当气候；火积云→热源地物；雨幡洞→飞机过过冷中云；糙面云→不稳定；KH波→切变 |
| 纬度/半球 | 珠母→高纬冬；夜光→≥50°（北6–7/南12–1）；极光高纬；钻石尘→高纬/高海拔严寒；中云高度两极低热带高 |
| 地形 | 荚状/帽/旗→山；山谷雾/峡谷雾→谷；云海→拍点高于云顶；Foehn→脊两侧干湿差；塞拉波=内华达背风荚状 |
| 海陆 | 平流雾/海层积→海岸；海风锋云→岸线走向；夏冷雾→海洋性沿岸；三角洲秋冬浓雾 |
| 季节/时段 | 辐射雾→秋冬晨；积云→暖季午后；夜光/珠母定季；霞/维纳斯带→日出日落；彩虹定朝向（交 lighting） |
| 气候带（弱） | 热带多积云；沿海层云/平流雾→海洋性；云底高→偏干/偏北 |
