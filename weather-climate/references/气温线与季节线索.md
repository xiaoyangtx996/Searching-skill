## 一、0℃ 等温线（雪线推理的基础）

**原理**：给定日期，**当日 0℃ 等温线**就是"能否积雪"的分界。

```
画面有积雪 + 已知拍摄日期
        ↓
拍摄位置大概率在当日 0℃ 等温线**以北/更冷**的一侧
```

### 中国 0℃ 等温线的季节移动（粗略）

| 月份 | 0℃ 等温线大致位置 |
|---|---|
| 1 月（最冷） | 长江流域附近（秦岭—淮河一线以南一点） |
| 3 月 | 华北（约 35–40°N） |
| 4 月 | 东北南部 / 40°N 以北 |
| 10 月 | 东北北部开始 |
| 12 月 | 长江以北 |

**快速判断**：
```
1–2 月见积雪 → 至少长江以北，多在华北/东北/西北
4 月见积雪  → 基本要到东北或高海拔
7–8 月见积雪 → 只能是高海拔（青藏/天山）或高纬（漠河）
```

> **海拔替代纬度**：夏季积雪不一定是高纬，也可能是**高海拔**（同样 0℃ 以下）。
> 需与地形（`landforms`）和 `terrain.py` 高程交叉。

### 配套工具

| 用途 | 工具 |
|---|---|
| 查历史天气 | 各类历史天气网站（按城市+日期查） |
| 查实时/历史气温分布 | 气象部门公开数据 |

## 二、物候线索（更细的季节判断）

| 现象 | 季节/区域 |
|---|---|
| 落叶乔木**全秃** | 深秋—冬（北方更早） |
| 新叶初发、花期 | 春 |
| 浓绿茂盛 | 夏 |
| 叶色变黄/变红 | 秋 |
| **常绿阔叶林** | 秦岭—淮河**以南** |
| **温带落叶阔叶林** | 秦岭—淮河**以北** |
| 农作物（水稻/小麦/玉米）生长阶段 | 季节 + 地域 |

## 三、其他天气/气候线索

| 现象 | 能推出 |
|---|---|

## 四、执行要求

1. **必须知道拍摄日期**才能用 0℃ 等温线推理；无日期则只能给"季节倾向"
2. **高原优先排除**：夏季积雪先想高海拔，不要直接判高纬
3. 证据分级：积雪（画面可见）= **A 级**；等温线位置（气候常识）= **B 级**；
   物候推断 = C 级
4. 与 `lighting-astronomy` 联动：**日期 + 太阳高度角**可进一步收窄纬度

---

## 五、局限

- 等温线是**气候平均值**，具体年份**偏差可达数百公里**
- **城市热岛**使市区比郊区暖，市区积雪早融
- 积雪**可能来自人工造雪**（滑雪场）或**局部风口堆积**，不代表区域气候
- 物候**受树种与养护影响**：同城不同街道的落叶时间能差一两周
