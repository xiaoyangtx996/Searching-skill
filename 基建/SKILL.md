## 电力设施

*电杆、电塔、变压器样式*

- 出现多边形（八边形）电线杆且杆身刻有一竖行字 → 墨西哥
- 木质电线杆上端多孔、下端无孔 → 属特定国家的电线杆形制特征，可作国家判据
- 电线杆贴纸、路面标线样式、车牌样式、文字系统、街景车外观 → 均为可独立使用的国家或地区判据
- 开放地图数据含发电站、高压输电线路、风力发电机、变电站等电力设施 → 当常用地图缺少此类图层时，改用开放地图按标签检索定位
- 长期浏览各国街景积累的元素（文字、电话号码、标线、路桩、电线杆、路牌车牌、建筑风格、植被、整体氛围） → 可形成对国家的直觉判断
- 电线杆样式与建筑风格 → 可判断所属区域，用于排除不相符的地区
- 道路中线样式、电线杆贴纸、通行方向、民居形式、语言 → 可用于区分相邻国家或地区
- 电线杆上有黑色贴纸 → 可作地区市政设施特征
- 某地红绿灯样式高度统一 → 可作为该城市或地区的识别特征
- 异形红绿灯的细微结构差异 → 可用于区分不同城市
- 建在湿地之上的建筑、旁边伴有电线杆 → 可作为同类景观特征的比对依据
- 红绿灯样式特征鲜明 → 可单凭其一眼判定城市
- 设施常见的更新趋势为旧样式换成统一新样式 → 图中不符合该趋势的样式可反推为非主流地区或未更新区域
- 只能看到物体一面的形态时 → 不能确定其另一面形态，该特征不足以单独作判据
- 高压输电线路可沿线追溯至变电站 → 可据此缩小排查范围
- 照片中缺少某地普遍存在的设施 → 可降低该地为目标的可能
- 同款设施可能同时存在于多个城市 → 单一款式不足以唯一确定城市
- 大功率照明（探照灯等）多布置在开阔场所 → 结合杆体与摄像头位置可进一步判断场所类型是路口还是停车场边
- 电线杆涂有特定配色条纹 → 电杆涂装属地区独有做法，可作定位线索
- 电线杆底部统一刷成某种颜色 → 该类涂装属地区固定规范，可用于定位
- 画面中出现很高的高压线塔（输电塔）且附近有工业区 → 可能位于跨江输电区域，常出现在大江大河沿岸
- 红绿灯的横装或竖装方式存在地区差异 → 可用于区分地区
- 某省区红绿灯款式高度统一 → 可用红绿灯款式判断省份
- 缺少某类交通设施（如无红绿灯）、某类车辆数量极少 → 属罕见特征，可用于区分区域
- 画面视角与画质可反映图片来源类型 → 可用于区分实拍、航拍、视频截图与盗图，避免误判
- 环境氛围（植被、建筑风格、色调）只能给出候选区域 → 须以电线杆等处的旗帜等明确标识物作最终判定

## 路灯与护栏

*路灯与护栏款式判断城市*

- 路灯灯杆颜色在同一地区往往统一 → 偏离当地常见颜色的灯杆可作为区域判读线索
- 路灯更换频率低 → 路灯形态是跨年份稳定的匹配特征与时间锚点
- 同一路段路灯为统一款式 → 路灯可作路段认定的辅助特征，但同款路灯可能整条路甚至多条路通用，单独不足以定位
- 路灯款式与候选地点全部不符 → 排除该城市或该路段
- 路灯、护栏等市政设施存在地域款式差异 → 同款设施可将范围缩小到城市
- 车辆与路灯的朝向 → 可判断拍摄方向与路口形式，如渠化路口、右转车道
- 路灯密度与行人密度 → 可判断离城区的远近
- 平原地区且护栏为绿色 → 可优先考虑某类平原省份，但需其他线索佐证
- 平原地区与绿色公路护栏组合出现 → 可作为特定平原省份的候选线索，需结合其他元素确认
- 校舍建筑风格与栏杆样式特殊 → 可推断学校的历史背景与办学对象
- 路灯样式带有城市特征 → 可作为筛选城市的线索
- 建筑临水一侧有成排树木且无护栏 → 沿海或感潮河段的护堤树
- 背景建筑高度、树木与路灯样式 → 判断站点层级并可据此检索
- 同款路灯在既往题中反复出现于同一城市 → 可建立设施-地域对应关系
- 高速护栏颜色与样式 → 与地区建设标准相关，可作区域线索但不具唯一性
- 串灯式路灯并非某地独有、各地样式均有差异 → 路灯样式不能单独作为定位判据，须与其他要素交叉验证
- LED路灯色温存在地域分布差异（冷白/暖光） → 可由色温排除某类地区
- 路灯、栏杆、标识牌、隔离栏等多要素同时一致 → 可确认定位
- 画面无其他可辨识特征时 → 路灯可作为定位切入点
- 护栏样式罕见 → 可单独取样，并叠加路灯特征交叉验证
- 护栏扶手颜色与点缀色独特 → 可作为地区的辅助判据
- 路灯间距通常约25米 → 可据此估算桥宽、河宽
- 路灯样式罕见 → 参考价值高，应优先比对
- 红绿灯形状、路灯杆下部涂层高度、附加装饰 → 组合特征可用于锁定城市
- 路灯造型独特 → 需判断是定制款还是全区域统一款，后者定位价值更高
- 特色路灯分布区域有限，且位于路中间的样本更少 → 可据此缩小搜索范围
- 桥面有路灯且灯杆下部发红（多为中国结灯箱） → 可辅助确认桥梁身份
- 路灯造型与安装样式 → 具有地域分布偏好，可作地区线索
- 偏离全国常见配色的路灯颜色 → 该异常配色可作为筛选少数城市的第一条件
- 同一城市不同区域常共用同一款路灯 → 可先用路灯款式锁定城市，再在城内按目标类型排查
- 护栏并非遍布全城，但安装区域多连续成片 → 可用护栏的有无与样式圈定城内连片区域
- 同一城市内护栏颜色存在分区差异 → 可用颜色差异逐步排除辖区
- 同款路灯往往成片集中出现 → 找到一处同款路灯，目标位置通常就在附近
- 同一路段或区域路灯款式杂乱多样 → 该地规模较小或发展程度中等
- 大城市马路旁路灯款式较为统一 → 路灯款式多样本身即可作为城市规模的判据
- 建筑外墙的一体化装饰面板具有地域与建筑专属性 → 可与路灯等设施互证定位
- 路灯等设施可能由外地厂家供货 → 仅在异地见到的同款设施不足以证明地点，需排除供货流通造成的假匹配
- 区域性配电箱与路灯款式一致出现 → 可作为城市判据
- 某款路灯造型罕见、与各地常见制式明显不同 → 稀有样式比通用样式更具定位价值
- 路灯造型复杂、做工考究 → 多出现在经济发达城市的核心路段或重点工程
- 本地居民认为某路灯样式在其城市不常见 → 该样式的地域分布有限，可据此缩小搜索范围
- 同款路灯存在有无底座、颜色差异 → 底座与颜色是区分不同城市同型路灯的细节
- 同一城市桥梁的护栏样式高度雷同 → 反映养护与采购单位集中，同城桥梁可归为同一风格
- 护栏焊接工艺复杂、造价高 → 该类护栏多出现在财政充裕或重点维护的路段、景区
- 路灯为某地独有制式 → 独有制式是锁定地点的强线索
- 路灯杆上贴有标签且朝向统一 → 标签通常面向本车道来车方向，可据此推断当地左行或右行，进而缩小国家范围
- 某路灯为各地广泛使用的标准款式 → 通用款无定位价值，应忽略
- 某造型路灯为多家厂商均可生产的通用产品 → 通用量产款不能用于定位
- 护栏颜色罕见（如蓝色）→ 罕见颜色的护栏本身即为强线索
- 同款颜色或样式的路灯反复出现在已知区域样本中 → 可将该路灯样式作为区域归属的辅助判据
- 某类道路基础设施（护栏、路灯、路面样式）的样式具有产地或城市集中性 → 可通过检索同类设施反推城市
- 护栏、路灯、路型的组合样式一致 → 可作为城市确认的依据
- 路灯造型具有强地域性，同一城市或区域往往统一款式 → 可作为判断城市或大区域的强线索
- 同一区域内的路灯造型高度统一 → 可由路灯式样推断所属区域范围
- 某款路灯为特定区县独有 → 可先锁定区县级范围，再用其他线索细化
- 罕见的特色路灯造型 → 可通过搜索该造型反查所属城市
- 特色路灯（动物、器物等造型）常为某城市的标志性市政设施 → 可作为城市识别的直接线索
- 各城市路灯样式普遍不同 → 路灯是区分城市的通用依据
- 护栏样式在特定区域极为常见 → 可作为区域判断依据
- 护栏易被车辆撞击，故常在交通事故报道中出现 → 可通过交警或交通广播的交通事故视频与报道反查护栏样式及路段
- 路灯杆上带有市政编码牌 → 说明该城市实施了路灯编码管理，可据此排除未实施该管理的城市
- 多个可见特征（地标设施、周边水系、灯杆形状与颜色、岸边护栏造型等）叠加筛选 → 可唯一确定地点
- 路灯装饰造型具有地域图腾特征 → 可据此检索对应城市
- 站点周边地物（路灯样式、建筑外形）与候选站点吻合 → 用于确定具体位置

## 风力与光伏

*风机与光伏板布点*

- 屋顶太阳能板密集 → 热水需求大，指向酒店或集中供热水建筑
- 画面中出现风力发电机 → 指示风资源丰富地区，如沿海、高原或草原地带
- 屋顶大量太阳能板 → 日照充足地区
- 植被 + 太阳能板 + 建筑 → 大陆性气候判断
- 太阳能板与空调外机同时出现 → 冬季寒冷、夏季炎热、日照充足的大陆性气候
