## 民俗节庆

*节庆活动与民俗特征*

- 公路为避让孤立巨石而异常绕行 → 与当地民俗保护相关，指向特定地区

## 宗教习俗

*宗教建筑与习俗特征*

- 宗教建筑形制与固定符号装饰 → 可提示所处文化区域
- 宗教造像露天或置于亭中并面向开阔水面 → 附近有开阔水域，且供奉形式与登高远眺的功能需求相符
- 宗教建筑形制辨识不清 → 先判定是佛寺还是教堂，类型判错会使后续检索方向整体偏离

## 历史文化

*历史遗迹与地域文化*

- 投稿者历史题目的地域分布 → 可作为搜索先验
- 出题来源的历史题目地域分布集中 → 可将其作为先验缩小搜索范围
- 历史地标原址现为成片住宅区 → 不能据旧照片中建筑仍在进行定位
- 市区内成片老校区 → 提示城市中存在历史较久的大学集中区
- 明显雾或极端天气 → 可查历史天气记录辅助确定日期
- 街区建筑朝向明显偏离当地主导朝向 → 该街区可能是历史特殊规划区
- 出题者历史题目的地理分布 → 可推测新题的地理范围
- 将画面天气现象与当地历史气象记录比对 → 可锁定拍摄日期或时段
- 传统建筑元素与现代楼体结合 → 多见于历史文化城市的公共建筑与景区周边商业街
- 画面信息被涂抹或遮挡 → 转向发布者的历史帖子、动态、评论等场外信息寻找位置起点
- 发布者历史内容中自述的位置 → 可作为定位起点，检索其周边带有特定关键词的地点
- 同一出题者/系列的历史题目集中区域 → 可作为新照片地域先验
- 同一发布者或系列题目的历史地点集中 → 可作为新照片地域先验
- 桥栏浮雕与柱头采用特定历史建筑样式 → 推断该地建城历史与文化分区
- 建筑外观风格明显不属于现代 → 该地有较深历史文化积淀，偏向传统建筑密集区域
