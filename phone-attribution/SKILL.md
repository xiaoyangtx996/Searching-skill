# 号码归属查询

由画面里的**电话号码**反查位置。分两条路：

| 号码类型 | 走哪条 | 网络 |
|---|---|---|
| **11 位手机号** | `phone_lookup.py`（本地 `phone.json`，无索引则直接扫库） | ❌ **零网络** |
| **座机号**（区号+本地号） | chahaoba.com `api.php` 反查单位名与坐标 | ✅ 需联网 |

> 数据源：
> - **本地号段库**：`phone.json`（483,977 条，字段：`prefix_3` `prefix_7` `middle_4` `operator` `province` `city` `area_code` `postal_code`）
> - **座机单位库**：[查号吧 chahaoba.com](https://www.chahaoba.com/)（MediaWiki，网友提交的「单位电话归类」结构化条目）
>
> 本技能是**查询方法 + 边界闸门**，不是自动爬虫；chahaoba 部分按站点 robots.txt 合规，一律用 `api.php`。

## 何时加载

- **11 位手机号**出现（招牌、车身、海报、门头）→ **优先走本地号段库，不依赖任何云端 API**
- **门头、招牌、广告牌、围挡、横幅上有座机号** → 走 chahaoba
- 售楼广告上的售楼热线（唯一性高，可直接反查项目与县市）
- 单位门口公示牌、施工告示上的联系号码
- 已从画面读出区号，想进一步落到**单位/街道级**

**不适用**：400/800 号、短号（110/119/12345）。

## 使用方式

从仓库根目录执行。没有 `python` 就用 `py`。

输出固定三行（缺一行=未执行）：

```
规则摘要：<号码 → 归属地/单位>
动作：<命令或「不适用」>
档位：倾向 | 跳过 | 本领域无可用规则
```

| 步 | 输入 | 立刻做 | 输出 |
|---|---|---|---|
| 1 | 画面上的号码串 | 去空格/`+86`；数位数；看是否 `1` 开头 | 类型：中国手机 / 座机 / 外国号 / 400·800·短号 |
| 2 | 中国手机（11 位且 `1` 开头） | `python phone-attribution/phone_lookup.py 13912345678` | `province` `city` `operator`；止于市级倾向 |
| 3 | 座机（含区号） | 先离线 `cn_area_codes.json` / `clues.py lookup area-code`；再剥区号查 chahaoba `api.php` | 区号级或单位条目；坐标≠机位 |
| 4 | 400/800/110/119/12345 | **不适用**，改查其它文字 | L0 |
| 5 | 步骤 2–3 | 交回总技能；升 L3+ 须过 STOP + 边界表 | 不报 L3+ |

无命中 → 换领域。条件冲突 → 跳过。只命中 1 条 → 止于倾向。

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 号码被遮挡/少一位 | 按可见部分列号段范围 | 只报运营商 |
| 手机号查不到 | 按新号段/虚拟运营商处理 | 只报"归属地库未收录" |
| 座机查不到条目 | 换切割位置或按单位名反搜 | 只报区号级 |
| 命中但信息是十年前的 | 见「三、边界」，降权 | 不当 L3+ 依据 |
| 仅命中1条 | 结论止于倾向 | 请用户补图或交叉其它领域 |

### 🔴 CHECKPOINT · 🛑 STOP

查完号段/单位后、把「市」写进候选前：画面须另有独立线索（门头文字、路牌、街景），否则 **停在倾向**，不报 L3+。
用户只要「定到哪栋楼」且本地号不全/仅区号 → **停**，套黄金出货 B。
**号码库大多是多年前的用户提交，只能当线索，不能当铁证。**

## 一、手机号：本地号段库（零网络）

三条全满足才进库：11 位 + 以 `1` 开头 + `prefix_7` 有记录。否则按外国号规则，**禁止**因「11 位」硬套。例：`+81-90-…` 剥国家码后 10 位 ≠ 中国号。

```bash
python phone-attribution/phone_lookup.py 13000001234
python phone-attribution/phone_lookup.py "+86 139 1234 5678"
python phone-attribution/phone_lookup.py 13000001234 --json
```

| 现象 | 动作 |
|---|---|
| 三条全满足 | 走本地库 |
| `1` 开头但库无 | 报未收录；再查 chahaoba |
| 非 `1` 开头 / 非 11 位 / 非 +86 | 外国号，不用本库 |
| 画面明显境外 | 不硬套归属地 |

### 字段

| 字段 | 值例 | 定位价值 |
|---|---|---|
| `prefix_3` | `130` | **运营商** — 见下方实测对照表 |
| `prefix_7` | `1300000` | 前 7 位，最细粒度（= `prefix_3` + `middle_4`） |
| `middle_4` | `0000` | **第 4–7 位**，查询时取号码的 `[3:7]` |
| `operator` | 中国联通 | 运营商。**查表直接读它，别自己背号段** |
| `province` | 山东 | **省级**，直接可用 |
| `city` | 济南 | **市级**，直接可用 |
| `area_code` | 370100 | **行政区划代码**（GB/T 2260）→ 可查区县层级 |
| `postal_code` | 250000 | **邮编**，交叉验证用 |

优先用：`city` / `area_code` / `postal_code`。

## 二、座机号：chahaoba.com（联网）

只用 `https://www.chahaoba.com/api.php`（robots **未禁**）。**禁止** `/wen_api/es_api.php`。

| 搜索词 | 结果 |
|---|---|
| `06603461119` 连写 | 0 命中 |
| `0660-3461119` 带区号 | 噪声海量 |
| **`3461119` 仅本地段** | 精确命中 ← 正确 |

```bash
curl -s "https://www.chahaoba.com/api.php?action=query&list=search&srsearch=3461119&format=json&srlimit=5"
curl -s "https://www.chahaoba.com/api.php?action=parse&pageid=<id>&prop=wikitext&format=json"
```

优先号码段；长单位名全文搜常 0 命中。只要 `{{单位电话归类}}`；`{{查询要求顶部}}` 仅区号级。

## 三、边界（与反例黑名单合并执行）

| 号码/情况 | 止于 | 禁止 |
|---|---|---|
| 手机号段命中 | 省市倾向 | 当拍摄点；报 L3+ |
| 座机单位坐标 | 单位地址级候选 | 当机位 |
| 400/800/短号 | L0 | 查本库 |
| 总部/连锁号 | 企业倾向 | 当地点独有 |
| 十年前条目 | 弱线索 | 当仍营业的排除依据 |
| 库无收录 | 「未收录」 | 「号码不存在」 |

升 L3+：门头文字 + 单位名 + 街景三者一致，且过 STOP。  
顺序：先 `cn_area_codes.json` / `clues.py` 离线缩城 → 再 chahaoba 查单位。
