## 判读顺序（先粗后细）

1. **定大区**：气候带（积雪/bio-clues/日照）→ 先砍掉一半国土
2. **看岩性**：石灰岩（喀斯特峰丛/溶洞）→ 亚热带石灰岩区；黄土（沟壑+浑浊河水）→ 黄土高原
3. **核走向**：山脊线走向 vs 道路/河流走向 → 交叉定方位
4. **比轮廓**：山形是天际线上最稳的"指纹"，用 3D 地形视图比对
5. **查雪线**：有雪则雪线高度 → 反推纬度和海拔
6. **找对景**：已知候选点 → 用航拍地形沿山脊/岸线找能形成对景的机位

## 山体形态线索

- 山脊线**连续平直** 且山顶平坦 → 多指向高原或夷平面，非喀斯特
- 山体**峰丛、峰林**、有溶洞 → 石灰岩喀斯特 → 优先 广西/云南/贵州
- 山体多**沟壑沟谷**且河水浑浊泛黄 → 黄土覆盖的高原丘陵
- 山顶**平坦**且轮廓独特 → 属标志性地貌，可反查地名
- 山体**自海面陡升** → 沿海山脉，结合云型可判海岸山脉
- 连绵山体**夹河谷或水库** → 小型山脉中的河谷/水库地貌
- 周围山体**低缓且植被茂密** → 多见南方丘陵
- 地形起伏大**且**植被茂密 → 倾向南方山区
- 画面**无山、视野开阔** → 平原，据此排除多山城市

## 朝向与光照

- 山脊、崖边与近处地物边缘在画面里**刚好相切** → 在卫星图上画同一条切线，机位在线上
- 山坡与平原交界处的**阴影走向** → 判断地形走向与太阳方位
- 已知拍摄时间 + 山体阴影 → 反推经度（配合 `lighting-astronomy`）
- 山体**迎风坡**：帽云/旗云栖居峰顶 → 正下方或紧邻处有山峰；背风侧常有荚状云
- 积雪分布**只在阴坡** → 该坡朝北（北半球）

## 海拔与气候

- 雪线以下才有植被、雪线高度可反推纬度与海拔
- 人物肤色偏深 + 日照强烈 → 高原或西南山地
- 楼顶普遍设**储水罐** → 供水不足的高原/山区/岩溶缺水区
- 高原文化标识（经幡、雪山）→ 高原文化区
- 大面积湖泊紧邻山地且常见云雾 → 湖山结合地形

## 植被与土壤（与 `bio-clues` 交叉）

- 林相（常绿阔叶 vs 落叶阔叶）→ 秦岭—淮河线南北
- 土壤颜色地带性：砖红壤—赤红壤—红壤—黄壤—黄棕壤—棕壤—暗棕壤
- **土壤颜色吻合但山势不吻合 → 候选地不成立**（两条必须同时成立）

## 与其他技能的接缝

| 线索 | 交给 |
|---|---|
| 影子方向/长度、日照/雪线经度反推 | `lighting-astronomy`（sun.py locate 可算） |
| 具体树种、林相、农作物 | `bio-clues` |
| 地形高程、天际线拟合、视域分析 | `geo-sleuth`（terrain.py） |
| 山体云型（帽云/旗云/荚状云） | `cloud-reading` |
