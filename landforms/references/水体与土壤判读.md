## 一、水体判读

### 四要素

| 要素 | 能推出什么 |
|---|---|
| **类型** | 河流 / 运河 / 湖泊 / 水库 / 海 —— 决定地理框架 |
| **流量** | 大江大河 vs 小支流；季节性丰枯 |
| **流向** | 结合地形与影子定方位 |
| **颜色** | 泥沙黄（黄河型）vs 清绿（南方型）vs 深蓝（水库/海） |

### 中国主要水系速认（判读用）

| 水系 | 外观特征 |
|---|---|
| **黄河** | 水色**黄浊**、含沙量大；河床高（地上河）、堤坝明显 |
| **长江** | 江面**宽阔**、水色偏绿或黄；两岸多港口、大桥、码头 |
| **珠江** | 水量大、水色偏绿；三角洲河网密集、汊道多 |
| **京杭大运河** | **人工河道**：河岸**笔直规整**、有船闸、护坡石砌、宽窄一致 |
| 山区河流 | 河床多卵石、水清、比降大、多峡谷 |

**快速区分**：
```
看"直不直"  → 特别直、护坡规整 = 人工运河（京杭大运河）
看"黄不黄"  → 很黄很浊 = 黄河
看"宽不宽"  → 极宽 + 大桥多 = 长江
看"汊不汊"  → 河网密集分汊多 = 珠江三角洲
```

### 判读要点

- **水体类型 → 地理框架**：见到大江 → 优先考虑沿岸城市
- **流向 + 影子** → 反推方位（与 `lighting-astronomy` 联动）
- **水色** → 泥沙型（北方/上游）vs 清澈型（南方/山区）
- 运河的**笔直岸线 + 船闸 + 护坡**是人工特征，非常独特

## 二、土壤带谱（南北判断）

**原理**：中国东部土壤呈**纬度地带性分布**，从南到北依次为：

```
砖红壤 → 赤红壤 → 红壤 → 黄壤 → 黄棕壤 → 棕壤 → 暗棕壤 → 棕色针叶林土
（华南）                                                    （东北）
```

| 土壤颜色 | 大致区域 |
|---|---|
| **砖红壤**（深红发暗） | 雷州半岛、海南、云南南部 |
| **赤红壤**（红） | 华南（广东、广西、福建南部） |
| **红壤** | 长江以南（江西、湖南、浙江） |
| **黄壤 / 黄棕壤** | 长江流域过渡带 |
| **棕壤 / 暗棕壤** | 华北、东北 |
| **黑土**（黝黑） | **东北平原**（松嫩、三江） |
| **黄土**（浅黄粉质） | 黄土高原（陕甘宁晋） |

**用途**：看**裸露土壤的颜色**（工地、农田、挖开的坡面）可大致定南北。

> ⚠️ 城市路面、绿化带土壤多为**回填土/外来客土**，颜色不可靠。
> 优先看：**农田、工地裸土、山坡剖面、开挖面**。

## 五、局限

- **土壤颜色受光照影响大**：阴天/逆光下红壤可能看着发暗，黄壤可能发灰
- **回填土普遍**：城市里看到的多是客土，不能代表当地土壤
- 水体流量**有季节性**：枯水期的小河可能是丰水期的大河
- **运河 vs 天然河**在部分段落难以区分（如运河借用了天然河道段）
