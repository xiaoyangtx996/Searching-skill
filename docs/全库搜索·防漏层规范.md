# 全库搜索：防漏层操作规范

> **这篇是给"执行者"（我 / 任何 agent）看的操作规范**，不是判读规则。
> 起因：曾出现「只搜元素层 → 漏掉区域层 → 少报一个市」的错误。

## 为什么要专门讲这个

这套知识库分两层，**功能不同**：

| 层 | 回答 | 举例 |
|---|---|---|
| **元素层**（27 技能） | 「这是什么」 | 这是黄色出租车、这是蓝白护栏、这是悬铃木 |
| **区域层**（152 文件） | 「这里是哪」 | **黄色+顶灯竖放=重庆**、**蓝白护栏=重庆**、悬铃木+空调外机=重庆 |

**关键风险**：元素层会把线索"认出来"就停了，但**真正能定城市的强规则几乎都在区域层**。
只加载元素层 = 认出了东西但定不了位。

## 强制动作（每张图都要做）

```bash
# 一次性搜遍所有层，按层报命中数
py geo-sleuth/scripts/kb_search.py <线索词1> <线索词2> …

# 只看区域层
py geo-sleuth/scripts/kb_search.py --layer region_cn 黄色 出租车 蓝白 护栏
py geo-sleuth/scripts/kb_search.py --layer region_cn 悬铃木 空调
```

**门禁**：报 **L2+ 之前**，`kb_search` 的**区域层命中必须 >0**，或在输出里写明「已搜区域层，0 命中」。
只有元素层命中就下结论 = 违规。

## 搜索词怎么写才有效

区域层的措辞和元素层**不一样**，用元素层的词常搜不到。要点：

| 元素层词（易漏） | 区域层该用的词 |
|---|---|
| 出租车 | 出租车 **涂装**、**黄色**、**顶灯**、**配色** |
| 护栏 | **蓝白**、**颜色**、**双层**、**样式** |
| 行道树 | **悬铃木**、**榕树**、**黄葛树**、**香樟** |
| 建筑 | **外墙**、**瓷砖**、**马赛克**、**屋顶**、**空调外机** |
| 路牌 | **路名牌**、**方位标**、**底色**、**翻译** |

**技巧**：先跑一次元素词拿到"是什么"，再用**具体属性词**（颜色/材质/数量）复搜区域层。

## 中国区覆盖范围（重要限制）

中国区**只有 19 个文件**：
`中国通用` `中国出租车` `上海` `上海崇明` `云南` `内蒙古` `吉林` `天津` `山西` `广西`
`新疆` `河北` `海南` `湖南` `甘孜` `福建` `西藏` `重庆` `香港`

**没有**北京、广东、四川、江苏、浙江、山东、河南、湖北、陕西…的区域文件。
→ **「搜不到」不等于「不是这里」**。缺文件时改用：
1. `中国通用.md`（跨省通用规则：土壤、植被、护栏、路名牌、橙线等）
2. `中国出租车.md`（全国出租车涂装对照，含所有直辖市+多省）
3. 元素层 + `geo-sleuth/references/clues/china.md`

## 与其它步骤的接口

- 步骤 2（列线索）产出**线索词** → 喂给 `kb_search.py`
- 步骤 3（加载元素层）→ 认"是什么"
- **步骤 4（区域层）→ 定"哪里"，必须搜**
- 出候选前，`kb_search` 的区域层命中情况要写进输出模板的 `kb_search:` 行
