货币、饮食、方言、计量等不成文规则


## 何时加载

照片中出现 生活常识 相关元素、需要据此推断地点时加载本技能。

无命中→换领域；条件冲突→跳过；单规则→不升格点位。
回传行：规则摘要：<线索> → <结论>

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索命中 | 换领域或加载解题方法论 | 写明本领域无可用规则 |

| 仅命中1条 | 结论止于倾向区域 | 请用户补图或交叉其它领域 |

## 货币与价格

*纸币硬币版本判断国家*

- 摊位、商品标价、包装上出现本地文字或货币 → 限定使用该文字或货币的区域
- 楼体为四四方方的密集居民楼 → 城中村或城中村型城区
- 出现某地特有的面食种类 → 指向该面食的发源或流行地域
- 新区与老区建筑风格差异明显 → 可分别对应城市的新城与老城片区
- 居民区周边遍布与居民合作的停车场 → 该区域居住密度高、停车需求紧张
- 摆件、游戏设备与机械键盘 → 使用者为年轻男性，且工作自由度较高

## 饮食与方言

*饮食习惯与口音判断地域*

- 方言分区在县域内即可存在差异 → 方言特征可将定位细化到县级
- 画面中出现成组的地域性饮食 → 指向其所属饮食文化圈
- 老字号门店内员工方言构成 → 反映城市本地化程度，不能单独作为地域判据

## 计量单位

*公制英制与当地习惯单位*

- 垃圾桶上的标志 → 可作为归属地或管理单位的判读线索
- 成片样式统一的职工宿舍楼 → 单位集中建设的老城区
- 建筑旁立有方形文保石碑 → 该处为文物保护单位，可据此检索定位
- 工牌样式与佩戴方式 → 所属单位为政府、学校或企业等机构
- 桌面大量工具书与教科书 → 场所为科研单位或学校
- 墙面悬挂人物与风景照片 → 该场所兼有单位活动摄影功能
- 画面中出现企业、单位、工程名称 → 检索其在目标区域的驻地或项目点，缩小至具体位置

## 门牌与邮筒

*门牌号与邮筒样式*

- 门牌、楼牌或门头标识出现在画面中 → 放大读取文字与编号，可定位到街道、建筑或门牌段

## 时区与作息

*当地作息时间反推时区*

- 某架飞机近期航段数少且末段在夜间 → 该机与照片时间不符时应予排除
- 照片中出现交通事故等特殊事件 → 可检索相关新闻反查地点和时间
- 无明显时间线索的照片，默认按下午拍摄处理 → 太阳大致位于西南方向
- 太阳时角以约每小时15°变化 → 由太阳高度变化量可换算经过的时间
- 太阳在画面中的位置 → 缩小方位与时间的首要线索
- 画面中出现的时钟读数或影像时间戳 → 可辅助推断所处时区与作息规律
- 同组照片中是否存在相同建筑构件 → 可判断拍摄时间是否同一时期
- 大屏仍显示停止检票而列车未发车 → 画面时间在发车后极短时间内
- 在建工地与稀疏绿化 → 照片拍摄时间早于该地建成现状
- 画面出现成片积雪 → 拍摄时间必为冬季
- 树木萌芽但未见绿色、树坑有残雪 → 拍摄时间为早春（残冬末至初春）
- 连续照片中云量变化 → 天气具有延续性，可用于校准拍摄时间与地点
- 车厢内多乘客举手机拍照/视频 → 可能为新线开通、试乘或特殊区段，可用于时间/事件定位
- 题目未给出精确拍摄时间 → 不能把时间作为判读依据，应仅凭画面地物定位
- 答题按正确答案提交时间排序 → 速度与准确度共同决定结果；先锁定可靠线索再提交
- 人工出题/评判存在少量延误 → 发布时间或提示时间可能有偏差，不因分钟级差异排除线索
- 未提供精确拍摄时间 → 不将时间作为定位依据，按画面可见地物独立判断
- 多名答题者提交正确答案 → 按提交时间先后判定，先提交可靠答案优于反复迟疑
- 人工发布或评判可能出现少量延误 → 发布时间、提示时间可能有偏差，不因分钟级误差排除合理线索
- 夜间活动规律（灯光密度、营业状态、人流）→ 可用于推断城市规模与所处区域
- 定位精度停留在城市级而未细分到区 → 需额外投入大量时间排查
- 门店周边的相邻商家组合 → 用于验证定位结果
