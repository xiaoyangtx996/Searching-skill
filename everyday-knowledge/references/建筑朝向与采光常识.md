# 建筑朝向与采光常识（旁挂）

> **旁挂文件**：`everyday-knowledge/SKILL.md` 是 darwin 生成的规则表（`<!-- darwin-wrapper:v1 -->`），
> 正文不直接改；本文补足**「从朝向/采光反推方位」**这一类常识规则。
> 素材来源：用户自备经验（网络迷踪入门指南 第九节「生活常识」）。

---

## 一、核心原理

**北半球建筑普遍朝南**——这不是巧合，是**日照规范 + 生活习惯**决定的。

由此可得一条强推论：**看到建筑/太阳能板/阳台的朝向，就能反推拍摄方位。**

| 观察 | 推论 | 强度 |
|---|---|---|
| 太阳能板倾斜面朝某方向 | 北半球→**朝南**（南半球→朝北） | 强（物理约束） |
| 阳台/晾衣杆集中在一侧 | 该侧多为**南向** | 中 |
| 主卧/客厅大窗在一侧 | 该侧多为**南向** | 中 |
| 楼房正立面受光、背立面阴影 | 受光面偏**南** | 中（需结合时刻） |
| 屋顶水箱/机房偏一侧 | 常在北侧（不影响南向采光） | 弱 |

> 用户原话：「一般来说楼房的朝向都是坐北朝南，**太阳板也一定是朝南的**。」

## 二、与 `lighting-astronomy` 配合（关键）

**朝向本身只给方向，要转成"时间/位置"必须结合太阳。**

```
① 读出建筑朝向（本文）  →  ② 画面阴影方向（光影天文）
        ↓                          ↓
   确定相机朝向            sun.py pos 算太阳方位/高度角
        └──────────┬─────────────┘
                   ↓
        交汇出：拍摄时刻 + 纬度带
                   ↓
        sun.py locate → 全球亮带（候选纬度）
```

**例**：
- 太阳能板朝右前方 + 影子朝左后方 → 太阳在右前 → 若为上午，则相机大致朝**东偏南**
- 结合 `sun.py locate` 的亮带 → 缩到纬度区间

> 🔴 这是 `docs/技能互联·产出手册.md` 里「`lighting-astronomy` ↔ `geo-sleuth` 主闭环」的一个**入口**。

## 三、其他可利用的"不成文规则"

| 现象 | 推论 | 备注 |
|---|---|---|
| 太阳能板朝南 | 北半球 | 南半球（澳/新西兰/南美南部）**朝北** |
| 太阳能板**平铺无倾角** | 赤道附近（倾角小） | 热带 |
| 太阳能板**倾角很陡** | 高纬度 | 倾角≈纬度 |
| 楼房密集且无阳台 | 北方部分老城/单位房 | 弱线索 |
| 阳台全部封闭 | 北方常见（防风保暖） | 弱 |
| 阳台开放式多 | 南方常见 | 弱 |
| 晾衣杆外挑 | 长江流域及以南常见 | 弱 |
| 屋顶坡度很大 | 多雪地区（东北/西北） | 中 |
| 屋顶平缓、有女儿墙 | 少雪地区 | 弱 |
| 空调外机密集挂墙 | 夏季炎热地区 | 弱 |
| 室内暖气片/地暖分水器 | 北方集中供暖区 | **强**（秦岭—淮河以北） |
| 双层窗（内层加装） | 北方寒冷地区 | 中 |

> **冬季供暖线（秦岭—淮河）是一条很硬的南北分界线索**：室内照到暖气片 = 北方集中供暖区。

## 四、执行要求

1. **朝向推论必须与光影联动**，单独用只能给"方向"，不能给"地点"
2. **南半球要反过来**（太阳能板朝北）——先判半球再套规则
3. 本文规则**多为「倾向」**，不得单条定城（同 `SKILL.md` 置信度规则）
4. 证据分级：太阳能板朝向 = **A 级**（物理约束，画面可见）；
   阳台/屋顶样式 = **C 级**（社区经验）；暖气片 = **B 级**（制度性事实）

---

## 五、局限

- 朝向**不是必然**：受地块形状、道路走向、规划限制影响，存在大量非正南朝向
- 老城、山地城市（重庆、攀枝花等）朝向**随地形走**，不能机械套用
- 太阳能板也有**朝东/朝西**装的（受屋顶形状限制），只是少数
- 半球判断错了，结论**完全反转**——必须先确认南北半球
