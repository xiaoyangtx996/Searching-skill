## 屋顶形式

*平顶/斜面/坡屋顶对应气候*

- 屋顶设备的品牌存在地域集中分布 → 可作区域线索
- 民居屋顶颜色的区域分布具有地域性 → 可用屋顶颜色组合辅助判断地区
- 私房屋顶的样式与年代特征 → 可反映地域建筑风格，用于划分大区
- 特征性建材仅偶发于场景边缘 → 不足以作为定位依据
- 相邻城市同类设施规格不同（砖体高厚与矮薄之分） → 可据设施规格区分相邻城市
- 统一规划建设、无临街商铺的成片住宅 → 判定为拆迁安置区而非原生聚落
- 景区内临街开店且房屋形制多样 → 判定为原住民自建房片区
- 特定车辆型号特征加周边老小区屋顶形态 → 可推断公交线路所在区间
- 屋顶结构属仓库厂房常见形式 → 拍摄点位于港口或工业仓储区
- 塔多为形制规整的攒尖顶、楼形制多样 → 可据屋顶形制区分塔与楼并检索具体建筑
- 远处建筑的屋顶颜色与窗户样式同已知建筑吻合 → 可交叉验证拍摄方位
- 沿公路零散分布两三户人家 → 属小聚落而非村镇中心
- 街道地面铺设瓷砖 → 指向老街区或商业步行街而非普通街道
- 路面材质与建筑风格 → 可反推该片区在旧时期的经济与建设水平
- 成片低矮平顶房加简易棚顶 → 指向特定气候区的自建民居风格
- 建筑混合哥特、罗马、拜占庭、神庙及东南亚佛塔等多种风格 → 混搭罕见，辨识度高
- 建筑群内各单体朝向不一、屋顶琉璃瓦颜色不同 → 可作为组合特征逐项比对
- 屋顶红色航空障碍灯 → 提示附近有机场
- 百叶窗等纯装饰性构件 → 不反映气候需求，不能作为气候判据
- 同一区域内儒释道混合供奉 → 现象普遍，不足以单独判定地区
- 画面中唯一地标属当地常见风格 → 不足以支撑定位
- 关键画面仅一闪而过 → 截图并与既往关注点比对，可锁定拍摄位置
- 检索词被高频无关内容淹没 → 改用近义词或细分场景词重新检索
- 一种瓷砖样式在多地被普遍使用 → 不能作为定位依据
- 建筑采用庑殿顶、歇山顶或重檐下檐等组合屋顶 → 属等级较高的传统或仿古建筑
- 红色屋顶 → 东部沿海地区较为常见
- 红砖清水外墙、人字坡屋顶、普遍三层以上的住宅 → 属特定地区的城镇近现代民居风格
- 农村或城中村出现多层高层自建房 → 可排除北方地区，该区域多为低层平顶自建房
- 一两层平顶火柴盒式自建房密集 → 北方农村或城中村特征
- 某类建筑风格在某区域高度常见 → 可作为区域判读依据
- 民居屋顶檐角明显起翘 → 属传统民居地域风格标志
- 旋转餐厅等标志性建筑 → 可直接用于锁定地标与城市
- 画面出现体育场灯架 → 一般属中学或以上级别的体育场
- 大规模蓝色棚架与远处水塔同现 → 该城市可能有采矿或金属冶炼等重工业
- 南向缺大窗与阳台 → 与常规住宅朝向不符，可能非住宅或另有朝向
- 仅两坡斜面、无正脊正吻的简易屋顶 → 与汉族传统民居风格不同，需另判
- 蓝色铁皮屋顶 → 西南农村地区较常见
- 按住宅层高约2.8米 → 可由层数估算建筑总高
- 彩钢瓦颜色存在明显地域偏好 → 可用红色与蓝色屋顶比例排除或锁定区域
- 大屋顶新中式建筑群 → 多见于自称古都且经济实力较强的城市，约2000年前后流行
- 建造时属当地较高层的建筑群 → 反映当时当地经济实力较强
- 出现水塔 → 多位于发展较早的工业区
- 屋顶坡面、积雪或加盖结构的朝向 → 可判断房屋朝向与南北关系
- 斜面屋檐加蓝色玻璃加外挂空调机位 → 二十世纪末建造的城镇住宅
- 老建筑普遍坡屋顶且屋顶太阳能普及 → 降水充沛的季风气候区
- 收费站等建筑采用鲜艳统一色屋顶 → 属地方建造习惯，可作区域风格线索
- 建筑风格与屋顶形式 → 反映区域建造习惯，可作分区线索
- 平顶房结合黄土状丘陵 → 干旱半干旱地区
- 屋顶以承重陡坡、防雪构造为主 → 冬季降雪频繁的高纬或高海拔地区
- 屋顶以平顶或轻质遮雨棚为主 → 降雪稀少的温暖地区
- 低层房屋密集、屋顶坡度大、窗户偏小 → 冬季降雪频繁地区
- 屋顶坡度与屋面绿植类型组合 → 可判断所属气候区
- 屋顶颜色与塔尖形制特殊 → 受当地文化习惯影响，可作地域线索
- 共享单车集中停放 → 人口密集的居住或工作区，周边可能有大型厂区
- 市区较高楼层大面积使用斜面屋顶 → 当地冬季降雪量大，指向寒冷多雪地区
- 庭院、墙体、屋顶等建筑要素可辨 → 提取布局、材料与装饰风格，与相应地域的传统民居类型比对

## 墙体与立面

*材质、颜色、幕墙判断地域与年代*

- 高楼玻璃幕墙形态与密度 → 可区分市中心与开发区
- 拱形正立面加旁侧塔楼的火车站形制 → 属特定年代铁路建筑，可据形制检索同类旧址照片比对
- 成片高层玻璃幕墙建筑 → 城市规模较大
- 大砖与小砖混砌的墙体 → 特殊砌法可作地域标识
- 红砖墙、清水外墙、缺少构造柱与圈梁、三至六层 → 指向特定区域的自建房形制
- 全玻璃幕墙的高层建筑 → 多为商业办公建筑，而非住宅
- 密集多层老住宅使用马赛克瓷砖外墙 → 多见于华南地区的老居住区
- 红砖外墙且普遍三层以上 → 可与其他同类特征交叉印证区域
- 外墙多经涂装饰面，裸红砖外墙较少见 → 裸红砖可作为地区或年代的判读线索
- 车窗或玻璃反光中出现的文字 → 可作线索，但无法检索查证时不能作为定位实锤
- 背景建筑立面装饰的形状、高度可与周边知名建筑匹配 → 可作定位佐证
- 建筑正立面受光、侧面背光 → 可判断太阳所在方位，反推画面朝向
- 玻璃幕墙镜面反光结合太阳位置计算工具 → 可确定道路走向
- 玻璃隔断的独立房间 → 可能为演播室或影音室
- 玻璃上贴有超市英文名 → 可作为定位线索
- 玻璃贴纸上的英文店名 → 可作为检索定位的文本线索
- 玻璃贴纸上出现英文店名 → 可作为文本检索定位线索
- 玻璃等反光面中的倒影 → 可提取画面外的环境信息
- 高层玻璃幕墙、规整道路、商业标识密集 → 倾向大都市金融商业区或核心商务区
- 阳台外挑或开敞方向 → 可判断建筑立面朝向与拍摄方位
- 住宅阳台朝向 → 反映住宅立面朝向，可判断建筑朝向与拍摄方位
- 主要线索缺失或被遮挡（曝光过度、站牌无字、文字被涂抹） → 改用墙面标牌、玻璃贴纸等次要标识判断场所类型
- 墙面金属标牌加玻璃宣传贴纸组合出现 → 常为银行或通信营业厅等临街门店
- 外墙面砖采用小方块马赛克铺贴 → 指向该材料集中使用的特定区域，可缩小地域范围
- 机场塔台呈细高收腰造型、竖排玻璃幕墙、底部横向条带装饰 → 识别为机场塔台并据此定位机场
- 建筑外观具有鲜明特征（特殊立面、行业招牌等）→ 可作独立地标，辅助确认具体街区

## 民居类型

*骑楼/吊脚楼/石库门/窑洞等地方民居*

- 白墙黑瓦马头墙 → 指向徽派建筑流行区域
- 马头墙与灰墙青石砖的组合 → 属特定地域的传统民居做法
- 成片骑楼、底层架空柱廊 → 指向湿热气候、受外来建筑影响的沿海城区
- 古民居、码头、石桥、城垣等遗存并存 → 指向历史上水运发达、具商埠性质的城镇
- 屋脊带正脊、正吻与翘角 → 属汉族传统官式民居做法
- 灰色碎石垒砌的房屋 → 具特定山区民居特征
- 民居大门普遍朝向 → 可反推拍摄者的取景方位
- 成片飞檐、灰墙建筑沿河分布 → 指向传统商贸古镇或历史城区
- 带有特定传统建筑元素（如马头墙）的仿古建筑 → 可指向具有该建筑风格传统的区域
- 连片低层建筑的形制与样式 → 可辅助判断城市或区域类型
- 民居形式为高脚屋 → 可指向特定湿热地区建筑传统
- 低层建筑样式 → 可辅助判断区域

## 宗教与标志建筑

*教堂、寺庙、塔、牌楼*

- 教堂固定为坐西朝东 → 可据此反推照片方位与日照方向
- 教堂祭台位于最内、大门位于最外 → 可据内部空间朝向判断拍摄方位
- 检索教堂加城市名易返回当地最具观光价值的教堂 → 用于验证候选城市
- 屋檐挂铃铛、照壁前有石灯与罗汉松 → 提示寺庙为新建或翻修
- 同一区域寺庙类地标多 → 需建筑细节和相对位置区分

## 建筑年代判断

*由风格与材料推断建成年代*

- 画面中车辆涂装与广告的年代特征 → 可判断照片拍摄年代
- 两层平放一层竖放的砌砖方式 → 属罕见砌法，可作地域或年代标识
- 成片多层红砖住宅 → 指向特定地区或年代的建房习惯
- 外观不似商品房的成片住宅 → 可能是安置房或保障性住房，影响后续检索方向
- 某一年代车型在某区域保有量高 → 仅作弱线索，需与其他线索交叉印证
- 楼顶带飞碟形圆盘 → 多为八九十年代流行的旋转餐厅
- 素材有可查的创作者账号与首发时间 → 可溯源拍摄地点与拍摄年代
- 车型已停产或大批报废 → 可推断照片拍摄的年代范围，按时间维度筛选
- 早期站牌制式在全国范围内高度统一 → 只能用于判断年代，不能用于区分地域
- 画面中出现满文等非通用文字 → 提示该地存在相应民族文字遗存，可辅助判断地区与年代
- 建筑风格与建造年代 → 辅助判断城市发展水平与区域
- 某品牌或某年代车型在特定地区保有量集中 → 可作地域线索
- 普速列车统一涂装 → 不能用于判断拍摄年代
- 画面中家用电器的机型代际 → 可用于判断照片拍摄年代下限
- 老年代步车与电动车混行 → 城市等级/区域特征
- 雨棚材质/结构样式 → 可推断车站建成年代
- 老年代步车与电动车混行 → 可指示城市等级或区域交通特征
- 站名牌底色与配色在同一线路不同年份可能改变 → 判断线路不能只看站牌颜色，需结合拍摄年代
- 轨道交通的标识与车辆涂装会随年代更换 → 判断旧照片应参照同期样式而非当前样式
- 门牌字迹浅而圆润 → 材质或印刷方式带年代特征，可用于排除部分数字读法
- 照片中的换乘标识样式为旧版 → 可判断照片年代或拍摄时期，并据此使用相应年份的线网图
- 标识版式随年代更替 → 可用于时间定位，进而缩小城市范围
- 年代久远的画面与公开信息 → 可查性下降，需多重线索交叉验证
- 建筑内部隔断形式与靠墙关系 → 可辅助判断房间类型与建筑布局
