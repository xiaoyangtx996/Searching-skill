# 光污染分级（波特尔暗空分类）与星空题

> **旁挂**：`SKILL.md` 是「线索 → 结论」规则表；本文补足**「能看到多暗的星」→ 反推光污染等级 → 收窄到城郊/乡村/野外**这一步。
> 素材来源：本地 `星空题解题辅助/星空图解题思路.txt`。

## 波特尔暗空分类法（Bortle scale）

| 等级 | 环境 | 肉眼极限星等 |
|---|---|---|
| **BS9** | 市中心 | 4.0 |
| **BS8** | 市区 | 4.1–4.5 |
| **BS7** | 市郊 / 满月 | 4.6–5.0 |
| **BS6** | 郊区 | 5.1–5.5 |
| **BS5** | 乡村 | 5.6–6.0 |
| **BS4** | 乡郊 | 6.1–6.5 |
| **BS3** | 野外 | 6.6–7.0 |
| **BS2** | 很黑地区 | 7.1–7.5 |
| **BS1** | 绝黑地区 | 7.6–8.0 |

## 用法

1. 星空软件（Stellarium / SkySafari）算出画面中**可见的最暗星**的星等
2. 对照上表 → 得光污染等级 → 得「城中心 / 市郊 / 乡村 / 野外」档次
3. 用**光污染地图**查该等级对应的地理范围，砍掉不符的候选

> 例：画面只拍到 2~3 等星 → BS8/BS9 → 市中心或市区；拍到 6 等以上星 → BS4 以下 → 远离城市。

## 提醒

- 相机长曝光能拍到**肉眼看不到的暗星**，不能直接用「肉眼可见星等」下结论——要按**曝光参数**折算。
- 月亮、薄云、光晕会显著抬高背景亮度，误判为高光污染。
- 该法只给**城–郊–野**档次，不给经纬度；需与地形、建筑、道路交叉。
