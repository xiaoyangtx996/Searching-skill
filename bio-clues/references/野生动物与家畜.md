# 野生动物与家畜

由**野生动物、鸟类、家畜**反推生态区、保护区与农牧文化区。

> 数据源：iNaturalist（`geo-sleuth/scripts/species.py`，免登录，3.9 亿条观测）；
> 区域条目抽自 `region/references/world/` 与 `中国/`（21 个区域文件含动物信息）。

## 怎么用（三步）

**第一步：认出是什么类群**（不需要精确到种）
照片里能看清的形态（角、体型、羽色、群居方式）先定到**科/属/类群**即可，
多数定位结论只需要"这是什么类群"，不需要精确物种。

**第二步：查分布**（`species.py`）

```bash
py geo-sleuth/scripts/species.py obs "Grus japonensis"        # 丹顶鹤
py geo-sleuth/scripts/species.py obs "Budorcas taxicolor"     # 羚牛
```

**⚠️ 必须用拉丁学名**。中文名会撞车（实测搜"大熊猫"命中澳洲蜗牛 Giant Panda Snail）。
拿不准学名时先用 `taxon` 子命令，或搜英文名。

**第三步：反查验证**（有候选坐标后）

```bash
py geo-sleuth/scripts/species.py near 39.9042,116.4074 --radius 50 --iconic Aves
```

**这是最硬的一步**——候选地附近的实际物种记录里有没有你认出的物种。
没有 → 该候选可疑。`--iconic` 可限定类群：`Aves` 鸟 / `Mammalia` 兽 / `Insecta` 虫 / `Plantae` 植物 / `Reptilia` / `Amphibia` / `Actinopterygii` 鱼 / `Fungi` 真菌。

## 判读规则

### 野生动物

- 画面中有特定动物或展示设施 → 反查目标区域内动物园及公开视频比对
- 动物形态具有明显地域特征（角型、毛色、体型） → 结合该物种分布区收窄范围
- 出现狭域特有种 → **强证据**，可将范围限定在该物种自然分布区内
- 候鸟出现在画面中 → 需配季节；迁徙路线比繁殖地更能指示走廊
- 群居大型兽群（角马、野牛、驯鹿） → 指向特定草原/苔原带与保护区

### 家畜与家禽

- 山地附近加蒙古包加果树 → 西北地区常见组合，只能缩小到大区域，难以精确定位
- 牦牛 → 青藏高原及周边高海拔牧区
- 水牛 → 南方水稻区（长江以南、东南亚）
- 骆驼（双峰/单峰） → 中亚/蒙古 vs 中东/北非，双单峰可分区
- 蒙古马、蒙古包 → 内蒙古及蒙古高原
- 牲畜圈舍形制（如石板圈、木栅栏） → 可提示农牧交错带

### 农作物

- 田间作物处于某一生育阶段 → 结合农事历与积温条件反推月份并限定南北范围
- 有人家处伴生竹林、柑橘类果树多 → 南方乡村聚落特征
- 稻田（含梯田、水田） → 季风区；收割状态可推月份
- 小麦/玉米带 → 北方旱作区（配生育期）

## 护栏

1. **中文名不能直接喂 iNaturalist** —— 会撞车（见开头）。必须用学名。
2. **动物园/保护区 ≠ 自然分布** —— 城市动物园里什么都有，不能据此定位。
   判据是**野外拍摄**（无围栏、无人工喂食设施、有自然背景）。
3. **候鸟有季节** —— 同一地点冬夏物种完全不同，必须配拍摄月份。
4. **家畜指示的是文化区/农牧区，不是精确地点** —— 牦牛给"青藏高原"，给不了具体县。
5. **`species.py` 的 `obs` 只取最近若干条**，样本不等于完整分布；
   要判断"某地有没有"用 `near` 反查，比 `obs` 可靠。
6. **iNaturalist 记录有地域偏** —— 发达地区、观鸟热点记录密度高，
   偏远地区记录稀疏；"没记录"不等于"没有"，只作**弱证伪**。
