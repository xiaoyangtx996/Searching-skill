# 生物线索

由**植物、农作物、家畜、野生动物**推断地域、气候带、季节。

> 本技能由原 `vegetation/` + `flora-fauna/` 合并而来（`flora-fauna/` 原有 22 条中 18 条与生物无关，
> 已归回各自领域，见文末「归位记录」）。
> 收录的是**可复用的判读规则**（线索 → 结论），非单题答案。

## 何时加载

照片中出现**植物、树木、农作物、家畜家禽、野生动物、鸟类**时加载。

## 使用方式

1. 可见特征匹配规则左侧 2. 抄命中并标倾向 3. 交回总技能互证（本领域不报 L3+）
无命中→换领域；条件冲突→跳过；单规则→不升格点位。
回传行：规则摘要：<线索> → <结论>

| 触发 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 无线索命中 | 换领域或加载解题方法论 | 写明本领域无可用规则 |
| 规则与季节/半球冲突 | 跳过该条 | 只输出倾向 |
| 仅命中1条 | 结论止于倾向区域 | 请用户补图或交叉其它领域 |
| 只有树形没有叶片细节 | 别喂识别引擎，用「树种 → 地域」规则 | 只报气候带 |

### 🔴 CHECKPOINT · 🛑 STOP

报城市前须另有独立线索；勿把「多为」写成必然；本领域不单独报 L3+。
**生物线索必须先配拍摄月份**——同一树种在不同季节指示完全不同的纬度（见反例黑名单）。

## 反例黑名单

- 单规则定城定点；脑补未见特征；线索不符仍强行套规则
- **不配月份就套物候规则**（"常绿"在冬天是热带、在夏天毫无意义）
- **把中文学名喂给 iNaturalist**（会撞车，见下）
- 拿"某某植物分布于欧洲"这类散文当分布证据——要用 `species.py` 查**实际观测坐标**
- 苔藓、枝条偏向推方位（原 `bio-clues/` 规则里有多条明确否定）
- 单株植物识别结果当国别铁证（栽培、引种、公园绿化极常见）

## 一、四个子类，先看哪一类

| 子类 | 线索 | 推断目标 | 主要规则节 |
|---|---|---|---|
| **植被与地表覆被** | 树种、林相、常绿/落叶、棕榈、雪松、行道树 | 气候带、纬度、城市绿化指纹 | 本文「树种识别」等 |
| **农作物** | 稻田、麦田、果树、生育期、收割状态 | 农业区、季节（配农事历） | 本文「农作物」 |
| **家畜与家禽** | 牦牛、水牛、骆驼、蒙古马、羊、蒙古包 | 农牧区、文化区 | 本文「家畜」 |
| **野生动物** | 兽类、鸟类、特有种、候鸟 | 生态区、保护区、迁徙走廊 | `references/野生动物与家畜.md` |

## 二、两个识别/分布数据源（互补，都要用）

### `plant.py` — 照片 → 物种（Pl@ntNet，植物专用）

```bash
set PLANTNET_API_KEY=你的key      # https://my.plantnet.org 免费注册（500 次/天）
py geo-sleuth/scripts/plant.py identify leaf.jpg
py geo-sleuth/scripts/plant.py identify leaf.jpg flower.jpg   # 同株 1–5 张更准
py geo-sleuth/scripts/plant.py identify leaf.jpg --organ leaf # 指定部位
```

实测：2 张图（`flower, leaf`）→ `95.7% Brassica oleracea 野甘蓝`。
返回含 `scientific`（拉丁名）、`common_zh`、`family`/`genus`、`iucn`、`gbif_id`、`score`。

### `species.py` — 物种 → 真实观测坐标（iNaturalist，**全体生物**）

```bash
py geo-sleuth/scripts/species.py obs "Fagus sylvatica"        # 正查分布
py geo-sleuth/scripts/species.py near 39.9042,116.4074 --radius 20   # 反查附近物种
py geo-sleuth/scripts/species.py taxon "Ginkgo"                # 拿 taxon_id
```

**反查是定位上最硬的用法**——拿候选地坐标看那里实际有哪些物种记录，**证伪候选地**：

```
30.9135,102.9887 (四川) 50km → 3335 种  绿绒蒿 / 喜山兀鹫 / 黄嘴山鸦…
39.9042,116.4074 (北京) 50km → 9505 种  绿头鸭 / 鸳鸯 / 异色瓢虫…
```

**两个候选地的物种区系明显不同** → 只要从照片认出 1–2 个物种，就能判断哪个候选地对得上。

### ⚠️ iNaturalist 中文名的坑（实测）

搜「大熊猫」→ 实际命中 `Hedleyella falconeri`（**Giant Panda Snail，澳洲蜗牛**），
返回澳洲坐标。因为它的**英文俗名**里带 "Giant Panda"。

**所以默认只吃拉丁学名或英文名**，中文名会被脚本直接拦下。
正确顺序：**`plant.py` 拿学名 → `species.py obs <学名>`**。
脚本还会在命中多个分类单元时警告（如大熊猫有四川亚种 + 秦岭亚种）。

## 三、完整链路

```
照片 → plant.py（植物定物种）/ 现有规则（动物定类群）
         ↓  学名
       species.py obs（查真实观测坐标）
         ↓  分布范围
       与本领域规则 + region/ 交叉 → 候选区域
         ↓  候选有了
       species.py near（反查该地物种）→ 证伪不符的候选
```

## 四、可执行闸门（抄规则前必过）

输出只允许三行，缺一行视为没执行本技能：

```
规则摘要：<可见线索> → <结论>
动作：<跑哪条命令 / 不跑识别 / 交回总技能>
档位：倾向 | 跳过 | 本领域无可用规则
```

| 画面条件 | 立刻执行 | 禁止 |
|---|---|---|
| 用户没给拍摄月份（含「冬天」这种季节词但无年月） | 跳过全部物候条：落叶期、展叶、花期、生育期、候鸟迁徙、「冬季光秃定纬度」 | 不写省/城；季节词只当外貌描述，不当物候证据 |
| 只有树形/行道树轮廓，无叶片花果特写 | 不跑 `plant.py`；只用下表「不依赖叶片」的气候带条 | 不喂任何识别引擎 |
| 公园、花坛、行道、校园单株 | 结论止于「栽培/绿化，非自然分布」 | 不定国家、不定省 |
| 要查 iNaturalist / `species.py` | 学名必须是拉丁名或英文名 | 禁止把中文名当查询词 |
| 命中家畜（牦牛/水牛/骆驼/蒙古马/蒙古包） | 只抄「家畜表」，止于农牧文化区 | 不定县、不定点 |
| 主线索是护栏、路灯、天桥、欧式校园、品牌网点、站房 | 本领域不抄该条，交对应技能 | 不把构筑物当生物结论 |

命令（有特写才跑；Windows 用 `python`，没有 `py` 就用 `python`）：

```bash
python geo-sleuth/scripts/plant.py identify leaf.jpg
python geo-sleuth/scripts/species.py obs "Fagus sylvatica"
python geo-sleuth/scripts/species.py taxon "Ginkgo"
python geo-sleuth/scripts/species.py near 39.9042,116.4074 --radius 20
```

`plant.py` 需要环境变量 `PLANTNET_API_KEY`。没 key → 动作写「缺 key，改用规则表」，不编识别结果。

## 树种识别

*由树种推断气候带/区域倾向；过不了闸门的条直接跳过，不改写成交情话*

- 狭域特有种（自然种群，非公园）→ 范围限定该种自然分布区；公园单株 → 跳过本条
- 区域内的特有植被可佐证位置判断 → 疑似的定位点可借助标志性植被确认
- 同属南方，不同沿海区域在建筑、植被、地理环境上差异明显 → 可进一步细分区域
- 建筑风格需与植被、地理环境结合判断 → 避免仅凭单一特征定性
- 护栏颜色、行道树种类与照片吻合 → 可作候选路段的验证特征
- 街景年份旧、原地建筑已拆除 → 仍可用路灯、大灯、行道树等街道设施的形态与相对位置对应验证
- 冬季街景中光秃枝条与宿存果序 → 可辨识特定树种，需与形态相似的树种区分
- 植被的生长形态 → 反映气候区与生长季，可排除不符区域
- 环境植被、地貌与品牌分布不符 → 应在非典型地貌区域优先查找品牌网点
- 植物特征比建筑风格更可靠，现代建筑风格普遍混搭 → 定位应优先参考植被
- 路灯类型与植被种类 → 可推断所处南北地域
- 光看路边树也能猜城市 → 特色行道树/植被是城市或区域指示线索
- 特色行道树、植被、建筑外立面 → 可作为城市或区域尺度的辅助判读线索
- 植被杂乱、维护痕迹差 → 可推断该处非繁华地段
- 画面中出现特征植物 → 结合该物种的分布区缩小地理范围
- 画面中落叶乔木处于集中落叶期且气温温和 → 拍摄时间为当地秋末落叶期
- 画面中出现狭域分布的特有植物 → 可将范围限定在该物种自然分布区内
- 不靠海但植被常绿、气候温和 → 拍摄地属内陆温和气候区
- 山体土色裸露、植被稀疏、水岸规整 → 类似北方人工水库
- 站房样式独特且周边植被具明显地域性 → 可据此锁定规模较小的城市
- 画面中出现积雪 → 不足以单独判定为北方，需结合植被、地形与气候综合判断
- 冬季植被未枯萎落叶且山体无积雪 → 推断拍摄地冬季温暖或不下雪
- 落叶树基本落叶、仅少量松柏常绿 → 北方寒冷地带冬季/深秋景观。通用
- 树木并非全常绿且已全部展叶 → 拍摄季为暖季
- 单株胸径很大、需多人合抱的桉树 → 非一般城市公园绿化，更可能是林地、乡村或特定人工林
- 狭窄视野中山形、植被、房屋样式与候选地吻合 → 提高候选地置信度
- 灌木、草地与裸露土地组合 → 半荒漠景观
- 半荒漠景观 → 倾向干旱或半干旱区
- 当地特有的城市管理标识（如设施杆编码牌、井盖、护栏样式）可进一步区分同省城市 → 与车牌、植物、路牌共同指向时用于收敛城市
- 河面结冰且植被带偏北 → 位于气候分界线以北
- 雪峰轮廓高度相似 → 单凭山形易误判为最著名山脉，需靠周边植被、树线、村镇、道路校正
- 花期短的观赏植物处于盛花期 → 对应极短的时间窗口，可据此推断拍摄月份
- 植被类型与山体形态 → 用于佐证大尺度地理分区
- 枝条偏向与水体一侧、且树干无苔藓等指示物 → 不能据此判定方位
- 树干上的苔藓仅个别出现 → 不作为南北方向的判据
- 天桥等构筑物的外形轮廓 → 作为可检索、可比对的地物特征
- 目标点街景被人行道树木等遮挡物挡住关键细节 → 改用同侧相邻位置的街景截图间接判读
- 学校位于郊外河边 → 可能处于城市边缘或新区
- 校园采用欧式建筑风格 → 多为近年新建，不能按老城区定位

## 农作物

*作物类型判断农业区；无月份则跳过生育期/收割条*

- 无拍摄月份 → 跳过生育期、收割状态、农事历反推；只认作物种类本身
- 稻田（梯田、水田）→ 季风水稻区倾向（中国南方 / 东南亚等）；不定省
- 小麦或大面积旱作玉米带 → 北方旱作区倾向；不定省
- 田间作物处于某一生育阶段且用户给了月份 → 对照农事历与积温，反推南北范围
- 宅旁竹林 + 柑橘类果树 → 南方乡村聚落倾向

## 家畜与家禽

*牲畜类型判断农牧文化区，不是地点*

| 可见 | 结论（止于文化区） | 禁止 |
|---|---|---|
| 牦牛 | 青藏高原及周边高海拔牧区 | 不定县 |
| 水牛 | 南方水稻区（长江以南、东南亚） | 不定县 |
| 双峰驼 | 中亚 / 蒙古干旱牧区 | 不定点 |
| 单峰驼 | 中东 / 北非干旱牧区 | 不定点 |
| 蒙古马或蒙古包 | 内蒙古及蒙古高原 | 不定点 |
| 山地 + 蒙古包 + 果树 | 中国西北大区域倾向 | 不定点 |
| 低矮帐篷但不是蒙古包 | 不套蒙古包规则 | 不把任意帐篷写成蒙古包 |

## 棕榈科与热带

*棕榈椰树指向热带/亚热带*

- 城市花坛以棕榈为主要绿化且少常绿阔叶 → 该地城市绿化呈棕榈主导特征
- 照片中几乎不见棕榈而常绿阔叶丰富 → 与棕榈主导城市绿化不符，可降低该地可能性

## 针叶与寒带

*松柏白桦指向高纬度*

- 用户给了冬季/月份，且落叶树光秃、常绿针叶仍绿 → 拍摄于当地冬季；无月份 → 跳过
- 画面中落叶树光秃、常绿针叶树仍绿、但无月份 → 跳过本条，只报「可见落叶针叶混交」

## 市树与行道树

*行道树种往往对应城市*

- 绿化带中大量种植雪松 → 该地属温带或偏北气候区
- 道路中间有绿化带 → 可能是较宽的城市道路
- 道路中央设有绿化带 → 通常为较宽的城市主干道或快速路
